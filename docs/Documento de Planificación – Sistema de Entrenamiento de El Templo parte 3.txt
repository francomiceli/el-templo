


Construcción de Bloques SPOM según Intensidad y 
Tipo de Contracción 
Para diseñar bloques de entrenamiento precisos, potentes y fisiológicamente coherentes, 
debemos tener en cuenta dos criterios fundamentales: 
1. La cantidad ideal de ejercicios por bloque, en función de la intensidad relativa (% 
de carga, dificultad técnica, densidad, fatiga). 
2. La distribución de tipos de contracción muscular dentro del bloque: concéntrica 
(C), excéntrica (E) e isométrica (I). 
Cada fase del modelo SPOM responde a una lógica adaptativa distinta, y eso define cómo 
deben construirse los bloques para que el estímulo sea efectivo.

 Cantidad de ejercicios sugerida por bloque: 4 a 5 ejercicios. 
 Tipo de contracción dominante: Concéntrica.

 Este bloque genera mucha fatiga local. 
 Se requiere mayor control y eficiencia, por eso se reduce el volumen. 
 Ya se limita el número de concéntricos, priorizando ejercicios con freno o 
estabilización. 
 Se utilizan pausas activas, tensiones mantenidas o negativas lentas.

 Se reduce la densidad para evitar fallos técnicos bajo cargas altas. 
 El control postural y la capacidad de freno excéntrico son claves. 
 Aparecen transiciones lentas, sostén bajo carga, isometrías avanzadas. 
 No es deseable fallar, sino trabajar con precisión al límite técnico.

 Fase utilizada para testeo, ajuste técnico fino, o reto específico. 
 El uso de ejercicios isométricos es clave para seguridad y especificidad 
neuromuscular. 
 La fatiga es secundaria: lo esencial es la calidad de ejecución al máximo nivel. 
 Ideal para movimientos de altísima carga relativa o técnica avanzada. 


Aplicación en la práctica 
Estos criterios permiten que cada bloque se construya de forma inteligente, no arbitraria: 
1. Primero se elige el objetivo (fuerza, técnica, volumen, etc.). 
2. Luego se determina la intensidad relativa del día. 
3. En base a eso, se definen: 
 Cuántos ejercicios usar (cantidad por bloque). 
 Qué tipo de contracción utilizar y en qué proporción. 
Este sistema no solo asegura coherencia metodológica, sino que también permite adaptar 
el entrenamiento a distintos niveles (Initium, Nucleus, Deuteros, etc.) de forma progresiva, 
garantizando una curva de aprendizaje y estimulación bien diseñada.
