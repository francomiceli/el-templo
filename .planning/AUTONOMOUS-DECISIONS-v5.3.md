#### 146-02 (ejecutado) — CAJA-02 + CAJA-03 + COBRO-05 + primitivos plan 03

- **Migración 0160 idempotente con derived tables (esquiva error 1093)** — el seed de Galicia/Mercado Pago hace `INSERT ...
