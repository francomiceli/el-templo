| Boundary                          | Description                                                                                     |
| --------------------------------- | ----------------------------------------------------------------------------------------------- |
| transacción de cobro → applyDelta | corre dentro del `tx`: un saldo escrito en el gimnasio equivocado queda commiteado con el cobro |
| body del movimiento → loadCaja    | `origenCajaId` y `destinoCajaId` llegan del cliente                                             |
| body del egreso → registerExpense | `costCenterId` llega del cliente                                                                |

## STRIDE Threat Register

| Threat ID   | Category               | Component                                         | Disposition | Mitigation Plan                                                                                                                           |
| ----------- | ---------------------- | ------------------------------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| T-172-09-01 | Tampering              | applyDelta (UPSERT de balances y debt_management) | mitigate    | `tenantWhere` en lecturas y updates + `tenantValues` en el lazy seed, todo sobre el `tx` recibido; el ctx llega del cobro, no del payload |
| T-172-09-02 | Tampering              | loadCaja / registerMovement                       | mitigate    | `tenantWhere(schema.cashRegisters, ctx)`: una caja de otro gimnasio no matchea y el service tira su NotFound actual (404, contrato D-09)  |
| T-172-09-03 | Tampering              | registerExpense con centro de costo ajeno         | mitigate    | `tenantWhere(schema.costCenters, ctx)` antes de imputar el egreso                                                                         |
| T-172-09-04 | Information Disclosure | getBalance / getRowsForTransaction                | mitigate    | `tenantWhere` sobre las 2-3 tablas strict que aparecen en cada statement                                                                  |
