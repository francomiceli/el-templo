  **Data file: `el-templo-web/data/app-landing.ts`**

Centralize ALL /app content in one TypeScript data file. Follow franquicias.ts pattern.

Define interfaces and export data:

```typescript
export interface AppModule {
  id: string;
  name: string;
  tagline: string;
  description: string;
  features: string[];
  properties: { label: string; value: string }[];
  accentColor: string; // CSS custom property name (e.g., "--color-terracotta")
  badgeText: string; // "ACTIVO" or "PROXIMAMENTE"
  badgeClass: string; // BEM modifier for badge color
  isActive: boolean; // true = active, false = proximamente (data-driven toggle)
  iconPlaceholder: string; // SVG inline string (stroke-based, 40x40)
}
```

Export `modules: AppModule[]` array with 4 entries matching spec exactly:

1. **arete**: Arete -- freemium, active, Terracotta accent, features: Tracking de habitos diarios, Modulos gratuitos de bienestar, Contenido de filosofia y mindset, Puerta de entrada accesible. Properties: Modelo=Freemium, Publico=Cualquier persona, Estado=OPERATIVO, Stores=App Store + Google Play.

2. **el-templo**: El Templo -- premium, active, Terracotta accent, features: Test de Nivel, Ruta del Heroe, Rutinas personalizadas segun nivel y objetivos, Seguimiento de progreso, Comunidad online. Properties: Modelo=Premium, Publico=Alumnos + cualquier persona, Estado=OPERATIVO, Contenido=Metodo patentado de El Templo.

3. **olympic-academy**: Olympic Academy -- premium by level, proximamente, Aged Gold accent, features: 3 niveles de certificacion, Videos y material descargable, Evaluaciones teoricas y practicas, Certificacion digital por nivel. Properties: Modelo=Premium (por nivel o suscripcion), Estado=PROXIMAMENTE, Relacion /academy=Mismo programa.

4. **labs**: Labs -- SaaS, proximamente, Azul Noche accent, features: Turnos, Socios, Finanzas, Mensajeria, CRM, Metricas. Properties: Modelo=SaaS (suscripcion mensual), Publico 1=Franquiciados (incluido), Publico 2=Gimnasios externos, Estado=PROXIMAMENTE, Diferencial=Simplicidad nacida de experiencia real.
