  **Service: `el-templo-api/src/modules/app-landing/service.ts`**

Clone GladiusService inquiry pattern. Class `AppLandingService` with:

- Constructor takes `db` (MySql2Database&lt;typeof schema&gt;) and `log` (FastifyBaseLogger)
- `submitWaitlist(data)`: Insert into `appWaitlist`, log, send notification email, return `{ whatsappUrl }`
- `submitLabsInquiry(data)`: Insert into `labsInquiries`, log, send notification email, return `{ whatsappUrl }`
- `listWaitlist()`: Select all from `appWaitlist` ordered by `createdAt` desc
- `listLabsInquiries()`: Select all from `labsInquiries` ordered by `createdAt` desc
- `updateLabsInquiryStatus(id, status)`: Update status field for a labs inquiry. Valid statuses: "new", "contacted", "closed".
- Private `sendNotificationEmail(subject, htmlBody)`: Reads `RESEND_API_KEY` and `APP_NOTIFICATION_EMAIL` from env (default: `ignaciobordon@eltemplo.org`). Same graceful error handling as GladiusService (email failure does NOT fail submission).

WHATSAPP_URL constant: `"https://wa.link/ci8dpl"` (same as franchise/gladius).

**Routes: `el-templo-api/src/modules/app-landing/routes.ts`**

Follow gladius routes pattern:

- `POST /waitlist` (public, no auth): JSON schema validation.
  - nombre: string, minLength 1, maxLength 255 (required)
  - email: string, format email, maxLength 255 (required)
  - moduloInteres: string, minLength 1, maxLength 255 (required) — comma-separated module slugs
  - ciudadPais: string, maxLength 255 (optional)
  - Returns 201 with `{ message: "Registro exitoso", whatsappUrl }`

- `POST /labs-inquiry` (public, no auth): JSON schema validation.
  - nombre: string, minLength 1, maxLength 255 (required)
  - email: string, format email, maxLength 255 (required)
  - telefono: string, minLength 1, maxLength 100 (required)
  - nombreGimnasio: string, minLength 1, maxLength 255 (required)
  - ciudadPais: string, minLength 1, maxLength 255 (required)
  - cantidadSocios: string, enum ["menos-de-50", "50-200", "200-500", "mas-de-500"] (required)
  - sistemaActual: string, enum ["ninguno", "excel", "fitco", "crosshero", "otro"] (required)
  - mensaje: string, maxLength 500 (optional)
  - Returns 201 with `{ message: "Consulta enviada", whatsappUrl }`

- `GET /admin/waitlist` (authenticated, admin/superadmin only): Returns list of all waitlist entries
- `GET /admin/labs-inquiries` (authenticated, admin/superadmin only): Returns list of all labs inquiries
- `PATCH /admin/labs-inquiries/:id/status` (authenticated, admin/superadmin only): Update status. Body: `{ status: "new" | "contacted" | "closed" }`
