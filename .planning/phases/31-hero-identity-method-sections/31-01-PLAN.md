  <files>el-templo-web/composables/useScrollReveal.ts</files>
  <action>
Create a reusable IntersectionObserver composable for scroll-triggered entrance animations. This composable is used by SectionIdentity (Plan 02) and SectionMethod (Plan 03).

**Interface:**

```typescript
interface UseScrollRevealOptions {
  threshold?: number; // default 0.15
  rootMargin?: string; // default '0px 0px -60px 0px'
  once?: boolean; // default true (stop observing after revealed)
}

interface UseScrollRevealReturn {
  revealed: Ref<boolean>;
  elementRef: Ref<HTMLElement | null>;
  cleanup: () => void;
}

export function useScrollReveal(
  options?: UseScrollRevealOptions,
): UseScrollRevealReturn;
```

**Behavior:**

- Creates an IntersectionObserver that sets `revealed` to `true` when the element enters the viewport
- If `once: true` (default), disconnects observer after first reveal
- Guards with `import.meta.client` (SSR safe)
- Sets up observer in `onMounted`, follows cleanup() pattern from CLAUDE.md
- Respects `prefers-reduced-motion`: if enabled, set `revealed` to `true` immediately in onMounted (skip animation wait)
- Follow the same patterns as `useActiveSection.ts` (Ref imports from Vue auto-imported by Nuxt, onMounted, cleanup method)

**Do NOT:**

- Use `process.client` (Nuxt 3 uses `import.meta.client`)
- Use `console.log` (use createLogger if logging needed, but this composable shouldn't need logging)
- Put `onUnmounted` inside the composable (expose `cleanup()` per CLAUDE.md pattern)
