**Key implementation details:**

1. **Split layout** (55% text / 45% image):

   ```css
   .identity__container {
     display: grid;
     grid-template-columns: 55% 1fr;
     gap: var(--space-large); /* 64px */
     align-items: center;
   }
   ```

2. **Mobile stacking** (480px):
   - Image goes first with `order: -1`
   - Grid switches to `1fr`
   - Image aspect ratio changes from 4:5 to 16:9, max-height 280px
   - Use PlaceholderBox with different aspect-ratio on mobile. Since PlaceholderBox uses inline style, use CSS to override: apply `aspect-ratio: 16/9` and `max-height: 280px` on `.identity__image-wrap .placeholder-box` in the mobile breakpoint.

3. **Tablet** (768px):
   - Keep split layout but reduce gap to 32px
   - Reduce padding from 96px to 64px
   - Title font-size from 36px to 28px

4. **Dimmed ghost CTA** (per CONTEXT.md — /filosofia does not exist):
   - Render as `<span>` NOT `<a>` to prevent navigation (same Phase 30 pattern for coming-soon links)
   - Color: `var(--color-olive-stone)` (#8A8472)
   - No hover effect, no pointer cursor, no underline
   - Add modifier class: `.identity__cta--disabled`
   - DO NOT use `.btn--ghost` class (that has active hover states)

5. **Body text** (Geologica Regular, 16px):
   - max-width: 560px on the body wrapper
   - 20px margin-bottom between paragraphs
   - On mobile, max-width: 100%

6. **Parametrized data**:

   ```typescript
   const sedesCount = 8;
   const alumnosCount = "1000";
   ```

7. **Scroll-reveal animation** (per CONTEXT.md):
   - Use `useScrollReveal()` composable from Plan 01
   - The composable sets `revealed` to true when element enters viewport
   - Text slides in from left, image slides in from right:
     ```css
     .identity__text {
       opacity: 0;
       transform: translateX(-30px);
       transition:
         opacity 600ms ease,
         transform 600ms ease;
     }
     .identity__image-wrap {
       opacity: 0;
       transform: translateX(30px);
       transition:
         opacity 600ms ease,
         transform 600ms ease 150ms; /* slight delay */
     }
     .identity__container.is-visible .identity__text,
     .identity__container.is-visible .identity__image-wrap {
       opacity: 1;
       transform: translateX(0);
     }
     ```
   - `prefers-reduced-motion`: composable handles this by setting `revealed = true` immediately, but also add CSS media query to remove transitions:
     ```css
     @media (prefers-reduced-motion: reduce) {
       .identity__text,
       .identity__image-wrap {
         opacity: 1;
         transform: none;
         transition: none;
       }
     }
     ```

8. **Connecting useScrollReveal to the container**:
   - The composable returns `elementRef` and `revealed`
   - Bind `elementRef` to the section element using template ref
   - Bind `revealed` to toggle `is-visible` class on the container
   - Call `cleanup()` in `onBeforeUnmount`

**CSS organization**: Use `<style scoped>` with all identity-specific BEM classes. Reference design tokens via `var(--*)`. Never hardcode colors. All CSS values from spec2-pt2.md.

**Script**: `<script setup lang="ts">`. Import useScrollReveal. Import PlaceholderBox (auto-imported by Nuxt but good for clarity).

**Copy accuracy**: Use the exact Spanish copy from spec2-pt1.md. Keep accented characters (á, é, í, ó, ú, ñ). "Sesión" not "clase". "Comunidad" not "tribu". No marketing language.
