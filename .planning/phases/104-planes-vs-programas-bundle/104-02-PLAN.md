<objective>
Wire the "Todos los Programas" bundle into the subscription lifecycle. When a member is assigned a plan with `grants_all_programs=true`, atomically create one `program_enrollment` (status='active', currentWeek=1) for every `programs.isActive=true` row with `goalPlanType IS NOT NULL` (Foundation programs are excluded — they reuse W* templo session content; granting them would amount to giving bundle users templo content for free, defeating R7's anti-piracy intent) that does not already have an active enrollment for this user. Reject if the user already has another active bundle subscription (no double-bundle, since there is no UNIQUE constraint on grants_all_programs at the schema level — see 02-SUMMARY.md note). When that subscription expires or is cancelled, close exactly the enrollments the bundle owns — leaving any pre-existing enrollment from a different plan untouched — AND null out `users.current_program_enrollment_id` if it points at one of the cancelled rows (per SPEC Constraints).

Purpose: Implements R3 (auto-enroll on bundle activation), R4 (graceful teardown on bundle expiry/cancel + currentProgramEnrollmentId hygiene), and addresses two checker WARNINGS (Foundation-program anti-piracy hole + multi-bundle SKU collision).
Output: Service-layer changes inside `assignPlan` (existing transaction), a new `tearDownBundleEnrollments` private helper called from `cancelSubscription`, `autoExpireSubscriptions`, and `changePlanNow`, plus a new integration test file with all required acceptance scenarios.
</objective>
