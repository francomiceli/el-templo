  <action>
    **Update types.ts:**
    - Add `isArchived: boolean` to PlanListItem interface
    - Add `BulkMigrateInput` interface: `{ userIds: number[]; targetPlanId: number; targetBranchId: number; }`
    - Add `BulkMigrateResult` interface: `{ migrated: number; skipped: number; errors: Array<{ userId: number; error: string }> }`

    **Update schemas.ts:**
    - Add `isArchived: { type: "boolean" }` to plan list item response schema
    - Add `bulkMigratePlanSchema` Fastify schema:
      - body: required [userIds, targetPlanId, targetBranchId]
        - userIds: array of integers, minItems 1
        - targetPlanId: integer
        - targetBranchId: integer
      - response 200: BulkMigrateResult shape

    **Update service.ts:**
    - In `listPlans()`: add `isArchived` to the SELECT columns. Return it in the result.
    - Optionally add `listPlans(includeArchived?: boolean)` parameter. If false (default), filter WHERE isArchived=false. If true, return all. This controls admin UI toggle.
    - In `assignPlan()`: add a guard at the top -- look up the plan, if `isArchived=true`, throw Error("No se puede asignar un plan archivado"). This prevents assigning archived plans to new members.
    - Add `async bulkMigratePlan(input: BulkMigrateInput, adminId: number): Promise<BulkMigrateResult>`:
      1. Verify targetPlanId exists and is NOT archived
      2. For each userId in input.userIds:
         a. Find their active subscription (status='active')
         b. If no active subscription, add to skipped count
         c. Cancel active subscription with reason `Migrado a [target plan name]`
         d. Create new subscription: planId=targetPlanId, branchId=targetBranchId, startDate=today, priceTypeApplied='regular', pricePaid=0, notes='Migrado desde plan legacy', status='active'
         e. Increment migrated count
      3. Wrap each user's operation in try/catch, collect errors per user
      4. Log summary with request.log
      5. Return { migrated, skipped, errors }

    **Update routes.ts:**
    - Add query parameter `includeArchived` (boolean, optional) to the list plans endpoint. Pass to service.
    - Add POST `/admin/subscriptions/bulk-migrate` route:
      - Schema: bulkMigratePlanSchema
      - Handler: call subscriptionService.bulkMigratePlan(req.body, req.user.userId)
      - Return result

  </action>
