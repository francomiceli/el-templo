    Run in a single pass (not transaction -- too many records, but each operation is idempotent):

    1. **Hash temp password** -- hash 'eltemplo2026' with argon2 once
    2. **Create archived legacy plans** -- for each unique legacy plan name not already in DB:
       - INSERT into subscription_plans with: name=exact CSV name, planTier='other', bookingMode='flexible', priceRegular=0, priceZero=0, durationDays=30, isActive=false, isArchived=true
       - Use ON DUPLICATE KEY UPDATE (by name) to be idempotent
    3. **UPSERT members** -- for each resolved member:
       - Check if user exists by DNI (primary dedup key) or email (secondary)
       - If exists: UPDATE non-null fields (merge: don't overwrite existing non-null with null)
       - If not exists: INSERT with all fields, passwordHash from hashed temp password, role='member', level='alfa', branchId from lookup
       - Set createdAt to fechaIngreso if available (preserves real gym join date, not import timestamp). For UPDATE, do NOT overwrite createdAt.
       - Track: created vs updated vs unchanged count

       - Also create note for Creador del legajo: "Creador del legajo: [name]"
       - Skip if note with same content already exists for this user (idempotent)
    5. **Create subscriptions** -- for members with planName:
       - Look up planId (from current plans or newly created archived plans)
       - INSERT subscription with: userId, planId, branchId, status based on isActive and vencimiento (active if isActive=true AND vencimiento >= today, expired if vencimiento < today, cancelled if isActive=false), startDate=fechaIngreso or createdAt, endDate=vencimiento
       - pricePaid=0, priceTypeApplied='regular', notes='Importado desde CSV'
       - Skip if subscription already exists for this user+plan combo (idempotent)
    6. **Mark orphans** -- query users NOT in the resolved member DNI set, where role='member'. Include in report as orphans (don't modify them, just report).
