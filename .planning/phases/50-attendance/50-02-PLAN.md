<!-- Attendance API routes from Plan 01 -->

Admin routes (prefix /api/admin/attendance):

- GET /qr/:branchId -> { token: string, branchId: number, branchName: string }
- GET /today?branchId=N -> { data: AttendanceRecord[] }
- POST /confirm -> body { attendanceIds: number[] } -> { confirmed: number }
- POST /manual -> body { memberId: number, branchId: number } -> AttendanceRecord
- GET /?branchId&date&dateFrom&dateTo&status&page&limit -> { data: AttendanceRecord[], total: number }
- GET /member/:userId?page&limit -> { data: AttendanceRecord[], total: number }

AttendanceRecord shape:

```typescript
interface AttendanceRecord {
  id: number;
  memberId: number;
  memberName: string;
  branchId: number;
  branchName: string;
  checkedInAt: string;
  confirmedAt: string | null;
  status: "registrado" | "confirmado";
  source: "qr" | "manual";
}
```
