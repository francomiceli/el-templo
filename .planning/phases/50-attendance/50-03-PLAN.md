<!-- Member attendance API routes from Plan 01 -->

Member routes (prefix /api/members/attendance):

- POST /check-in -> body { qrToken: string } -> AttendanceRecord (201) or error (400)
- GET /history?page&limit -> { data: AttendanceRecord[], total: number }

Error responses (400):

- "No tenés una suscripción activa"
- "Tu suscripción tiene un pago pendiente. Acercate a recepción."
- "Tu plan solo permite asistir a tu sede asignada"
- "Ya registraste asistencia hoy"

AttendanceRecord shape:

```typescript
interface AttendanceRecord {
  id: number;
  memberId: number;
  memberName: string;
  branchId: number;
  branchName: string;
  checkedInAt: string;
  confirmedAt: string | null;
  status: "registrado" | "confirmado";
  source: "qr" | "manual";
}
```
