<interfaces>
From el-templo-api/src/modules/members/service.ts (count pattern to reuse):
COUNT over schema.completedSessions filtered by eq(userId). Use the same sql<number>`COUNT(*)` shape.

New GraduationService contract (this plan creates it):

- constructor(db, logger)
- maybeGraduateKairos(userId: number): Promise<void>
  - reads users.level + users.level_override for userId
  - if level !== 'kairos' → return (one-way; never touch alfa+)
  - if level_override === true → return (D-03 sticky coach override)
  - counts total completed_sessions for userId
  - if count >= KAIROS_GRADUATION_THRESHOLD → UPDATE users SET level='alfa' WHERE id=userId AND level='kairos'
  - logs the promotion via the injected logger
    </interfaces>
