  <name>Task 1: DNS, SSL, server setup, and GitHub secrets</name>
  <action>
    The user must complete the following manual steps. Claude cannot access GoDaddy, the EC2 server, or GitHub repository settings.
  </action>
  <how-to-verify>

    **Step 1: GoDaddy DNS Configuration**

    In GoDaddy DNS management for eltemplo.org:

    1. Change the `@` (root) A record from "Parked" to `54.21.0.171`
    2. Add `www` A record pointing to `54.21.0.171`
    3. Add `web-staging` A record pointing to `54.21.0.171`

    Wait 5-15 minutes for DNS propagation, then verify:
    ```bash
    dig +short eltemplo.org        # Should show 54.21.0.171
    dig +short www.eltemplo.org    # Should show 54.21.0.171
    dig +short web-staging.eltemplo.org  # Should show 54.21.0.171
    ```

    **Step 2: Server Directory and Nginx Setup (SSH to EC2)**

    ```bash
    # Create deploy directories
    sudo mkdir -p /var/www/el-templo-web
    sudo mkdir -p /var/www/staging/el-templo-web
    sudo chown -R $USER:$USER /var/www/el-templo-web
    sudo chown -R $USER:$USER /var/www/staging/el-templo-web

    # Create a temporary index.html so Nginx doesn't 403
    echo '<html><body><h1>El Templo - Coming Soon</h1></body></html>' > /var/www/el-templo-web/index.html
    echo '<html><body><h1>El Templo Staging - Coming Soon</h1></body></html>' > /var/www/staging/el-templo-web/index.html

    # Copy Nginx configs from the repo (or create them manually using deploy/nginx/ files)
    # Option A: If you have the repo on the server:
    sudo cp deploy/nginx/eltemplo.org /etc/nginx/sites-available/eltemplo.org
    sudo cp deploy/nginx/web-staging.eltemplo.org /etc/nginx/sites-available/web-staging.eltemplo.org
    sudo cp deploy/nginx/www-redirect.eltemplo.org /etc/nginx/sites-available/www-redirect.eltemplo.org

    # Option B: If not, create the files from the content in deploy/nginx/ directory

    # Enable sites
    sudo ln -sf /etc/nginx/sites-available/eltemplo.org /etc/nginx/sites-enabled/
    sudo ln -sf /etc/nginx/sites-available/web-staging.eltemplo.org /etc/nginx/sites-enabled/
    sudo ln -sf /etc/nginx/sites-available/www-redirect.eltemplo.org /etc/nginx/sites-enabled/

    # Test and reload Nginx
    sudo nginx -t
    sudo systemctl reload nginx
    ```

    **Step 3: SSL Certificates (after DNS propagation)**

    ```bash
    # Production cert
    sudo certbot --nginx -d eltemplo.org

    # Staging cert
    sudo certbot --nginx -d web-staging.eltemplo.org

    # www redirect cert
    sudo certbot --nginx -d www.eltemplo.org
    ```

    **Step 4: GitHub Repository Secrets**

    In GitHub repo Settings > Secrets and variables > Actions, add:

    - `WEB_DEPLOY_PATH` = `/var/www/el-templo-web`
    - `STAGING_WEB_DEPLOY_PATH` = `/var/www/staging/el-templo-web`

    (All other secrets like SSH_PRIVATE_KEY, SERVER_HOST, VITE_SENTRY_DSN are already configured.)

    **Step 5: Verify Everything**

    ```bash
    # Test URLs respond
    curl -sI https://eltemplo.org | head -5          # Should show HTTP 200
    curl -sI https://web-staging.eltemplo.org | head -5  # Should show HTTP 200
    curl -sI https://www.eltemplo.org | head -5      # Should show 301 redirect to eltemplo.org
    ```

  </how-to-verify>
