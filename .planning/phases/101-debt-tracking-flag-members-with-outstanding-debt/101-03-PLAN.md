**API contract (from Plan 02):**

- `GET /admin/members?debtorOnly=true&...` → `{ members: MemberListItem[], total, page, limit, totalDebtByCurrency: Array<{currency: string, amount: number}> }`
- Each MemberListItem has `debt: { amount: number, currency: string, note: string | null } | null`
- `PUT /admin/members/:userId` body accepts optional `debt: { amount: number, currency: 'ARS'|'EUR'|'USD', note?: string | null } | null | undefined`
  - object → upsert active debt
  - `null` → soft-cancel active debt
  - `undefined` (key omitted) → leave debt untouched
- `GET /admin/members/:userId` response now includes `debt: ActiveDebt | null` (from Plan 02 schema extension)
