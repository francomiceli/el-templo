  <name>Task 1: Create useJourneySession composable for session fetch, filtering, and completion</name>
  <files>

    el-templo-app/src/modules/journey/stores/journeyStore.ts

  <action>
    Create `useJourneySession.ts` composable following the `useSessionPlayer` pattern:

    **Session Fetching:**
    - Takes `journeyType`, `duration`, and `week` as parameters.
    - Calls `journeyApi.getSession(week, day, duration)` where day is computed from current weekday.
    - If no session found for current week, API handles fallback to most recent available session.
    - Stores fetched session in journeyStore.

    **Duration-Based Block Filtering:**
    - Implements `getBlocksForDuration(blocks, duration)`:
      - 20 min: INITIUM + NUCLEUS only
      - 40 min: INITIUM + NUCLEUS + DEUTEROS_1 (single, no choice between two)
      - 60 min: All blocks (INITIUM + NUCLEUS + DEUTEROS_1 + ATHLOS or EPIKOS)
    - Note: For 40 min, there is no Deuteros choice (only DEUTEROS_1 shown). For 60 min, the coach determines which final block (Athlos/Epikos) is present.
    - Exposes `visibleBlocks` computed from filtered blocks.

    **Session Player State:**
    - `currentBlockIndex: ref<number>` — index into visibleBlocks
    - `currentBlock: computed` — visibleBlocks[currentBlockIndex]
    - `isSessionComplete: computed` — currentBlockIndex >= visibleBlocks.length
    - `advanceBlock()` — increment blockIndex
    - `selectedExerciseIndex: ref<number>` — for exercise list accordion
    - Track session start time, elapsed time.

    **Completion Flow:**
    - `completeSession(rpe?, notes?, exercisesCompleted?)` — calls journeyApi.completeSession with journeyType, duration, date, blocksCompleted, etc.
    - On success: updates journeyStore progress (semana advances for played duration).
    - Returns `cleanup()` method per composable convention.

    **Update journeyStore** to include:
    - `currentWeek: ref<number>` — fetched from SPOM config or passed from API.
    - Methods to load session data and manage session state.

    Fallback to recent session when current week unavailable.
  </done>
