  <action>
    Create `journeys/schemas.ts` with Fastify JSON schemas for request/response validation. Follow existing patterns in sessions/routes.ts and admin/routes.ts.

    Create `journeys/routes.ts` as a Fastify plugin with these endpoints:

    **Member Endpoints (require authentication):**

    1. `GET /journeys/metadata` — Returns JOURNEY_METADATA array (all 6 journeys with names, tiers, descriptions, zones, idealFor). No auth needed beyond member role. Response: `{ journeys: JourneyMetadata[] }`.

    2. `GET /journeys/active` — Returns member's active journey progress or null. Uses `request.user.id`. Response: `{ journey: JourneyProgress | null }`.

    3. `POST /journeys/select` — Body: `{ journeyType: JourneyType }`. Validates journeyType is in ALL_JOURNEY_TYPES. Calls `journeyService.selectJourney(userId, journeyType)`. If member already has same journey active, return 200 with current state (idempotent). Response: `{ journey: JourneyProgress }`.

    4. `GET /journeys/archived` — Returns `{ journeys: ArchivedJourney[] }`.

    5. `GET /journeys/session` — Query params: `{ week: number, day: string, duration: 20|40|60 }`. Retrieves journey session for authenticated member's active journey and level. Uses `journeyService.getJourneySession()`. If no active journey, return 400. If no session found, return 404. Response: session object with blocks filtered by duration.

    6. `POST /journeys/complete` — Body: `{ dayId: string, duration: 20|40|60, date: string, startedAt: string, blocksCompleted: string[], exercisesCompleted?: Record<string, number[]>, rpe?: number, notes?: string }`. Records completion in completed_sessions with journey_type and duration. Calls `journeyService.advanceSemana()` to increment the duration-specific semana counter. Response: `{ success: true, progress: JourneyProgress }`.

    **Admin Endpoints (require admin role):**

    7. `POST /admin/journeys/generate` — Body: `{ week: number, journeyType: JourneyType, days?: string[], regenerate?: boolean }`. Calls `journeyService.generateJourneySessions()`. Response: `{ generated: number, skipped: number }`.

    8. `GET /admin/journeys/members` — Query params: `{ search?: string, journeyType?: string, page?: number, limit?: number }`. Returns all members with their active journey status (or "Sin journey"). Uses a left join between users and member_journeys (isActive=true). Response: `{ members: MemberJourneyInfo[], total: number }`.

    9. `GET /admin/journeys/members/:userId` — Returns detailed journey info for a specific member: active journey, all archived journeys, completed sessions history with journey scope. Response: `{ active: JourneyProgress | null, archived: ArchivedJourney[], completions: CompletionSummary[] }`.

    Register the plugin in `index.ts` alongside existing route registrations. Follow the same pattern: `app.register(journeyRoutes, { prefix: '/api' })`.

    Use Fastify's built-in Pino logger (`request.log`). No console.log per CLAUDE.md.
    Error messages in Spanish per project convention.
    Use `catch (err: unknown)` with `instanceof Error` checks per CLAUDE.md.
