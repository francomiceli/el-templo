    Create `member-journeys.ts` Drizzle schema:
    - `id`: int, primaryKey, autoincrement
    - `userId`: int, notNull, references users.id
    - `journeyType`: varchar(30), notNull (stores journey type code like 'tren_superior', 'empuje', 'planche')
    - `semana20`: int, notNull, default(1) — current semana for 20-min sessions
    - `semana40`: int, notNull, default(1) — current semana for 40-min sessions
    - `semana60`: int, notNull, default(1) — current semana for 60-min sessions
    - `isActive`: boolean, notNull, default(true)
    - `startedAt`: timestamp, defaultNow, notNull
    - `archivedAt`: timestamp, nullable
    - Index on (userId, isActive) for quick active journey lookup.

    Extend `sessions.ts`:
    - Add `journeyType`: varchar('journey_type', { length: 30 }), nullable. Null = general Entrenamiento. Non-null = journey type code.
    - Update the existing unique constraint: dayId is already unique, which handles the J-{type}-W{week}-{day}-{level} format.

    Extend `completed-sessions.ts`:
    - Add `journeyType`: varchar('journey_type', { length: 30 }), nullable.
    - Add `duration`: int('duration'), nullable. Stores 20, 40, or 60 for journey sessions.

    Update `schema/index.ts`:
    - Add `export * from './member-journeys';`

    Create migration `0016_member_journeys.sql`:
    ```sql
    CREATE TABLE member_journeys (
      id INT NOT NULL AUTO_INCREMENT PRIMARY KEY,
      user_id INT NOT NULL,
      journey_type VARCHAR(30) NOT NULL,
      semana_20 INT NOT NULL DEFAULT 1,
      semana_40 INT NOT NULL DEFAULT 1,
      semana_60 INT NOT NULL DEFAULT 1,
      is_active BOOLEAN NOT NULL DEFAULT TRUE,
      started_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
      archived_at TIMESTAMP NULL,
      FOREIGN KEY (user_id) REFERENCES users(id),
      INDEX member_journeys_user_active_idx (user_id, is_active)
    );

    ALTER TABLE sessions ADD COLUMN journey_type VARCHAR(30) NULL;
    ALTER TABLE completed_sessions ADD COLUMN journey_type VARCHAR(30) NULL;
    ALTER TABLE completed_sessions ADD COLUMN duration INT NULL;
    ```
