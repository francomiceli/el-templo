**ReservasPage.vue:**
A mobile-optimized scheduling page with two sections:

**Section 1: "Tus proximas reservas" card (top of page):**

- QCard showing upcoming confirmed + waitlist bookings for the current week
- Each booking: activity name, day + date + time (e.g., "Sesion Grupal - Mar 11 Mar - 8:00")
- Status badge: "Confirmada" (green) or "En espera (#2)" (amber with position)
- Cancel button (X icon) per booking — shows confirm dialog ("Cancelar reserva de Martes 8:00?")
- If no upcoming bookings: "No tenes reservas esta semana" placeholder text
- Weekly limit indicator below the card: "Reservas: 2/3 esta semana" (using booking count vs classesPerWeek from user's subscription — get this from the weekly endpoint response or calculate from myBookings)

**Section 2: Weekly calendar grid:**

- Week navigation: left/right arrows + "Esta semana" button with date range label
- Compact grid optimized for mobile:
  - 6 columns (Mon-Sat), each showing abbreviated day name + date number (e.g., "Lun 10")
  - Rows per time slot (7:00, 8:00, etc.)
  - Each cell shows:
    - Time (small, e.g., "8:00")
    - Occupancy fraction ("12/22")
    - Visual state:
      - **Available:** default style, tappable
      - **Full:** "COMPLETO" text, amber/red tint, still tappable (for waitlist)
      - **Already booked:** highlighted border/background (e.g., primary color border), not tappable (already reserved)
      - **Holiday:** grey, "FERIADO" text, not tappable
      - **Past slot:** dimmed, not tappable
    - Saturday cells only show if ROM slots exist for the branch

**Booking flow (on slot tap):**

1. If slot is available (not full):
   - QDialog confirmation: "Reservar [ActivityName] [DayName] [Date] [Time]?" with "Confirmar" (primary) and "Cancelar" buttons
   - On confirm: call reserve(scheduleId, date)
   - On success: show QNotify positive "Reserva confirmada", refresh grid and bookings
   - On error (weekly limit, overdue, etc.): show QNotify negative with error message from API

2. If slot is full:
   - QDialog: "Este horario esta completo ([X/X]). Queres anotarte en la lista de espera?"
   - "Lista de espera" button + "Cancelar"
   - On confirm: call reserve(scheduleId, date) — API handles waitlist logic
   - On success: show QNotify warning "Te anotaste en la lista de espera (posicion #N)"

3. If already booked: do nothing (cell is visually marked, not tappable)

4. If holiday: do nothing (cell shows FERIADO, not tappable)

**Cancel flow:**

- Tap cancel button on a booking in "Tus proximas reservas"
- QDialog: "Cancelar reserva de [Day] [Time]?"
- On confirm: call cancelBooking(bookingId)
- On success: refresh grid and bookings, show QNotify
- On error (< 20min before class): show error message

**Data loading:**

- On mount: compute current week's Monday, call getWeeklyGrid(weekStart)
- Response includes slots, holidays, and myBookings — use all three to render the grid
- Re-fetch on week change
- Overlay myBookings on grid cells to mark "already booked" state

**Mobile styling:**

- Grid cells should be compact — use a CSS grid with `grid-template-columns: repeat(6, 1fr)`
- Min-width per cell ~55px, allow horizontal scroll on very narrow screens
- Use the app's existing SCSS variables ($primary, $cream, $accent) from `src/css/quasar.variables.scss`
- Font sizes: day label 11px, time 12px, occupancy 14px bold
- Touch targets: cells should be at least 44px tall for comfortable tapping
