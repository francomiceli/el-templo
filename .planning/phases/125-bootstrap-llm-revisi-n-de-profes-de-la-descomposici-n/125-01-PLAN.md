<objective>
Build the data layer + heuristic engine for the first automatic pass of the 3-dimension decomposition (TREE-02).

Create the `exercise_dimension_proposals` table (Drizzle schema + hand-written migration 0138), and an idempotent, re-runnable one-off CLI `bootstrap-dimensions.ts` that reads `exercises` and writes deterministic proposals (sub-family from route code, leverage from name keywords, route only for `route_pending`). The bootstrap NEVER writes the `exercises` truth columns — it only inserts `pending` proposals (D-01). CI integration tests cover the bootstrap contract.

Purpose: A reviewable first pass that fills the dimensions created in Phase 124 without manual entry, while keeping `exercises` clean and auditable until a profe accepts (Plan 02).
Output: proposals schema, migration 0138 (committed, NOT applied), bootstrap script, integration tests.
</objective>
