<objective>
Build the profe review API (TREE-03) in the existing `admin` module: list proposals (filter/group by route), accept (transactionally writing the Phase 124 truth columns per D-02), reject, and bulk-accept-group.

The admin module already owns `/admin/exercises*`, the plugin-level auth hook (TRAINING_ROLES), and the bulk-approve pattern — proposal endpoints live there, NOT in a new module. Accept is the only write that touches `exercises` truth columns, and it does so transactionally (resolve-or-create subfamily, set subfamily_id + leverage, set route + clear route_pending for route_pending rows). Reject never writes truth.

Purpose: Profes confirm/correct/reject the heuristic proposals before they become truth, sweeping ~1.493 exercises fast via route-grouped bulk-accept + individual override.
Output: ProposalService, JSON schemas, routes wired into adminRoutes, CI integration tests.
</objective>
