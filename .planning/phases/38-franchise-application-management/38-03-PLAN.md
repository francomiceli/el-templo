## Goal

Build the AI agent tabbed panel component that sits on the FranchiseDetailPage. Four tabs (Strategy, Outreach, Follow-up, Negotiation), each with inline tutorial text, a generate button, loading state, rendered output, and a regenerate button with warning. Wire it into the detail page created by 38-02.

## Context

- API route from 38-01: `POST /api/franchise/admin/applications/:id/generate` with body `{ agentType: 'strategy' | 'outreach' | 'followup' | 'negotiation' }` — returns `{ agentType, content }`
- Composable from 38-02: `useFranchiseAdminApi().generateAiContent(id, agentType)` already wraps this endpoint
- FranchiseDetailPage from 38-02 has a placeholder comment for the AI panel section
- Application data includes ai_strategy, ai_outreach, ai_followup, ai_negotiation fields (pre-populated from previous generations)
- CONTEXT.md decisions:
  - 4 agents in tabs: Strategy | Outreach | Follow-up | Negotiation
  - Manual "Generate" button per tab
  - Re-generate with warning: "This will replace the current strategy..."
  - AI input: original form data only (NOT admin notes)
  - Output format: Claude's discretion (structured strategy brief)
  - Inline description per tab explaining what the agent does
  - AI content in its own dedicated section, separate from manual notes

8. **handleGenerate(agentType):**

   ```typescript
   async function handleGenerate(agentType: string) {
     generating.value = agentType;
     try {
       const result = await franchiseApi.generateAiContent(
         props.applicationId,
         agentType,
       );
       emit("generated", agentType, result.content);
     } catch {
       // Error handled by composable (Notify)
     } finally {
       generating.value = null;
     }
   }
   ```

9. **handleRegenerate(agentType):**

   ```typescript
   function handleRegenerate(agentType: string) {
     $q.dialog({
       title: "Regenerar contenido",
       message:
         "Esto reemplazara el contenido actual. Guarda cualquier informacion importante antes de regenerar.",
       cancel: { label: "Cancelar", flat: true },
       ok: { label: "Regenerar", color: "primary" },
       persistent: true,
     }).onOk(() => {
       handleGenerate(agentType);
     });
   }
   ```

10. **copyContent(content):**

    ```typescript
    function copyContent(content: string | null) {
      if (!content) return;
      navigator.clipboard.writeText(content);
      Notify.create({
        type: "positive",
        message: "Contenido copiado",
        timeout: 1500,
      });
    }
    ```

4. Add the `onAiGenerated` handler in the script:

   ```typescript
   function onAiGenerated(agentType: string, content: string) {
     if (!application.value) return;
     // Map agentType to the correct field on the application object
     const fieldMap: Record<string, keyof FranchiseApplication> = {
       strategy: "aiStrategy",
       outreach: "aiOutreach",
       followup: "aiFollowup",
       negotiation: "aiNegotiation",
     };
     const field = fieldMap[agentType];
     if (field) {
       // Update local state so the panel re-renders with the new content
       (application.value as Record<string, unknown>)[field] = content;
     }
   }
   ```

   Alternatively, if TypeScript complains about the indexed assignment, create a new object:

   ```typescript
   function onAiGenerated(agentType: string, content: string) {
     if (!application.value) return;
     const fieldMap: Record<string, string> = {
       strategy: "aiStrategy",
       outreach: "aiOutreach",
       followup: "aiFollowup",
       negotiation: "aiNegotiation",
     };
     const field = fieldMap[agentType];
     if (field) {
       application.value = { ...application.value, [field]: content };
     }
   }
   ```
