## Context

This plan builds sections 5-8 of the /academy page. The Flywheel is the strategically most important section — it shows visitors they're entering a path with infinite ceiling. It must be built as a reusable props-driven component that /franquicias can later override.

**CONTEXT.md locked decisions:**

- Flywheel: props-driven reusable component with defaults. Academy values are defaults, /franquicias can override any prop later
- Hover tooltips on desktop, mobile vertical flow with descriptions inline
- Node colors: Entren&aacute; = Terracotta, Formate = Aged Gold, Lider&aacute; = Deep Bronze, Invert&iacute; = Deep Charcoal
- Arrows: Warm Stone 60%, stroke 2px, curved
- Center: Logo El Templo or fire icon, 60x60px
- Deep Charcoal background section
- Scroll-triggered reveal: progressive node appearance with 0.2s stagger
- Digital tools displayed as subtle row below diagram
- Inversi&oacute;n: placeholder state, no prices, CTA scrolls to form, franchise note below

**Spec backgrounds:**

- Flywheel: Deep Charcoal #3D3732
- Modalidades: Warm Linen #EDE4D6
- Qui&eacute;n Ense&ntilde;a: Sandy Beige #E5D9C8
- Inversi&oacute;n: Marble Cream #F2EDE5

<title>Build FlywheelDiagram reusable component + AcademyFlywheel wrapper</title>
<details>

**Reusable component: `el-templo-web/components/FlywheelDiagram.vue`**

This is the strategically most important visual component. Built as a reusable, props-driven component.

**Props (all with defaults from academy data):**

```typescript
interface FlywheelProps {
  nodes?: FlywheelNode[]; // 4 nodes with id, title, description, color
  tools?: FlywheelTool[]; // Digital tools below diagram
  centerIcon?: "fire" | "logo"; // Default: 'fire'
  centerSize?: number; // Default: 60
  closingText?: string; // Text after diagram
}
```

Import default values from `~/data/academy` for defaults.

**Desktop layout (min-width: 768px) — Circular SVG diagram:**

Use a pure SVG approach. The diagram is a circle with 4 equidistant nodes at 12, 3, 6, 9 o'clock positions (or top, right, bottom, left). SVG viewBox e.g., `0 0 400 400`.

Node positions (clockwise from top):

- ENTREN&Aacute; (top) — Terracotta
- FORMATE (right) — Aged Gold
- LIDER&Aacute; (bottom) — Deep Bronze (#7A6543)
- INVERT&Iacute; (left) — Deep Charcoal (#3D3732) — use lighter text since bg is also Deep Charcoal, or use a lighter border ring

Each node is a circle (120x120px area mapped to SVG) with:

- Colored circle fill (or border ring)
- Title text: Geologica Semibold 14px, Marble Cream
- Subtitle text (on hover): Geologica Regular 12px, Warm Stone

Curved arrows between nodes (clockwise):

- Warm Stone at 60% opacity, stroke 2px
- SVG path with quadratic bezier curves between node edges

Center element:

- Fire icon (inline SVG, Olympic flame style) or El Templo logo, 60x60px
- Marble Cream color

**Hover behavior (desktop):**

- At rest: nodes show title + icon/color only
- On hover: tooltip appears with full stage description from node.description
- CSS-based tooltip (::after pseudo or a positioned div) or a reactive ref

**Mobile layout (below 768px) — Vertical flow:**

Replace circular SVG with a vertical CSS layout:

- 4 blocks stacked vertically
- Each block: colored left border (4px) + title + description always visible inline
- Downward arrows (SVG or CSS) between blocks
- No hover interaction needed

**Scroll-triggered animation:**
Use `useScrollReveal` or custom IntersectionObserver:

- Progressive node appearance: each node fades in with 0.2s stagger
- CSS approach: nodes start with `opacity: 0; transform: scale(0.8)` then transition to visible
- Use inline `transition-delay` per node: 0s, 0.2s, 0.4s, 0.6s (consistent with Phase 30 stagger pattern)

**Digital tools row (below diagram):**

- Subtle row/grid of 4 tool names with descriptions
- Geologica Regular 13px, Warm Stone color (subtle, informational)
- Not clickable, just informational

**Section-level styling:**
This component does NOT set its own background — the wrapper controls that.
