## Context

This plan builds the API backend for the /academy enrollment form and a basic admin list view. The pattern follows gladius-inquiries exactly: Drizzle schema, manual SQL migration, Fastify service with Resend email, routes, integration tests, then a simple read-only admin page.

**CONTEXT.md locked decisions:**

- New `academy_inquiries` DB table (follows gladius_inquiries pattern)
- API endpoint: POST /api/academy/inquire
- 10 fields: nombre, email, telefono, ciudadPais, nivelInteres, modalidad, experiencia, alumnoElTemplo, origen, mensaje
- Separate ACADEMY_NOTIFICATION_EMAIL env var (defaulting to ignaciobordon@eltemplo.org)
- Email notification via Resend (same pattern as franchise/gladius)
- Basic admin list view: read-only, name/email/date/level interest

<task id="43-01-T2">
<title>Create AcademyService + routes + register in app.ts</title>
<details>

**Service: `el-templo-api/src/modules/academy/service.ts`**

Clone the GladiusService inquiry pattern. Class `AcademyService` with:

- Constructor takes `db` (MySql2Database<typeof schema>) and `log` (FastifyBaseLogger)
- `submitInquiry(data)`: Insert into `academyInquiries`, log, send notification email, return `{ whatsappUrl }`
- `listInquiries()`: Select all from `academyInquiries` ordered by `createdAt` desc (for admin list)
- `sendNotificationEmail(data)`: Private method, reads `RESEND_API_KEY` and `ACADEMY_NOTIFICATION_EMAIL` from env. Default notification email: `ignaciobordon@eltemplo.org`. Email body includes all 10 fields. Subject: `Nueva consulta Academy: {nombre} — Nivel: {nivelInteres}`. Same graceful error handling as GladiusService (email failure does not fail submission).

WHATSAPP_URL constant: `"https://wa.link/ci8dpl"` (same as gladius/franchise).

**Routes: `el-templo-api/src/modules/academy/routes.ts`**

Follow gladius routes pattern:

- `POST /inquire` (public, no auth): JSON schema validation for all 10 fields. nombre, email, telefono, ciudadPais, nivelInteres, modalidad, experiencia, alumnoElTemplo, origen required. mensaje optional (maxLength 500). email format validation. Returns 201 with `{ message, whatsappUrl }`.
- `GET /admin/inquiries` (authenticated, admin/superadmin only): Returns list of all inquiries.

Interface `InquireBody` with all 10 fields. Validation schema with:

- nombre: string, minLength 1, maxLength 255
- email: string, format email, maxLength 255
- telefono: string, minLength 1, maxLength 100
- ciudadPais: string, minLength 1, maxLength 255
- nivelInteres: string, enum ["nivel-1-trainer", "nivel-2-olympic-trainer", "nivel-3-spartan-trainer"]
- modalidad: string, enum ["presencial", "online", "ambas"]
- experiencia: string, enum ["calistenia", "otro-entrenamiento", "sin-experiencia", "entrenador"]
- alumnoElTemplo: string, enum ["si", "no", "fui-alumno"]
- origen: string, enum ["instagram", "web", "recomendacion", "google", "otro"]
- mensaje: string (optional), maxLength 500

**Register in app.ts: `el-templo-api/src/app.ts`**

Add import: `import { academyRoutes } from "./modules/academy/routes";`
Add registration after blog routes: `await app.register(academyRoutes, { prefix: "/api/academy" });`
Add comment: `// Academy routes (enrollment inquiry form)`

**Update .env.example: `el-templo-api/.env.example`**

Add below GLADIUS_NOTIFICATION_EMAIL:

```
ACADEMY_NOTIFICATION_EMAIL=ignaciobordon@eltemplo.org
```
