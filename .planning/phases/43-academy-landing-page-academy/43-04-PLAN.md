## Context

This plan completes the /academy page with the remaining sections (FAQ + Form), adds the sticky side menu navigation, floating WhatsApp, and integrates Academy into the global site navigation. Also handles SEO structured data and analytics. Depends on 43-03 because T4 wires all 12 components in academy.vue, including AcademyFlywheel, AcademyModalidades, AcademyQuienEnsena, and AcademyInversion created in 43-03.

**CONTEXT.md locked decisions:**

- Side menu: sticky, 240px wide, below AppNav (top: ~80px), items are anchor links, active section via IntersectionObserver with Terracotta 2px left border, hidden below 1200px
- Form: 10 fields, POST /api/academy/inquire, confirmation + WhatsApp link
- AppNav: Add "Academy" as 7th link (after Blog)
- AppFooter: Change Academy disabled: true to disabled: false
- FranIncludes: Add note about included trainer formation with link to /academy
- Analytics: GA4 form_submit_academy + Meta Pixel trackLead
