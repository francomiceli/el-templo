<objective>
Backend-first editor for the skill tree (D-06). Build a new `tree-editor` module exposing admin/coach-scoped endpoints to: (1) READ the editable tree (auto vs manual distinguished), (2) REORDER exercises within a `(subfamily × effort)` partition (D-03), (3) ADD/REMOVE precedence cross-edges (D-04), and (4) GROUP/SPLIT subfamilies by reassigning `exercises.subfamily_id` (D-05). All overrides persist in the EXISTING `exercise_progressions` table as `source='manual'` (D-01). Every route → an integration test in CI.

This is the backend the Wave-2 admin UI (Plan 03) consumes. It is paired with Plan 01's locked-partition guard: the editor LOCKS a partition (by writing manual edges + deleting that partition's auto edges) and Plan 01 keeps the rebuild from clobbering it.

Purpose: gives profes the persistence layer to refine the auto-built tree, which is what "desbloquea el milestone sin curaduría manual previa".
Output: a `tree-editor` module + plugin registration + integration tests.
</objective>
