<objective>
Modify the Phase-126 graph constructor so a profe's manual overrides PREVAIL over the SPOM auto order and SURVIVE a full graph rebuild — the load-bearing risk-mitigation of TREE-07 (D-02). This is the ONLY change to the 126 constructor.

Today `runRebuildProgressionGraph` does a GLOBAL `DELETE FROM exercise_progressions WHERE source='auto'` then re-inserts the full computed backbone for every partition. Once the editor (Plan 02) replaces a `(subfamily_id × effort)` partition's auto chain with a manual chain, a rebuild would re-insert the auto backbone alongside the manual edges, resurrecting the order the profe intentionally overrode. The fix: a partition that owns ANY `manual` edge is LOCKED — the constructor must skip BOTH the auto-delete and the auto-insert for that partition.

Purpose: guarantees "una re-construcción del grafo no pisa los ajustes manuales" (ROADMAP success criterion 4, the phase risk note).
Output: a guarded constructor + a dedicated integration test proving the guard.
</objective>
