Blog API:

```typescript
// GET /api/admin/blog/posts?status=all|draft|published -> { posts, total, page, totalPages }
// POST /api/admin/blog/posts body: { title, excerpt?, coverImage?, body?, slug? } -> post
// PUT /api/admin/blog/posts/:id body: { title?, excerpt?, coverImage?, body?, status?, slug? } -> post
// DELETE /api/admin/blog/posts/:id -> 204
// POST /api/admin/blog/upload-image body: { filename } -> { uploadUrl, publicUrl }
```

Gladius API:

```typescript
// GET /api/admin/gladius/products -> GladiusProduct[]
// POST /api/admin/gladius/products body: { name, description, photo?, slug?, sortOrder? } -> product
// PUT /api/admin/gladius/products/:id body: partial fields -> product
// DELETE /api/admin/gladius/products/:id -> 204
```

       - `useBlogApi()` returns functions:
         - `listPosts(params?: { page?, limit?, status? })` -> GET /admin/blog/posts
         - `getPost(id: number)` -> GET /admin/blog/posts/:id
         - `createPost(data: { title: string; excerpt?: string; body?: string; coverImage?: string; slug?: string })` -> POST /admin/blog/posts
         - `updatePost(id: number, data: Partial<...>)` -> PUT /admin/blog/posts/:id
         - `deletePost(id: number)` -> DELETE /admin/blog/posts/:id
         - `publishPost(id: number)` -> PUT /admin/blog/posts/:id with { status: 'published' }
         - `unpublishPost(id: number)` -> PUT /admin/blog/posts/:id with { status: 'draft' }
       - Use `api` from `src/boot/axios`
       - Define BlogPost interface: { id, title, slug, excerpt, coverImage, body, status, createdAt, updatedAt, publishedAt }
       - Export interface for use by pages

    2. **`composables/useGladiusApi.ts`** — Gladius API composable:
       - `useGladiusApi()` returns:
         - `listProducts()` -> GET /admin/gladius/products (returns all, including unpublished)
         - `createProduct(data)` -> POST /admin/gladius/products
         - `updateProduct(id, data)` -> PUT /admin/gladius/products/:id
         - `deleteProduct(id)` -> DELETE /admin/gladius/products/:id
       - Define GladiusProduct interface: { id, name, slug, description, photo, status, sortOrder, createdAt, updatedAt }

    3. **`composables/useBlogImageUpload.ts`** — Image upload composable (follow useVideoUpload.ts pattern):
       - `useBlogImageUpload()` returns:
         - `uploading: Ref<boolean>`
         - `uploadImage(file: File): Promise<string>` — calls POST /admin/blog/upload-image to get presigned URL, then uploads file directly to R2 via PUT, returns the publicUrl
       - Steps: (1) call API for presigned URL with filename, (2) PUT file to uploadUrl with correct Content-Type, (3) return publicUrl
       - Handle errors: set uploading=false, throw for caller to handle

    4. **`router/routes.ts`** — Add new routes:
       - Under AdminLayout children, add:

       - Also add a route guard in `router/index.ts` (if not already present) that checks `allowedRoles` against user role and redirects to /sessions if unauthorized. Read the existing router/index.ts to check if beforeEach already handles this. If not, add:

      - **Italic** (I) -> wraps selection with `*`
      - **H2** -> inserts `## ` at line start
      - **H3** -> inserts `### ` at line start
      - **Link** -> inserts `[text](url)` (prompt for URL via q-dialog)
      - **Image** -> triggers image upload (see below), inserts `![alt](url)`
      - **Unordered List** -> inserts `- ` at line start
      - **Ordered List** -> inserts `1. ` at line start
    - Toolbar uses Quasar q-btn with icons (format_bold, format_italic, title, link, image, format_list_bulleted, format_list_numbered)
    - Textarea uses monospace font, full-width, min-height 400px

    - Image toolbar button opens a file picker (accept: image/*)
    - On file select, calls useBlogImageUpload().uploadImage(file)
    - While uploading: show loading indicator on toolbar button
    - On success: insert `![image](publicUrl)` at cursor position in textarea
    - On error: show q-notify error toast
    - Drag-and-drop: listen for dragover/drop on textarea, on drop extract file and upload same way

    **Cover image:**
    - Above the editor toolbar, a "Cover Image" section:
      - Shows current cover image URL as thumbnail (or placeholder if none)
      - "Upload Cover" button triggers same useBlogImageUpload flow
      - On success, sets coverImage field
      - "Remove" button clears coverImage

    **Form fields (above editor):**
    - Title: q-input (required, large font)
    - Slug: q-input (auto-generated from title on blur if empty, editable)
    - Excerpt: q-input textarea (2 rows, optional)

    **Preview mode:**
    - Toggle button "Vista Previa" / "Editor"
    - Preview renders the Markdown body as HTML using a simple Markdown-to-HTML converter
    - For the converter: use a lightweight library. Check if `marked` is already in dependencies. If not, use `marked` (small, fast, no deps). Install: `pnpm add marked` in el-templo-admin.
    - Preview area uses brand typography classes: h2 in Montserrat, body in Geologica, etc.
    - Preview is read-only, scrollable

    **Save/Publish flow:**
    - "Guardar Borrador" button: calls createPost (if new) or updatePost with status='draft'

    - Route params: if `:id` present, load existing post on mount. If no `:id`, create mode.

    **Loading/Error states:**
    - Loading existing post on edit: q-inner-loading
    - Save errors: q-notify error toast

    Use `createLogger()` for error logging. No console.log. No `any` types.
