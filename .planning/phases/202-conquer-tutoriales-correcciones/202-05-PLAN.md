  (idempotente) → storage (503) → `remove(video_key)` con `callVideoStore` (si falla → 503 y la fila NO cambia) → UPDATE
  `video_key = NULL, video_deleted_at = NOW(), video_deleted_by = request.user.userId` → 200 con la vista. Nunca borra
  `reply_video_key`. Log `{ correctionId }` con `request.log.info`.

  guard (el guard es plugin-level: un `coach` recibe 403 antes de validar nada).
