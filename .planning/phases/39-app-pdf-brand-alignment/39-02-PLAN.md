<task type="auto">
  <name>Task 1: Generate new base64 font assets for PDF builder</name>
  <files>el-templo-admin/src/utils/pdf/pdf-assets.ts</files>
  <action>
Replace the font base64 exports in pdf-assets.ts. The font files exist in el-templo-web/assets/fonts/ as .woff2 files, but pdfmake requires .ttf format. Generate base64 .ttf data:

**Approach**: Use the @fontsource npm packages (which contain .ttf files) to extract the base64 data. Install temporarily or locate the .ttf files:

1. Install font packages in el-templo-admin temporarily:

   ```bash
   cd el-templo-admin
   pnpm add @fontsource/montserrat @fontsource/geologica @fontsource-variable/cormorant-garamond
   ```

2. Write a Node.js script to find the .ttf files in node_modules and convert to base64:

   ```bash
   node -e "
   const fs = require('fs');
   const path = require('path');
   // Find .ttf files in @fontsource packages
   // Montserrat: latin-400-normal.ttf, latin-700-normal.ttf
   // Geologica: latin-400-normal.ttf, latin-600-normal.ttf
   // Cormorant Garamond: latin-400-normal.ttf, latin-400-italic.ttf
   // Convert each to base64 and output as JS export
   "
   ```

   If @fontsource packages only ship .woff2 (not .ttf), use a woff2-to-ttf converter or download .ttf files directly from Google Fonts API:

   ```bash
   # Download TTF files from Google Fonts
   curl -o /tmp/montserrat.zip "https://fonts.google.com/download?family=Montserrat"
   curl -o /tmp/geologica.zip "https://fonts.google.com/download?family=Geologica"
   curl -o /tmp/cormorant-garamond.zip "https://fonts.google.com/download?family=Cormorant+Garamond"
   ```

3. Replace exports in pdf-assets.ts:
   - Remove: `CINZEL_REGULAR_BASE64`, `CINZEL_BOLD_BASE64`, `ROBOTO_REGULAR_BASE64`, `NUNITO_SANS_REGULAR_BASE64`, `NUNITO_SANS_BOLD_BASE64`, `NUNITO_SANS_BOLD_ITALIC_BASE64`, `GREAT_VIBES_REGULAR_BASE64`
   - Add: `MONTSERRAT_REGULAR_BASE64` (400 weight), `MONTSERRAT_BOLD_BASE64` (700 weight), `GEOLOGICA_REGULAR_BASE64` (400 weight), `GEOLOGICA_SEMIBOLD_BASE64` (600 weight), `CORMORANT_GARAMOND_REGULAR_BASE64` (400 normal), `CORMORANT_GARAMOND_ITALIC_BASE64` (400 italic)
   - Keep: `LOGO_BASE64`, `ICON_BASE64`

4. Ensure each export is: `export const FONT_NAME_BASE64 = '...';` with the raw base64 string (no data URI prefix).

**IMPORTANT**: The base64 strings are very large (~200KB+ each). This is expected for embedded PDF fonts. pdfmake requires TTF format specifically.
