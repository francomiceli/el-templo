Create a NEW pure Vitest file `el-templo-bot/test/playbook-flow-coverage.test.ts` that covers each of PB1-PB5 with at least one happy path and one objection path, end-to-end at the engine + prompt layer. Pattern reference: `pb1-discovery-flow.test.ts` (uses a `stageContent()` helper to scope content assertions to stage promptSections) + `playbook-advance.test.ts` (uses `advanceStageIfComplete` to walk stage transitions deterministically) + `pb2-pb5-isolation.test.ts` (uses `getSystemPrompt` for wrapper-directive assertions).

Structure (5 describe blocks, one per playbook, each with happy + objection sub-blocks):

```ts
import { describe, it, expect } from "vitest";
import { getSystemPrompt } from "../src/ai/system-prompt.js";
import { advanceStageIfComplete } from "../src/playbooks/advance.js";
import { PLAYBOOKS } from "../src/playbooks/definitions.js";
import type {
  PlaybookId,
  StageId,
  AvatarProfile,
} from "../src/playbooks/types.js";

// Helper: scope content assertions to a stage promptSection so the base
// business knowledge string doesn't poison negative checks. Same pattern as
// pb1-discovery-flow.test.ts and pb2-pb5-isolation.test.ts.
function stageContent(playbookId: PlaybookId, stageId: StageId): string {
  const def = PLAYBOOKS[playbookId];
  const stage = def.stages.find((s) => s.id === stageId);
  if (!stage) throw new Error(`stage not found: ${playbookId}.${stageId}`);
  return stage.promptSection;
}
```
