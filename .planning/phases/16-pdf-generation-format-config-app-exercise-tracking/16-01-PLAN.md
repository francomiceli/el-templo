<task type="auto">
  <name>Task 1: Create FormatParams type system and default factory</name>
  <files>el-templo-api/src/modules/admin/format-params.ts</files>
  <action>
Create a new file `format-params.ts` with:

1. A discriminated union type `FormatParams` covering all HIGH and MEDIUM importance formats:
   - `{ type: 'amrap'; minutes: number }` (default: 10)
   - `{ type: 'emom'; intervalSeconds: number; totalMinutes: number }` (default: 60s interval, exerciseCount * 1 min total)
   - `{ type: 'complex'; rounds: number }` (default: 3)
   - `{ type: 'tabata'; workSeconds: number; restSeconds: number; rounds: number }` (default: 20/10/8)
   - `{ type: 'interval'; workSeconds: number; restSeconds: number; rounds: number }` (default: intensity-scaled)
   - `{ type: 'for_time'; timeCapMinutes?: number }` (default: no cap)
   - `{ type: 'chipper'; rounds: number }` (default: 1)
   - `{ type: 'buy_in_cash_out'; rounds?: number }` (default: 3)
   - `{ type: 'cluster'; clusterSize: number; restBetweenClusters: number }` (default: 3 cluster, 90s rest)
   - `{ type: 'ladder'; direction: 'ascending' | 'descending' }` (default: derived from intensity)
   - `{ type: 'unbroken' }` (no params)
   - `{ type: 'couplet' }` (no params)
   - `{ type: 'triplet' }` (no params)
   - `{ type: 'for_max' }` (no params)
   - `{ type: 'time_cap'; minutes: number }` (default: 10)
   - `{ type: 'standard' }` (default fallback for unknown formats)

2. A factory function `getDefaultFormatParams(formatName: string, context: { intensity: number; exerciseCount: number }): FormatParams` that:
   - Normalizes format name (lowercase, strip spaces)
   - Maps format name to the correct type with sensible defaults
   - Uses intensity to determine ladder direction (>=75% = descending per decision 13-07)
   - Uses exerciseCount for EMOM total minutes
   - Returns `{ type: 'standard' }` for unknown formats
   - Derives defaults from existing constants in `constants.ts` where available (AMRAP default 10min per decision 08-01, Tabata 20/10 per decision 13-07, EMOM 60s per decision 08-01)

3. A helper `formatParamsLabel(params: FormatParams): string` that returns a human-readable summary string (e.g., "AMRAP - 10 min", "EMOM - 60s / 5 min total", "Complex - 3 rondas").

Export all types and functions.
