2. Create `pdf-service.ts` with:

   a. **Singleton browser management:**
   ```typescript
   import puppeteer, { Browser } from 'puppeteer';

   let browserInstance: Browser | null = null;

   async function getBrowser(): Promise<Browser> {
     if (!browserInstance || !browserInstance.connected) {
       browserInstance = await puppeteer.launch({
         headless: true,
         args: ['--no-sandbox', '--disable-setuid-sandbox', '--disable-dev-shm-usage'],
       });
     }
     return browserInstance;
   }

   async function closeBrowser(): Promise<void> {
     if (browserInstance) {
       await browserInstance.close();
       browserInstance = null;
     }
   }
   ```

   b. **generatePdf function:**
   ```typescript
   async function generatePdf(html: string): Promise<Buffer> {
     const browser = await getBrowser();
     const page = await browser.newPage();
     try {
       await page.setContent(html, { waitUntil: 'networkidle0' });
       const pdf = await page.pdf({
         format: 'A4',
         printBackground: true,
         margin: { top: '10mm', right: '10mm', bottom: '10mm', left: '10mm' },
       });
       return Buffer.from(pdf);
     } finally {
       await page.close(); // CRITICAL: always close to prevent memory leaks
     }
   }
   ```

   c. **buildSessionHtml function:**
   Build an HTML string from session data (SessionDetail type from existing admin service). The template should be:
   - Clean, professional layout suitable for printing
   - Header: session week, day, level group, date
   - For each block:
     - Block header with colored left border (matching block role colors: INITIUM=light-blue, NUCLEUS=deep-purple, DEUTEROS=teal, ATHLOS/EPIKOS=amber)
     - Block metadata: role, format name, intensity%, exercise count
     - If formatParams exists and type is not 'standard': show format params summary (e.g., "AMRAP - 10 min", "EMOM - 60s / 5 min")
     - Exercise table with columns: #, Exercise Name, Contraction, Reps/Time, Rest, Notes
     - Exercises numbered sequentially within block
   - Footer: "El Templo - Sesion generada automaticamente"
   - Use inline CSS (no external stylesheets -- Puppeteer renders inline CSS best):
     - Font: Arial, sans-serif
     - Block cards with border-left matching block color
     - Exercise rows with alternating background (very subtle grey)
     - Compact but readable font sizes (11px body, 14px headers)
     - Page break avoidance within blocks (`break-inside: avoid` on block divs)

   d. **Type for session data input:**
   Define an interface `PdfSessionData` that matches what the existing `getSessionWithDetails` returns from admin service, OR import the existing type. Include: week, day, dayLabel, levelGroup, blocks array with exercises.

   e. **Helper: dayLabel function:**
   Map day number to Spanish day name (1 -> Lunes, 2 -> Martes, etc.) or use existing Spanish day constants if available.

   f. **Export:** `{ generatePdf, buildSessionHtml, closeBrowser, getBrowser }`
