1. Create `saved-blocks.ts` schema:
   ```typescript
   export const savedBlocks = mysqlTable('saved_blocks', {
     id: int('id').primaryKey().autoincrement(),
     name: varchar('name', { length: 150 }).notNull(),
     createdBy: int('created_by').notNull().references(() => users.id),
     sourceBlockId: int('source_block_id'), // nullable - original block may be deleted
     blockRole: varchar('block_role', { length: 20 }).notNull(),
     blockRoute: varchar('block_route', { length: 20 }).notNull(),
     formatName: varchar('format_name', { length: 50 }).notNull(),
     blockData: json('block_data').notNull(), // Full snapshot: exercises, prescriptions, format params
     createdAt: timestamp('created_at').defaultNow().notNull(),
   }, (table) => [
     index('saved_blocks_created_by_idx').on(table.createdBy),
   ]);
   ```

2. Export from `index.ts`.

3. Run migration: `ALTER TABLE` or `drizzle-kit push` to create the table.

4. In `edit-service.ts`, add methods:
   - `saveBlock(params: { blockId: number; name: string; userId: number })`:
     - Fetch the block with its exercises from session_blocks + session_prescriptions
     - Serialize the full block data as JSON: `{ role, route, formatName, formatParams, intensity, exercises: [{ exerciseId, exerciseName, reps, seconds, rest, notes, effort, dificultadLineal, sortOrder }] }`
     - INSERT into saved_blocks with name, createdBy, sourceBlockId, blockRole, blockRoute, formatName, blockData
     - Return the saved block row

   - `listSavedBlocks(userId: number)`:
     - SELECT from saved_blocks WHERE createdBy = userId ORDER BY createdAt DESC
     - Return array of saved blocks (id, name, blockRole, blockRoute, formatName, createdAt, and a preview of blockData exercise count)

   - `deleteSavedBlock(params: { savedBlockId: number; userId: number })`:
     - DELETE from saved_blocks WHERE id = savedBlockId AND createdBy = userId
     - Return success/not-found

5. In `routes.ts`, add three routes:
   - `POST /admin/saved-blocks` — body: `{ blockId: number, name: string }` — calls editService.saveBlock
   - `GET /admin/saved-blocks` — no params, uses request.user.userId — calls editService.listSavedBlocks
   - `DELETE /admin/saved-blocks/:id` — calls editService.deleteSavedBlock

   Add JSON schemas for all three routes following the existing pattern.
