Create `session-data-transformer.ts` — transforms the admin app's `SessionDetail` type into the PDF builder's `PdfDaySession` input type.

The key data mapping:

1. **SessionDetail → PdfDaySession:**
   ```typescript
   import type { SessionDetail, SessionBlock, SessionExercise } from 'src/types/session';
   import type { PdfDaySession, PdfBlockPage, PdfLevelBlock, PdfExercise } from './pdf-types';
   ```

2. **Day name mapping** (session.day is lowercase string like "lunes"):
   ```typescript
   const DAY_LABELS: Record<string, string> = {
     lunes: 'LUNES', martes: 'MARTES', miercoles: 'MIÉRCOLES',
     jueves: 'JUEVES', viernes: 'VIERNES', sabado: 'SÁBADO',
   };
   ```

3. **Block role to PDF page mapping.** The example PDF has a specific page structure:
   - INITIUM block → PdfBlockPage with `simpleExercises` (all levels share the same exercises)
   - NUCLEUS block → PdfBlockPage with `levelBlocks` (2x2 level grid)
   - DEUTEROS_1 + DEUTEROS_2 blocks → Combined into a single PdfBlockPage with two sets of `levelBlocks`
   - EPIKOS/ATHLOS block → PdfBlockPage with `levelBlocks`

4. **The current data model limitation:** Each `SessionDetail` is for ONE level group (e.g., "sigma"). The PDF example shows a 2x2 grid with ALL levels (α Δ Σ Ω) on one page. For the initial implementation, build the PDF with the single level's data and put it in the appropriate grid position. The full 4-level grid requires fetching sessions for all level groups of the same week+day, which can be a future enhancement.

   For now, the transformer should:
   - Place the session's exercises in the correct level position based on `session.levelGroup`
   - Leave other level boxes empty or with a placeholder like "—"

   ```typescript
   const LEVEL_MAP: Record<string, string> = {
     alfa_delta: 'alfa',  // alfa_delta maps to alfa position in the grid
     sigma: 'sigma',
     omega: 'omega',
   };
   ```

5. **Transform function:**
   ```typescript
   export function sessionToPdfDay(session: SessionDetail): PdfDaySession {
     const dayName = DAY_LABELS[session.day] || session.day.toUpperCase();
     const blocks: PdfBlockPage[] = [];

     // Group blocks by role
     const blocksByRole = new Map<string, SessionBlock[]>();
     for (const block of session.blocks) {
       const role = block.role;
       if (!blocksByRole.has(role)) blocksByRole.set(role, []);
       blocksByRole.get(role)!.push(block);
     }

     // Process in display order: INITIUM, NUCLEUS, DEUTEROS pair, EPIKOS/ATHLOS
     const roleOrder = ['INITIUM', 'NUCLEUS', 'DEUTEROS_1', 'ATHLOS', 'EPIKOS'];

     for (const role of roleOrder) {
       const roleBlocks = blocksByRole.get(role);
       if (!roleBlocks?.length) continue;

       const block = roleBlocks[0];

       if (role === 'INITIUM') {
         blocks.push({
           role: 'INITIUM',
           blockName: block.pattern || 'PYROS',
           formatName: block.formatName,
           simpleExercises: block.exercises.map(ex => ex.exerciseName),
         });
       } else if (role === 'DEUTEROS_1') {
         // Combine DEUTEROS_1 and DEUTEROS_2 into one page
         const deut2Blocks = blocksByRole.get('DEUTEROS_2');
         const deut2 = deut2Blocks?.[0];

         blocks.push({
           role: 'DEUTEROS I',
           formatName: block.formatName,
           levelBlocks: [blockToLevelBlock(block, session.levelGroup)],
         });
         if (deut2) {
           blocks.push({
             role: 'DEUTEROS II',
             formatName: deut2.formatName,
             levelBlocks: [blockToLevelBlock(deut2, session.levelGroup)],
           });
         }
       } else if (role === 'DEUTEROS_2') {
         continue; // Already handled with DEUTEROS_1
       } else {
         // NUCLEUS, EPIKOS, ATHLOS — standard level grid page
         blocks.push({
           role: role,
           formatName: block.formatName,
           levelBlocks: [blockToLevelBlock(block, session.levelGroup)],
         });
       }
     }

     return { dayName, week: session.week, blocks };
   }

   function blockToLevelBlock(block: SessionBlock, levelGroup: string): PdfLevelBlock {
     const level = LEVEL_MAP[levelGroup] || levelGroup;
     return {
       level,
       route: block.route,
       intensity: block.intensity,
       exercises: block.exercises.map(exerciseToPdf),
     };
   }

   function exerciseToPdf(ex: SessionExercise): PdfExercise {
     return {
       name: ex.exerciseName,
       contraction: ex.contraction,
       reps: ex.reps,
       seconds: ex.seconds,
       rest: ex.rest,
       notes: ex.notes,
     };
   }
   ```

6. **Week PDF helper** — fetches all sessions for the same week and combines:
   ```typescript
   export function sessionsToWeekPdf(sessions: SessionDetail[]): PdfDaySession[] {
     // Sort by day order
     const dayOrder = ['lunes', 'martes', 'miercoles', 'jueves', 'viernes', 'sabado'];
     return sessions
       .sort((a, b) => dayOrder.indexOf(a.day) - dayOrder.indexOf(b.day))
       .map(sessionToPdfDay);
   }
   ```

   async function onDownloadDayPdf() {
     if (!session.value) return;
     pdfDayLoading.value = true;
     try {
       const pdfDay = sessionToPdfDay(session.value);
       buildDayPdf(pdfDay);
     } catch (err) {
       $q.notify({ type: 'negative', message: 'Error generando PDF' });
       console.error('PDF generation error:', err);
     } finally {
       pdfDayLoading.value = false;
     }
   }

   async function onDownloadWeekPdf() {
     if (!session.value) return;
     pdfWeekLoading.value = true;
     try {
       // Fetch all approved sessions for this week
       const { sessions: weekSessions } = await sessionsApi.fetchSessions({
         week: session.value.week,
         status: 'approved',
       });
       // For each session, fetch full details
       const details = await Promise.all(
         weekSessions.map(s => sessionsApi.fetchSessionDetail(s.id))
       );
       const pdfDays = sessionsToWeekPdf(details);
       buildWeekPdf(pdfDays);
     } catch (err) {
       $q.notify({ type: 'negative', message: 'Error generando PDF de la semana' });
       console.error('Week PDF error:', err);
     } finally {
       pdfWeekLoading.value = false;
     }
   }
