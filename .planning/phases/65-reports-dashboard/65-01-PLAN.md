**service.ts** — `ReportsService` class with constructor DI pattern (`db`, `log`):

1. `getAccessLog(filters: AccessReportFilters): Promise<PaginatedResult<AccessReportRow>>` — Query attendance table joined with users, branches, schedules+activities. Filter by branchId, date range on `checkedInAt`, source enum, search on `CONCAT(firstName, ' ', lastName)` or DNI via LIKE. Order by `checkedInAt DESC`. Use `SQL_CALC_FOUND_ROWS` or separate COUNT query for total. Default page=1, limit=20. Format scheduleSlot as `"{dayLabel} {startTime} - {activityName}"` when scheduleId is not null, using DAY_LABELS mapping (Lun, Mar, Mie, Jue, Vie, Sab). When scheduleId is null, return null.

2. `getChargeHistory(filters: ChargeReportFilters): Promise<PaginatedResult<ChargeReportRow>>` — Query payments table joined with users (member), users (recorder), subscriptions, subscription_plans. Filter by branchId (via member's branchId), date range on `paymentDate`, paymentMethod enum, search on member name/DNI. Include ALL payments (both voided and non-voided — voided ones have voidedAt non-null). Order by `paymentDate DESC, createdAt DESC`. Default page=1, limit=20.

3. `getExpiringMemberships(filters: ExpiringReportFilters): Promise<ExpiringReportRow[]>` — Query subscriptions joined with users and subscription_plans. Filter: status IN ('active', 'paused') with endDate within `daysWindow` days from CURDATE(). If `includeExpired` is true (default), also include status='expired' subscriptions. Filter by branchId on subscription.branchId. Compute `daysRemaining = DATEDIFF(endDate, CURDATE())`. Order by daysRemaining ASC (most urgent first). No pagination — small result set.

4. `getInactiveMembers(filters: InactiveReportFilters): Promise<InactiveReportRow[]>` — Find users with active subscription (status IN ('active', 'paused')) whose last attendance record is older than `daysThreshold` days, OR who have no attendance records at all. Use a LEFT JOIN or subquery for MAX(checkedInAt). Compute `daysSinceCheckIn = DATEDIFF(CURDATE(), lastCheckIn)`. For members with no attendance at all, use their subscription startDate as reference and set lastCheckIn to null. Filter by branchId on subscription.branchId. Order by daysSinceCheckIn DESC (longest inactive first). No pagination.

5. `exportAccessLog(filters)`, `exportChargeHistory(filters)`, `exportExpiringMemberships(filters)`, `exportInactiveMembers(filters)` — Same queries as above but without pagination limits, returning all matching rows.
