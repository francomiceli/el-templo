  <action>
    Create an index.ts barrel export for each of the 11 modules that don't have one yet. Each barrel defines the module's public API — only export what other modules should be able to import.

    **For each module, read its files first** to determine what to export. Follow this pattern:
    - Routes plugin: always export (this is how the module registers with Fastify)
    - Service classes/functions: export if they contain business logic other modules may need
    - Types/interfaces: export as `export type` if they appear in service method signatures
    - Schemas (Zod/JSON Schema): generally do NOT export (route-internal validation)
    - Internal helpers: do NOT export

    **Convention per user decision:** Each barrel starts with a `// Module: {name}` comment header.

    **Specific guidance per module:**

    - **auth**: Export `authRoutes` from routes.ts. Do NOT export schemas (internal validation).
    - **sessions**: Export `sessionsPlugin` (the Fastify plugin from routes.ts), `SessionService` from service.ts, types from types.ts. The pipeline/, fallback/, trace/, validation/, validators/ subdirs are internal implementation.
    - **spom**: Export `spomPlugin` from routes.ts, `SpomService` from service.ts.
    - **progression**: Export `progressionPlugin` from routes.ts, `ProgressionService` from service.ts.
    - **journeys**: Export `journeyRoutes` from routes.ts, `JourneyService` from service.ts, types from types.ts, constants from constants.ts.
    - **blog**: Export `blogRoutes` from routes.ts, `BlogService` from service.ts. image-service.ts is internal.
    - **franchise**: Export `franchiseRoutes` from routes.ts, `FranchiseService` from service.ts. ai-agent-service is internal.
    - **gladius**: Export `gladiusRoutes` from routes.ts, `GladiusService` from service.ts.
    - **academy**: Export `academyRoutes` from routes.ts, `AcademyService` from service.ts.
    - **app-landing**: Export `appLandingRoutes` from routes.ts, `AppLandingService` from service.ts.
    - **shared**: Export everything (cross-cutting by definition): `errors.ts` exports, `training-constants.ts` exports, `video-url.ts` exports.

    **Important:** Read each module's actual source files to get the exact export names (class names, function names). Do not guess — the names above are approximate. For example, some modules may use `const xxxRoutes: FastifyPluginAsync` while others may export differently.

    **admin** already has index.ts — leave it as-is but verify it has `// Module: admin` header. If missing, add it.
