  <behavior>
    - award(): given valid userId + sourceType + referenceType + referenceId, creates ledger entry with amount from aura_config default, upserts balance atomically, returns the new balance
    - award() with explicit amount: overrides the config default
    - award() duplicate (same userId + sourceType + referenceType + referenceId): throws/rejects due to unique constraint
    - award() with optional description: stored in ledger entry
    - spend(): given userId + amount + description, creates negative ledger entry, decrements balance atomically, returns new balance
    - spend() with insufficient balance: throws error, no ledger entry created, balance unchanged
    - getBalance(): returns current balance for user (0 if no balance row exists)
    - getBalance() for non-existent user: returns 0
  </behavior>
  <action>
    **types.ts** — Create with `// Module: aura` header:
    ```typescript
    export interface AwardInput {
      userId: number;
      sourceType: string; // matches sourceTypeEnum values
      referenceType?: string;
      referenceId?: number;
      amount?: number; // override config default
      description?: string;
    }

    export interface SpendInput {
      userId: number;
      amount: number;
      description: string;
      referenceType?: string;
      referenceId?: number;
    }

    export interface AuraBalance {
      userId: number;
      balance: number;
    }
    ```

    **service.ts** — Create with `// Module: aura` header. AuraService is a class that receives the Drizzle DB instance in its constructor (dependency injection, not Fastify decorator — keeps it testable).

    Key implementation details:
    - `award()`: Use a MySQL transaction (`db.transaction(async (tx) => { ... })`). Inside: (1) if no explicit amount, query aura_config for default amount by sourceType, (2) insert into aura_transactions, (3) upsert aura_balances (INSERT ... ON DUPLICATE KEY UPDATE balance = balance + amount). Return new balance.
    - `spend()`: Use a transaction. Inside: (1) SELECT balance FROM aura_balances WHERE userId FOR UPDATE (row lock), (2) if balance < amount, throw InsufficientBalanceError, (3) insert negative amount into aura_transactions with sourceType='manual_adjustment', (4) UPDATE aura_balances SET balance = balance - amount. Return new balance.
    - `getBalance()`: Simple SELECT from aura_balances. Return 0 if no row.
    - Use Fastify's Pino logger (pass as optional constructor param) for logging transactions. Never console.log.
    - Error handling: Define `InsufficientBalanceError` extending Error. Use `catch (err: unknown)` with `instanceof` checks per project standards.

    **test** — Integration tests using createTestApp() from test helpers. Tests run against eltemplo_test database. Test each behavior listed above. Use beforeEach to clean aura_transactions, aura_balances, and aura_config tables. Seed aura_config with test values. Create a test user via registerUser helper to get a valid userId.
