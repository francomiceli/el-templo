## STRIDE Threat Register

| Threat ID | Category                          | Component                  | Disposition | Mitigation Plan                                                                                                                                                                                                                                                                               |

| T-132-13  | Information disclosure            | PII (name/phone) in CSV    | accept      | The CSV is built from data the server ALREADY authorized for this admin (gated by requireAdminAnalytics + scope in plan 132-02).
