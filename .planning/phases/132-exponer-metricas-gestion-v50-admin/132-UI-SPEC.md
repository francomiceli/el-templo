# Phase 132 — UI Design Contract

> Visual and interaction contract for exposing the 6 v5.0 management metrics in the admin Analytics panel + deleting deprecated screens. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Stack:** Quasar + Vue 3 (`el-templo-admin`). NOT React/Next/Vite-React → shadcn gate **not applicable** (no `components.json`; design system is Quasar + `quasar.variables.scss`). All visual/interaction decisions are **locked by Nacho** in `DECISIONES-VISUALIZACION.md` (D-01..D-21) and `132-CONTEXT.md` — this contract transcribes them, it does not re-litigate them.

## Layout & Panel Order (binding — D-07 / D-08)

Tabs in `AnaliticasPage.vue`, ordered by usage rhythm (left → right = daily → on-problem):

1. **Conversión** (Funnel) — first / leftmost, daily use. `icon="filter_alt"`
2. **Retención** (Churn + Renovación) — second band, weekly. `icon="replay"`
3. **Asistencia** (Frecuencia) — second band, weekly. `icon="event_available"`
4. **Ingresos** (Ticket + LTV) — last / rightmost, on-problem only. `icon="payments"`

Existing tabs that **remain**: Miembros (operational counts only, see D-21), Finanzas (D-21), Programas (D-21), Retención-por-ciclo (`RetencionTab.vue`, D-20). The 4 new tabs are added; deprecated content is removed (see Deprecation Map).

**Global filters** (D-09) — extend the existing filter row at the top of `AnaliticasPage.vue`:

| Filter               | Applies to                          | Control                                                                                           |
| -------------------- | ----------------------------------- | ------------------------------------------------------------------------------------------------- |
| Período (date range) | all 6                               | existing `q-btn-dropdown` date presets (reuse as-is)                                              |
| Sucursal             | all 6                               | existing `q-select` (reuse as-is)                                                                 |
| País (owner only)    | all 6                               | existing `q-select` gated by `isOwner` (reuse as-is)                                              |
| Plan                 | all 6                               | **new** `q-select`, `dense outlined emit-value map-options` — match existing filter styling       |
| Turno (mañana/tarde) | **only** Funnel + Frecuencia (D-10) | **new** `q-select`; hidden/disabled on tabs where data has no shift (Ticket/Churn/Renovación/LTV) |

Filter row spacing: `class="row items-center q-gutter-sm q-mb-md"` (existing convention).

## Per-Metric Visual Contract (binding — D-01..D-06)

### Conversión — Funnel de prueba (D-06)

- **Embudo visual clásico**: 3 escalones que se achican (reservó → asistió → compró). Render as stacked horizontal bars or proportional blocks, descending width.
- **Tasa estrella (grande):** `tasaCierre` (% que compra sobre los que asistieron) — `text-h3`/`text-h4`, visually dominant over the other two rates.
- Secondary rates (% asiste, punta-a-punta): smaller, `text-h6` + `text-caption` label.
- Cortes (D-11): general / sucursal / turno / turno+sucursal — achieved by **filtro turno + breakdown sucursal** (no 2D component). When turno filter is set, the sucursal breakdown is the effective 2D view.

### Retención — Churn + Renovación (D-02 / D-03)

- Churn + Renovación render in the **same block / card row** (two faces of one thing — D-03).
- **Churn titular:** ventana **15 días** as the headline number (`text-h4`); 5 and 10 días shown as smaller comparison readings (`text-caption` / secondary).
- **Both views:** período number **and** month-over-month curve (`Line` chart).
- **Desglose** por sucursal y plan: detail (`q-table` or expandable section).
- **Renovación "número vivo" note (D-03):** inline aclaración next to renovación — `text-caption text-grey-6`: "Número vivo: sube con el tiempo, no suma 100% con el churn (hay gente todavía en el margen)."

### Asistencia — Frecuencia (D-04)

- **Two pieces, equal weight:** (1) foto general en bandas (inactivo/bajo/medio/alto — `Doughnut` or banded bar) + (2) **lista accionable "enfriándose"** (`q-table`).
- **Lista "enfriándose" (`coolingDown[]`):** columns Nombre, Teléfono, banda actual ← banda previa, % variación. Row interactions (D-13):
  - **Nombre** = link/click → abre el perfil del miembro (navegación admin existente).
  - **Teléfono** = `tel:` link (clickable to call directly).
- **Export CSV (D-14):** "Exportar CSV" `q-btn` (`icon="download"`, `outline`) above the list — reuse the `downloadBlob` + `URL.createObjectURL` pattern from `TrialSessionsReport.vue`. Filename: `frecuencia-enfriandose-${YYYY-MM-DD}.csv`.
- **Alerta adopción check-in:** `q-banner` (warning tone) per sede with low QR adoption — "Adopción de check-in baja en {sede}: los datos de frecuencia de esta sede pueden no ser confiables."

### Ingresos — Ticket (D-01)

- **Titular doble lado a lado:** promedio general (`global`) **+** promedio a precio de lista (cohorte `listPrice`). Two `text-h4` side by side (`col-6` each).
- **% con descuento / % a $0:** shown **separated** (two distinct stats, never merged).
- **Desglose por plan / sucursal:** detail that opens (expandable / `q-expansion-item` or detail card — not always visible).
- **Currency isolation:** ARS and EUR rendered in separate blocks/cards. **Never sum currencies.**

### Ingresos — LTV (D-05)

- **Titular doble lado a lado:** meses de vida **+** $ por cliente.
- **Both month estimates:** `lifetimeHeadlineMonths` (simple) **and** `survivalMedianMonths` (supervivencia) — both shown, labeled distinctly.
- **Valor en plata:** `projected` **vs.** `observed` side by side, per currency. Null-safe (render "—" when `null`). **Never sum currencies.**

## Spacing Scale

Quasar spacing utilities (4px base — already multiples of 4). Use existing classes, do not introduce custom px.

| Token | Value | Quasar class                              | Usage                                                |
| ----- | ----- | ----------------------------------------- | ---------------------------------------------------- |
| xs    | 4px   | `q-pa-xs` / `q-mb-xs` / `q-gutter-xs`     | Inline gaps, KPI sub-label spacing                   |
| sm    | 8px   | `q-pa-sm` / `q-mb-sm` / `q-gutter-sm`     | Card section internal, filter row gutter             |
| md    | 16px  | `q-pa-md` / `q-mb-md` / `q-col-gutter-md` | Default card spacing, grid gutters, page padding     |
| lg    | 24px  | `q-pa-lg`                                 | Section padding                                      |
| xl    | 40px  | `q-pa-xl`                                 | Empty-state vertical padding (`text-center q-pa-xl`) |

Exceptions: Chart containers use fixed `height: 300px; position: relative` (existing convention in `FinanzasAvanzadasTab.vue`). Card pattern is always `<q-card flat bordered>` with `<q-card-section>`.

## Typography

Quasar type scale (Roboto). Use existing text classes — do not set raw font-size.

| Role                      | Class                 | Size      | Weight | Usage                                                                     |
| ------------------------- | --------------------- | --------- | ------ | ------------------------------------------------------------------------- |
| Display (headline metric) | `text-h3` / `text-h4` | 48 / 34px | 400    | Tasa estrella del funnel, titular doble de Ticket/LTV/Churn               |
| Heading                   | `text-h5` / `text-h6` | 24 / 20px | 400    | Page title ("Analiticas"), secondary rates                                |
| Subtitle (card title)     | `text-subtitle2`      | 14px      | 500    | Card section titles ("Caja vs Devengado por mes", "Bandas de frecuencia") |
| Body                      | `text-body2`          | 14px      | 400    | Dialog/explanatory copy                                                   |
| Label / caption           | `text-caption`        | 12px      | 400    | Metric labels, currency tags, "número vivo" note, check-in alert          |

Body line-height: Quasar default (~1.5). Heading line-height: Quasar default (~1.2). Semantic value coloring: `text-positive` (#3b7249) for good, `text-negative` (#b34a4a) for churn/bajas, neutral charcoal otherwise.

## Color

Source of truth: `src/css/quasar.variables.scss` + `src/utils/chart-colors.ts`. Warm palette, NO blue in brand chrome.

| Role                   | Value                                                         | Usage                                                                                                |
| ---------------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Dominant (60%)         | `#f2ede5` (Marble Cream — page bg) / white card surfaces      | `q-page`, `q-card` backgrounds                                                                       |
| Secondary (30%)        | `$secondary` Clay `#7d5d42` / charcoal text `$accent #3d3732` | Card borders (`bordered`), body text, chart secondary series                                         |
| Accent (10%)           | `$primary` Terracotta `#96593a`                               | Primary actions, active tab indicator, primary CTA buttons, headline KPI icons, primary chart series |
| Destructive / negative | `$negative` `#b34a4a` (`text-negative`)                       | Churn/bajas values, negative trends                                                                  |
| Positive               | `$positive` `#3b7249` (`text-positive`)                       | Renovación/altas values, positive trends, funnel "compró" step                                       |
| Warning                | `$warning` `#7d6520`                                          | Check-in low-adoption `q-banner`, premature churn windows (5/10d)                                    |

Accent (Terracotta `#96593a`) reserved for: active tab indicator, primary buttons (Exportar CSV uses `outline` accent), headline-metric icons, the dominant chart series. **Not** applied to every interactive element — secondary controls use Quasar default styling. Charts must pull from `COLORS`/`chartColors`, never inline ad-hoc hex.

## Copywriting Contract

All UI copy in **Spanish** (app convention). Match tone of existing tabs ("No hay datos para el periodo seleccionado").

| Element                         | Copy                                                                                                                        |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Primary CTA (Frecuencia)        | "Exportar CSV"                                                                                                              |
| Row action (Frecuencia)         | Nombre → abre perfil del miembro · Teléfono → llamar (link `tel:`)                                                          |
| Empty state (todas las tabs)    | "No hay datos para el periodo seleccionado"                                                                                 |
| Empty state (lista enfriándose) | "No hay miembros enfriándose en este periodo"                                                                               |
| Empty state (funnel)            | "No hay sesiones de prueba en el periodo seleccionado"                                                                      |
| Renovación "número vivo" note   | "Número vivo: sube con el tiempo, no suma 100% con el churn (hay gente todavía en el margen)."                              |
| Check-in adoption alert         | "Adopción de check-in baja en {sede}: los datos de frecuencia de esta sede pueden no ser confiables."                       |
| Currency tag                    | "(ARS)" / "(EUR)" as `text-caption text-grey-6` next to per-currency blocks                                                 |
| Error / load failure            | `$q.notify({ type: 'negative', message: 'Error al cargar las métricas' })` + skeleton fallback (`q-skeleton`) while loading |
| Export success                  | `$q.notify({ type: 'positive', message: 'Exportación completada', timeout: 1500 })`                                         |

**Destructive actions:** This phase deletes deprecated **code/screens** (D-15..D-19), not user data. No runtime destructive UI, no confirmation dialogs needed. The deletions are source-level (see map below) — they do not produce a user-facing destructive flow.
