Generate QR code PNG images using the `qrcode` npm package (or `qr-image`, whichever is simpler). Per D-03, these are raw PNG files -- no design, the designer will incorporate them into flyers.

Create a one-time generation script `el-templo-web/scripts/generate-qr.ts`:

```typescript
// Generate QR PNG images for promo codes
// Usage: npx tsx scripts/generate-qr.ts

import QRCode from "qrcode";
import { mkdirSync } from "fs";
import { join } from "path";

const OUTPUT_DIR = join(__dirname, "..", "public", "qr");
mkdirSync(OUTPUT_DIR, { recursive: true });

const codes = [
  { url: "https://eltemplo.org/qr/bcn", filename: "TEMPLOPASSBCN.png" },
  { url: "https://eltemplo.org/qr/aura-club", filename: "AURACLUB1.png" },
];

async function main() {
  for (const code of codes) {
    await QRCode.toFile(join(OUTPUT_DIR, code.filename), code.url, {
      width: 1024,
      margin: 2,
      color: { dark: "#2e2a26", light: "#ffffff" },
    });
    console.log(`Generated ${code.filename}`);
  }
}

main();
```

IMPORTANT: Before installing `qrcode`, check if it already exists in the project. If not, ASK the user before installing. As a fallback, use a Python-based approach with `qrcode` library or a system tool if available, to avoid adding a new npm dependency.

Alternative without npm dependency: use a simple inline approach with the `canvas` or `sharp` library if already installed, or use a bash command with `qrencode` CLI tool:

```bash
mkdir -p el-templo-web/public/qr
qrencode -o el-templo-web/public/qr/TEMPLOPASSBCN.png -s 10 -m 2 "https://eltemplo.org/qr/bcn"
qrencode -o el-templo-web/public/qr/AURACLUB1.png -s 10 -m 2 "https://eltemplo.org/qr/aura-club"
```

If `qrencode` is not available, use Python:

```bash
python3 -c "
import qrcode
for url, name in [('https://eltemplo.org/qr/bcn', 'TEMPLOPASSBCN'), ('https://eltemplo.org/qr/aura-club', 'AURACLUB1')]:
    img = qrcode.make(url)
    img.save(f'el-templo-web/public/qr/{name}.png')
    print(f'Generated {name}.png')
"
```

Try `qrencode` first (most likely available on Linux), then Python, then ask about npm package.

The QR images should encode the FULL redirect URLs (`https://eltemplo.org/qr/bcn` and `https://eltemplo.org/qr/aura-club`), NOT the final destination URLs. This way the QR always points to eltemplo.org which then redirects, allowing future redirect changes without regenerating QR codes.
