<objective>
Build the comparable-breakdowns engine (FUND-03) and the cohort range/bucket helpers (FUND-04 currency isolation + FUND-05 half-open [from,to) + weekly/monthly). The breakdowns engine COMPOSES the existing `applyScope` (security scope stays append-only and owned by scope.ts) and adds orthogonal grouping axes: branch, country, duration tier (via `deriveDurationTier`), and plan name grouped by `(name, country)`. Cohort helpers provide half-open range WHERE fragments and a selectable week/month bucket SQL expression, plus the per-currency `{ ARS, EUR }` accumulator contract that guarantees ARS/EUR are never summed.

Purpose: These are the reusable axis + cohort + currency primitives every block (starting with ticket in Plan 04, then phases 121-123) consumes so "open this metric by sucursal/pais/duracion/plan, side by side, per currency, over [from,to)" is one shared mechanism.
Output: two new utility modules + a real-MySQL integration test.
</objective>
