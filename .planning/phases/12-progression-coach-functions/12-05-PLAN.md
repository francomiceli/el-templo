  <what-built>
Complete Mi Camino (progression tracking) feature:
- Backend: GET /api/progression/stats and POST /api/progression/request-evaluation endpoints
- Database: evaluation_requests table for tracking requests
- Frontend: Mi Camino page with level display, training stats, RPE trend chart, evaluation request
- Navigation: Mi Camino link in drawer with eligibility badge
  </what-built>
  <how-to-verify>
1. **Start both servers:**
   ```bash
   cd el-templo-api && pnpm dev
   cd el-templo-app && pnpm dev
   ```

2. **Login as a member** who has completed some sessions with RPE ratings.

3. **Navigate to Mi Camino** via the drawer menu.

4. **Verify Level Display:**
   - Greek letter shows (alpha, Delta, Sigma, or Omega)
   - Level name shows below in uppercase
   - Both use brand styling (bronze + navy)

5. **Verify Training Stats:**
   - 4 cards in 2x2 grid
   - Shows: Total Sessions, Days Trained, This Week, Current Streak
   - Values match actual user history

6. **Verify RPE Trend Chart:**
   - Line chart renders with bronze line
   - Points are navy with bronze border
   - Y-axis shows 1-10 (RPE scale)
   - X-axis shows date labels
   - Average displayed below chart

7. **Verify Evaluation Request section:**
   - If avg RPE > 6: Shows "keep training" message
   - If avg RPE <= 6 (2 weeks): Shows "ready for evaluation" + button
   - If pending request exists: Shows "pending" status

8. **Test evaluation request (if eligible):**
   - Click "Solicitar Evaluacion" button
   - Confirm button shows loading state
   - After success, status changes to "Pendiente"
   - Refresh page - pending status persists

9. **Verify navigation badge:**
   - If eligible (and no pending request): Badge shows on Mi Camino icon
   - After submitting request: Badge disappears

10. **Test edge cases:**
    - New user with no sessions: Shows empty state with "Ir a Entrenar" button
    - Refresh page: Data loads correctly
    - Error state: (Manually stop API) shows retry button
  </how-to-verify>
