    The workflow should be structured with clear documentation about required secrets, since this will only work once the user completes Apple Developer account setup.

    ```yaml
    name: Build iOS Staging (TestFlight)

    # Manual trigger only — macOS runners are expensive
    # PREREQUISITES: Set up the following GitHub Secrets before first run:
    #   IOS_BUILD_CERTIFICATE_BASE64  — Distribution certificate (.p12) encoded as base64
    #   IOS_P12_PASSWORD              — Password for the .p12 certificate
    #   IOS_PROVISION_PROFILE_BASE64  — Provisioning profile (.mobileprovision) encoded as base64
    #   APPLE_API_KEY_ID              — App Store Connect API key ID
    #   APPLE_API_ISSUER_ID           — App Store Connect API issuer ID
    #   APPLE_API_KEY_BASE64          — App Store Connect API private key (.p8) encoded as base64
    on:
      workflow_dispatch:

    env:
      NODE_VERSION: '22'

    jobs:
      build:
        name: Build & Upload to TestFlight
        runs-on: macos-latest

        steps:
          - name: Checkout code
            uses: actions/checkout@v4

          - name: Setup pnpm
            uses: pnpm/action-setup@v4
            with:
              version: 10

          - name: Setup Node.js
            uses: actions/setup-node@v4
            with:
              node-version: ${{ env.NODE_VERSION }}

          - name: Install dependencies
            working-directory: el-templo-app
            run: pnpm install --frozen-lockfile

          - name: Build web assets for staging
            working-directory: el-templo-app
            run: pnpm run build
            env:
              VITE_API_URL: ${{ secrets.STAGING_VITE_API_URL }}
              VITE_APP_NAME: "El Templo (Staging)"
              VITE_SENTRY_DSN: ${{ secrets.STAGING_VITE_SENTRY_DSN }}

          - name: Sync Capacitor iOS
            working-directory: el-templo-app
            env:
              STAGING: 'true'
            run: npx cap sync ios

          - name: Install CocoaPods
            working-directory: el-templo-app/src-capacitor/ios/App
            run: pod install

          - name: Import signing certificate
            env:
              BUILD_CERTIFICATE_BASE64: ${{ secrets.IOS_BUILD_CERTIFICATE_BASE64 }}
              P12_PASSWORD: ${{ secrets.IOS_P12_PASSWORD }}
            run: |
              CERTIFICATE_PATH=$RUNNER_TEMP/build_certificate.p12
              KEYCHAIN_PATH=$RUNNER_TEMP/app-signing.keychain-db

              echo -n "$BUILD_CERTIFICATE_BASE64" | base64 --decode -o $CERTIFICATE_PATH

              security create-keychain -p "" $KEYCHAIN_PATH
              security set-keychain-settings -lut 21600 $KEYCHAIN_PATH
              security unlock-keychain -p "" $KEYCHAIN_PATH
              security import $CERTIFICATE_PATH -P "$P12_PASSWORD" -A -t cert -f pkcs12 -k $KEYCHAIN_PATH
              security list-keychain -d user -s $KEYCHAIN_PATH

          - name: Import provisioning profile
            env:
              BUILD_PROVISION_PROFILE_BASE64: ${{ secrets.IOS_PROVISION_PROFILE_BASE64 }}
            run: |
              PROFILE_PATH=$RUNNER_TEMP/build_pp.mobileprovision
              echo -n "$BUILD_PROVISION_PROFILE_BASE64" | base64 --decode -o $PROFILE_PATH
              mkdir -p ~/Library/MobileDevice/Provisioning\ Profiles
              cp $PROFILE_PATH ~/Library/MobileDevice/Provisioning\ Profiles

          - name: Build and archive
            working-directory: el-templo-app/src-capacitor/ios/App
            run: |
              xcodebuild -workspace App.xcworkspace \
                -scheme App \
                -sdk iphoneos \
                -configuration Release \
                -archivePath $RUNNER_TEMP/app.xcarchive \
                archive \
                CODE_SIGN_STYLE=Manual

          - name: Create ExportOptions.plist
            run: |
              cat > $RUNNER_TEMP/ExportOptions.plist << 'PLIST'
              <?xml version="1.0" encoding="UTF-8"?>
              <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
              <plist version="1.0">
              <dict>
                <key>method</key>
                <string>app-store</string>
                <key>destination</key>
                <string>upload</string>
              </dict>
              </plist>
              PLIST

          - name: Export IPA
            run: |
              xcodebuild -exportArchive \
                -archivePath $RUNNER_TEMP/app.xcarchive \
                -exportOptionsPlist $RUNNER_TEMP/ExportOptions.plist \
                -exportPath $RUNNER_TEMP/export

          - name: Upload to TestFlight
            env:
              APPLE_API_KEY_ID: ${{ secrets.APPLE_API_KEY_ID }}
              APPLE_API_ISSUER_ID: ${{ secrets.APPLE_API_ISSUER_ID }}
              APPLE_API_KEY_BASE64: ${{ secrets.APPLE_API_KEY_BASE64 }}
            run: |
              # Decode API key
              mkdir -p ~/private_keys
              echo -n "$APPLE_API_KEY_BASE64" | base64 --decode > ~/private_keys/AuthKey_${APPLE_API_KEY_ID}.p8

              # Upload to TestFlight via App Store Connect API
              xcrun notarytool submit --wait || true  # notarytool not needed for iOS
              xcrun altool --upload-app \
                -f $RUNNER_TEMP/export/*.ipa \
                --apiKey "$APPLE_API_KEY_ID" \
                --apiIssuer "$APPLE_API_ISSUER_ID" \
                -t ios

          - name: Upload IPA as artifact (backup)
            if: always()
            uses: actions/upload-artifact@v4
            with:
              name: staging-ipa-${{ github.sha }}
              path: ${{ runner.temp }}/export/*.ipa
              retention-days: 30
              if-no-files-found: ignore

          - name: Cleanup keychain
            if: always()
            run: |
              security delete-keychain $RUNNER_TEMP/app-signing.keychain-db 2>/dev/null || true
    ```

    IMPORTANT NOTES in the workflow comments:
    - This workflow requires Apple Developer Program membership ($99/year)
    - The user must register the staging app (com.eltemplo.app.staging) in App Store Connect
    - The user must create a distribution certificate and provisioning profile
    - All Apple-related secrets must be base64-encoded before adding to GitHub Secrets
    - macOS runners are ~10x more expensive than Linux — workflow_dispatch only

    The `altool` step may need adjustment once the user has actual Apple credentials. The research notes that Apple has partially deprecated `altool` in favor of the App Store Connect API. If `altool` doesn't work at runtime, the user can switch to the `apple-actions/upload-testflight-build` GitHub Action or use `xcrun notarytool`.
