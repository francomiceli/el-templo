<task type="auto">
  <name>Task 2: Create Android staging APK build workflow</name>
  <files>.github/workflows/build-android-staging.yml</files>
  <action>
    Create `.github/workflows/build-android-staging.yml`:

    ```yaml
    name: Build Android Staging APK

    on:
      workflow_dispatch:  # Manual trigger only (per user decision)

    env:
      NODE_VERSION: '22'

    jobs:
      build:
        name: Build Staging APK
        runs-on: ubuntu-latest

        defaults:
          run:
            working-directory: el-templo-app

        steps:
          - name: Checkout code
            uses: actions/checkout@v4

          - name: Setup pnpm
            uses: pnpm/action-setup@v4
            with:
              version: 10

          - name: Setup Node.js
            uses: actions/setup-node@v4
            with:
              node-version: ${{ env.NODE_VERSION }}
              cache: 'pnpm'
              cache-dependency-path: el-templo-app/pnpm-lock.yaml

          - name: Setup Java
            uses: actions/setup-java@v4
            with:
              distribution: 'zulu'
              java-version: '17'

          - name: Install dependencies
            run: pnpm install --frozen-lockfile

          - name: Build web assets for staging
            run: pnpm run build
            env:
              VITE_API_URL: ${{ secrets.STAGING_VITE_API_URL }}
              VITE_APP_NAME: "El Templo (Staging)"
              VITE_SENTRY_DSN: ${{ secrets.STAGING_VITE_SENTRY_DSN }}

          - name: Copy web assets to Capacitor
            env:
              STAGING: 'true'
            run: npx cap copy android

          - name: Build staging debug APK
            working-directory: el-templo-app/src-capacitor/android
            run: ./gradlew assembleStagingDebug

          - name: Upload APK artifact
            uses: actions/upload-artifact@v4
            with:
              name: staging-apk-${{ github.sha }}
              path: el-templo-app/src-capacitor/android/app/build/outputs/apk/staging/debug/app-staging-debug.apk
              retention-days: 30
    ```

    Notes:
    - Uses `workflow_dispatch` only (per user decision: mobile builds are manual trigger)
    - Uses debug APK (no keystore needed for sideloading, per research recommendation)
    - Sets `STAGING=true` for `cap copy` so capacitor.config.ts picks up staging appId
    - Builds `assembleStagingDebug` (staging product flavor + debug build type)
    - APK artifact path matches Gradle's output for staging flavor: `apk/staging/debug/app-staging-debug.apk`
    - Artifact includes commit SHA in name for traceability
    - 30-day retention for artifacts (per research recommendation)
    - No signing step needed for debug APKs
    - Java 17 required for Gradle/AGP 8.7.2

  </action>

    - Uses STAGING=true env var for cap copy
    - Builds assembleStagingDebug (not assembleDebug or assembleRelease)

    - Java 17 is set up for Gradle compatibility
