**Implement bookClass handler:**

```typescript
async function bookClass(
  db: DB,
  args: Record<string, unknown>,
  context?: { phone: string; clientState: ClientState },
): Promise<string>;
```

1. **State gate:** If clientState is not `active_member`, return a contextual message:
   - `lead`: "Para reservar clases necesitas ser miembro. ¿Te interesa una clase de prueba gratuita?"
   - `trial`: "Tu cuenta de prueba no permite reservar clases adicionales. ¿Querés info sobre membresías?"
   - `inactive_member`/`expired_member`: "Tu membresía no está activa. ¿Querés info sobre cómo reactivarla?"

2. **Resolve memberId** from phone: query `SELECT id FROM users WHERE phone = {context.phone} LIMIT 1`. If not found, return error.

3. **If `confirmed` is not true:** Query the schedule to build a confirmation summary, then return a formatted summary string. The AI will present this to the user and the confirmation/cancellation will flow through natural conversation (the AI calls book_class again with `confirmed: true` when the user confirms):

   ```
   📋 *Resumen de reserva*

   🏋️ {activityName}
   📅 {dayName} {date}
   🕐 {startTime} - {endTime}
   📍 {branchName}

   ¿Confirmo la reserva?
   ```

   Return this as the tool result so the AI presents it.

4. **If `confirmed` is true:** Call el-templo-api via HTTP:
   ```typescript
   const apiUrl = process.env.API_BASE_URL || "http://localhost:3000";
   const apiKey = process.env.BOT_API_KEY;
   const response = await fetch(`${apiUrl}/api/bot/scheduling/book-class`, {
     method: "POST",
     headers: {
       "Content-Type": "application/json",
       "x-bot-api-key": apiKey,
     },
     body: JSON.stringify({ memberId, scheduleId, date }),
   });
   ```

   - On 201: Return success message with booking details ("Reserva confirmada! Te esperamos el {day} a las {time} en {branch}. ¡Nos vemos!")
   - On 409 (already booked): Return "Ya tenés una reserva para esa clase. ¡Te esperamos!"
   - On 400 (class full): Query for alternative classes on the same day or same activity this week, return suggestion: "Esa clase está llena. Hay estas opciones: ..."
   - On other errors: Return "No pude completar la reserva. Intentá de nuevo en un momento."
