# Plan 114-06: Admin UI — Sesiones de Prueba tab in Reportes

<objective>
Ship the admin UI tab that lets staff browse, filter, inline-edit, and export the trial sessions report. Reuses the existing ReportesPage tab pattern (q-tabs + q-tab-panels). Self-contained component with own load lifecycle (mirror Plan 109-04 DeudasReport pattern per STATE.md).

Each row in the table = ONE lead (D-03/D-42). The "Gestiona" filter is OWNER-ONLY (D-44) — admin/gestion users do not see the filter at all, and the API ignores `gestionaUserId` if it sneaks through (Plan 05 T3 enforces server-side).
</objective>

    async function fetchTrialSessions(
      filters: TrialSessionsFiltersClient,
    ): Promise<{ rows: TrialSessionsRowClient[]; total: number; page: number; limit: number }> {
      const params = buildTrialSessionsParams(filters); // strips undefined
      const { data } = await api.get("/api/admin/reports/trial-sessions", { params });

    }

    function exportTrialSessionsUrl(filters: TrialSessionsFiltersClient): string {
      const usp = new URLSearchParams();
      // serialize: skip undefined, leadStatus as repeated keys
      for (const [k, v] of Object.entries(filters)) {
        if (v === undefined || v === null || v === "") continue;
        if (Array.isArray(v)) v.forEach((vv) => usp.append(k, String(vv)));
        else usp.append(k, String(v));
      }
      return `/api/admin/reports/trial-sessions/export?${usp.toString()}`;
    }
    ```

      let debounceTimer: ReturnType<typeof setTimeout> | null = null;
      function debouncedReload(): void {
        if (debounceTimer) clearTimeout(debounceTimer);
        debounceTimer = setTimeout(() => {
          void load();
        }, 300);
      }
      ```

      Wire it up via a deep watcher on filters:
      ```ts
      watch(filters, () => debouncedReload(), { deep: true });
      ```
