# Plan 114-03: Subscription conversion hook — auto-close lead + prefill plan name

<objective>
Extend the existing `recomputeUserStatus` helper in `subscriptions/service.ts` to also flip `lead_status='cerrado'` and conditionally prefill `lead_notes` with the plan name when a trial user converts (the same trigger that already sets `converted_at`). All mutations stay inside the existing single UPDATE statement to preserve atomicity with the parent transaction. No new entrypoints; no changes to any `recomputeUserStatus` caller.
</objective>

Locked decisions implemented here: D-32, D-33, D-34. **Critical:** D-33 mandates the hook MUST run inside the SAME db.transaction as the subscription create — `recomputeUserStatus` already satisfies this (see STATE.md Plan 103-04 evidence: it's called from inside `db.transaction(async (tx) => { ... })` at every callsite, lines 1180, 1508, 1574 (non-tx), 1673, 1751, 1971, 2424, 2767, 3059).

**Hook trigger semantics (current behavior, do NOT regress):**
The existing `recomputeUserStatus` sets `converted_at = CURRENT_TIMESTAMP` only when ALL of:

1. `users.converted_at IS NULL`
2. User has an active/paused sub with `start_date <= CURDATE() AND (end_date IS NULL OR end_date >= CURDATE())`
3. User has any `bookings` row with `is_trial=1`

Plan 114 reuses the SAME predicate to gate `lead_status='cerrado'` and `lead_notes` prefill — i.e. "this exact moment, the trial is being converted to a paying member."
</context>

<!-- Target shape: two additional CASE columns in the same UPDATE -->

The conversion predicate (let P = `converted_at IS NULL AND EXISTS active sub AND EXISTS is_trial booking`) is reused. We additionally need the PLAN NAME of the converting subscription — extracted via a correlated subquery on the active sub that is causing the conversion.

```sql
UPDATE users u
SET
  u.status = ... (unchanged) ...,
  u.converted_at = ... (unchanged) ...,
  u.lead_status = CASE
    WHEN P THEN 'cerrado'
    ELSE u.lead_status
  END,
  u.lead_notes = CASE
    WHEN P AND (u.lead_notes IS NULL OR u.lead_notes = '')
    THEN (
      SELECT sp.name
      FROM subscriptions s
      INNER JOIN subscription_plans sp ON sp.id = s.plan_id
      WHERE s.user_id = u.id
        AND s.subscription_status IN ('active','paused')
        AND s.start_date <= CURDATE()
        AND (s.end_date IS NULL OR s.end_date >= CURDATE())
      ORDER BY s.created_at DESC
      LIMIT 1
    )
    ELSE u.lead_notes
  END
WHERE u.id = ${userId}
```
