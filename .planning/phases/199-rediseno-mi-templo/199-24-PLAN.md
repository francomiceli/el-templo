<decisiones_de_diseno>

Lo marcado **[discreción]** queda anotado en el SUMMARY para el UAT humano abierto en 199-21.

- **Un solo reloj por novedad:** `dwellMs = novedadDwellMs(overflowPx)`. Sin desbordamiento = `NOVEDAD_ROTATE_MS` (4500, el valor de hoy). Con desbordamiento = `max(NOVEDAD_ROTATE_MS, 2 * MARQUEE_HOLD_MS + ceil(overflowPx / MARQUEE_PX_PER_S * 1000))`, con `MARQUEE_HOLD_MS = 900` y `MARQUEE_PX_PER_S = 45` **[discreción]**: a 4,5 s fijos, una novedad de 200 caracteres (máximo del API) correría a ~350 px/s, ilegible. El mismo `dwellMs` alimenta el `setTimeout` de la rotación, la `animation-duration` de la barra y la duración del desplazamiento: "sincronizado con la barra" se cumple por construcción.
- **Ciclo:** `cycle` (ref numérica) se incrementa cada vez que se arma el timer. La barra va `:key="cycle"` (antes `:key="current"`) y el desplazamiento se (re)crea en el mismo watch: barra, texto y timer arrancan juntos.
- **Pausa** (`!running`: dedo apoyado o página oculta): la barra queda congelada (`animation-play-state: paused`, sin `opacity` ni `scaleX(0)`) y el desplazamiento `.pause()`. Al reanudar, el timer se rearma con el `dwellMs` completo (comportamiento actual) → `cycle++` → ambos desde cero.
- **Desplazamiento:** Web Animations API sobre un `<span class="nov-item__line">` interno (`display: inline-block; white-space: nowrap`), con `marqueeKeyframes(overflowPx, dwellMs)` = `[{ transform: 'translateX(0)', offset: 0 }, { transform: 'translateX(0)', offset: h }, { transform: 'translateX(-Npx)', offset: 1 - h }, { transform: 'translateX(-Npx)', offset: 1 }]` con `h = MARQUEE_HOLD_MS / dwellMs`, `fill: 'forwards'`. Sin desbordamiento no se crea animación. El contenedor `.nov-item__text` pierde `text-overflow: ellipsis` (queda `overflow: hidden; white-space: nowrap`).
- **1 sola novedad** (no hay timer ni barra): si desborda, el desplazamiento se repite (`iterations: Infinity`) con el mismo `dwellMs` **[discreción]**; si entra, quieto.
- **Medición:** `overflowPx = marqueeOverflowPx(line.scrollWidth, text.clientWidth)` (0 si la diferencia es ≤ 1 px). Se mide en `nextTick` tras cada cambio de `currentItem`, en un `ResizeObserver` del stage y una vez en `document.fonts.ready` (Montserrat/Geologica cargan después del primer render). Si el valor cambia, se actualiza `dwellMs` y se rearma el timer. Con el `<Transition>` conviven dos `.nov-item` un instante: medir siempre el del `currentItem` (ref por función o `data-key`).
- **Reduced motion:** `reducedMotion` ref con `matchMedia('(prefers-reduced-motion: reduce)')` + listener de cambio (molde: `SponsorsCarousel.vue:298`). Con `reducedMotion`: no se mide ni se anima; clase `nov-card--reduced` en la raíz y estas reglas EXACTAS (sin ellas el `inline-block; nowrap` del span impide el wrap y el texto queda cortado sin "…"):
  - `.nov-card--reduced .nov-item__line { display: inline; white-space: normal; transform: none }`;
  - `.nov-card--reduced .nov-item__text { white-space: normal; display: -webkit-box; -webkit-box-orient: vertical; -webkit-line-clamp: 2; overflow: hidden }`;
  - `.nov-card--reduced .nov-card__stage { height: 82px }` = 2 líneas (2 × 14.5 × 1.38 ≈ 40) + meta (4 + 16) + padding (10 + 10) + 2 de margen. Alto FIJO (no `auto`): la card no cambia de alto al rotar entre una novedad corta y una larga; `.nov-item` sigue `position: absolute; inset: 0`.
  - La barra (si 2+) se muestra llena y estática (`transform: scaleX(1)`, sin animación); la rotación sigue con `NOVEDAD_ROTATE_MS`.
  - Una novedad que en 2 líneas no entra (el API admite 200 caracteres) cae al clamp con "…" como último recurso: documentarlo en el SUMMARY como límite conocido.
- **Barra nueva** (debajo de la novedad, dentro de la card, ancho del contenido con márgenes 16): riel `#e5dbcd` (token `line` de UI-SPEC) de 3 px, radio 999, y relleno `$primary` sólido con `transform-origin: left` animado `scaleX(0 → 1)` lineal durante `dwellMs`. Se borra `opacity: .55`, el `--paused` con `opacity: .2`, y el `display: none` del bloque reduced-motion. El stage + barra no deben cambiar el alto total de la card al rotar.
- **Accesibilidad:** el texto completo sigue en el DOM dentro de `.nov-item__line` (sin `aria-hidden`), así que lectores de pantalla y el nombre accesible del `role="button"` no dependen de la animación. La barra lleva `aria-hidden="true"` (decorativa: los puntos ya dicen "Ver novedad i de n").
- **Fuera de alcance:** la vista previa del admin (`NovedadPreview.vue`) sigue con elipsis; anotarlo como posible ajuste para otra tanda.
  </decisiones_de_diseno>
