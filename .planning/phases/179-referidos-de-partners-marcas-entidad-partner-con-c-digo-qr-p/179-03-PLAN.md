Reglas concretas: `code` `type: "string"`, `minLength: 3`, `maxLength: 24`, `pattern: "^[A-Za-z0-9 -]+$"` (el servidor normaliza después); `name` 1..120; `branchId` entero `minimum: 1`; `benefitType` `enum: ["discount_percent", "free_pass"]`; `benefitValue` entero `minimum: 0`, `maximum: 100`; `commissionType` `enum: ["none", "fixed"]`; `commissionValue` entero `minimum: 0`; `contactName`/`contactPhone`/`notes` opcionales con `maxLength`. Crear `admin-routes.ts` exportando `export const referralPartnersAdminRoutes: FastifyPluginAsync`. Un `fastify.addHook("onRequest", ...)` que: llama `await fastify.authenticate(request, reply)`, devuelve 403 con `{ error: "Acceso denegado", message: "No tenés permisos para gestionar partners" }` si `request.user.role` no está en `MEMBER_LIFECYCLE_ROLES`, y luego `await attachCountryScope(request, fastify.db)`.

Cuatro rutas, todas construyendo `ctx` con `assertTenant(request.scope, "referralPartners.<accion>")` y todas con `try { ... } catch (err: unknown) { handleServiceError(err, reply, request.log, "<acción>") }`:

- `GET /` → `service.listPartners(ctx, request.query)` con querystring `branchId?`, `isActive?`
- `GET /:id` → `service.getPartner(ctx, id)`
- `POST /` → `service.createPartner(ctx, request.body, request.user.userId)`, responde 201 con `{ id }`
- `PATCH /:id` → `service.updatePartner(ctx, id, request.body)`, responde 200

El servicio se instancia una vez arriba del plugin (`new PartnerReferralService(fastify.db, fastify.log)`), igual que hace `improvement-proposals`.

Exportar el plugin desde `index.ts` y registrarlo en `src/app.ts` con `prefix: "/api/admin/referral-partners"`, ubicado junto al bloque de `referralAdminRoutes` y con un comentario de una línea que explique qué expone y con qué set de roles.
