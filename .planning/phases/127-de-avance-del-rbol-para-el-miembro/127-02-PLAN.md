## Trust Boundaries

| Boundary                               | Description                                                                                                                   |
| -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| member app → GET /api/tree-progress/me | Authenticated read; the app sends only its bearer token, no user id. Access control enforced backend-side (127-01, T-127-01). |
| rendered values                        | The app trusts and displays server-computed percentages; it performs no privileged computation.                               |

## STRIDE Threat Register

| Threat ID | Category               | Component    | Disposition | Mitigation Plan                                                                                                                                                                                                |
| --------- | ---------------------- | ------------ | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-127-04  | Information Disclosure | client view  | mitigate    | The view only renders the authenticated member's own response; the request carries no target user id (the backend scopes to request.user.userId per T-127-01). No cross-member data reachable from the client. |
| T-127-05  | Tampering              | displayed %  | accept      | A malicious client could mutate displayed numbers in its own browser, but this only affects that user's own screen; the % is non-authoritative cosmetic data, no privilege attached.                           |
| T-127-SC  | Tampering              | npm installs | mitigate    | No new packages introduced (reuses Quasar, axios boot, Pinia already present). If an install becomes necessary, stop and request the Package Legitimacy Gate.                                                  |
