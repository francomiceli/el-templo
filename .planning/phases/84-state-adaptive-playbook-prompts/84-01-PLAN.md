**PB2.E2 — Escuchar + Identificar Objeción**
This is the objection-handling core. Must include four explicitly labeled objection branches with scripts:

- _Objeción precio_ ('me gustó pero es caro'):
  Script: 'Entiendo. ¿Sabés qué? Si te sirve, tenemos el plan [plan_básico] a [precio]. Muchos arrancan por ahí y después van subiendo. ¿Te copa?'

- _Objeción tiempo_ ('no sé si tengo tiempo'):
  Script: '¿Cuántos días por semana podrías venir? Con 2-3 ya se nota mucho. Y los horarios son flexibles: [horarios disponibles].'

- _Objeción identidad/miedo_ ('no sé si es para mí'):
  Script: 'Es normal sentir eso al principio. Todos los que hoy destraban los movimientos que se proponen arrancaron igual. ¿Qué fue lo que más te costó? Porque eso es exactamente lo que más rápido mejora.'

- _Objeción difusa_ ('lo pienso' / 'voy a ver'):
  Script: 'Dale, sin presión. Esta semana tenemos buenos horarios libres. Si te copa, me avisás y te reservo lugar.'

CRITICAL — TEAM-CORR-06: do NOT use 'grupo nuevo', 'arranca un grupo', 'cohorte nuevo', 'esta semana arranca' phrasing anywhere in PB2. Use generic timing like 'esta semana tenemos buenos horarios libres' or 'el [día] suele quedar tranqui'.

Closing rule paragraph: _Después de manejar CUALQUIERA de las cuatro objeciones_, transicionar a la propuesta con urgencia suave (Etapa 3) — no insistir, no descontar, no cerrar duro. The engine-level transition (refined in plan 84-03 Task 1) advances PB2.E2 → PB2.E3 on any substantive user reply (discoveryAnswered), so this prompt-level instruction must match: every objection branch ends by setting up the soft-urgency proposal in the next turn.

**PB2.E3 — Propuesta con Urgencia Suave**

3. _No mencionar 'grupo nuevo'._ (Repeat the TEAM-CORR-06 guard inline so any future edit catches it.)
