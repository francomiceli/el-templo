    **2. Create `el-templo-web/composables/useCountUp.ts`:**

    Extract the count-up animation logic from SectionCommunity into a reusable composable. Follow CLAUDE.md pattern: exposes `cleanup()`, no `onUnmounted` inside.

    ```typescript
    interface CountUpItem {
      value: number;
      prefix: string;
    }

    interface UseCountUpOptions {
      duration?: number; // ms, default 1500
      formatLocale?: string; // default 'es-AR'
    }

    interface UseCountUpReturn {
      displayValues: Ref<string[]>;
      trigger: () => void; // Call to start animation
      cleanup: () => void;
    }

    export function useCountUp(items: CountUpItem[], options?: UseCountUpOptions): UseCountUpReturn;
    ```

    Implementation:
    - Same rAF + easeOutCubic logic as SectionCommunity
    - `trigger()` starts the animation (idempotent — only runs once)
    - `prefers-reduced-motion` guard: instant display if reduced
    - `cleanup()` cancels any pending rAF
    - `displayValues` initialized to all "0"
    - Only runs on client (import.meta.client guard)
