  <action>
    **1. Install Resend:**
    ```bash
    cd el-templo-api && pnpm add resend
    ```

    **2. Create `el-templo-api/src/db/schema/franchise-applications.ts`:**

    Define `franchiseApplications` table with columns:
    - `id` — int, auto-increment, primary key
    - `nombre` — varchar(255), not null
    - `email` — varchar(255), not null
    - `telefono` — varchar(50), not null
    - `ciudadPais` — varchar(255), not null (maps to `ciudad_pais` column)
    - `modelo` — varchar(50), not null (enum-like: 'activa' | 'pasiva' | 'ambas')
    - `experiencia` — varchar(100), not null ('fitness' | 'negocios' | 'ambas' | 'sin_experiencia')
    - `capital` — varchar(100), not null ('menos_50k' | 'entre_50k_100k' | 'mas_100k')
    - `origen` — varchar(100), not null ('instagram' | 'web' | 'recomendacion' | 'google' | 'otro')
    - `mensaje` — text, nullable (max 500 chars validated in route, not DB)
    - `createdAt` — timestamp, default now
    - `status` — varchar(50), default 'new' (for Phase 38 management: new/contacted/negotiating/closed)

    **3. Update `el-templo-api/src/db/schema/index.ts`:**
    Add `export * from './franchise-applications';`

    **4. Create `el-templo-api/src/modules/franchise/service.ts`:**

    `FranchiseService` class:
    - Constructor takes `db` (Drizzle instance)
    - `submitApplication(data)`: inserts into `franchise_applications`, sends email via Resend, returns `{ success: true, whatsappUrl }`
    - Email sent to `FRANCHISE_NOTIFICATION_EMAIL` env var (or skip silently if no `RESEND_API_KEY`)
    - Email content: plain text with all application fields formatted clearly
    - WhatsApp URL: `https://wa.link/ci8dpl`
    - Use Fastify logger (passed in constructor) for logging. Never console.log.
    - Error handling: `catch (err: unknown)` with `instanceof Error` checks per CLAUDE.md

    **5. Create `el-templo-api/src/modules/franchise/routes.ts`:**

    Export `franchiseRoutes` as a Fastify plugin:
    - `POST /apply` — validates body schema (Fastify JSON Schema), calls `FranchiseService.submitApplication()`
    - Body JSON Schema validation for all required fields, email format, mensaje maxLength 500
    - Returns `{ message: string, whatsappUrl: string }` on success (201)
    - Returns `{ error: string, details?: unknown }` on validation failure (400)
    - This route is PUBLIC (no auth required) — investors are not logged in
    - Add CORS origin for `https://eltemplo.org` and `http://localhost:9200` to allow the web app to call this endpoint. Add these to the CORS origin list in app.ts.

    **6. Register routes in `el-templo-api/src/app.ts`:**
    - Import `franchiseRoutes` from `./modules/franchise/routes`
    - Register with prefix `/api/franchise`

    **7. Update `el-templo-api/.env.example`:**
    Add:
    ```
    # Resend (Email notifications)
    RESEND_API_KEY=re_xxxxxxxx
    FRANCHISE_NOTIFICATION_EMAIL=ignacio@eltemplo.org
    ```

    **8. Run drizzle-kit to generate migration:**
    ```bash
    cd el-templo-api && pnpm db:generate
    ```
    Then push schema to dev DB:
    ```bash
    cd el-templo-api && pnpm db:push
    ```
