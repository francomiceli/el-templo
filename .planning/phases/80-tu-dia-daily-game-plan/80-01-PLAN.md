    2. In `routes.ts`, add `GET /progression/weekly-summary` endpoint:
       - Calculate current week boundaries: Monday 00:00 to Sunday 23:59 (per D-16).
         Use this logic to find current Monday:
         ```typescript
         const now = new Date();
         const dayOfWeek = now.getDay(); // 0=Sun, 1=Mon...
         const diffToMonday = dayOfWeek === 0 ? -6 : 1 - dayOfWeek;
         const monday = new Date(now);
         monday.setDate(now.getDate() + diffToMonday);
         const weekStartStr = monday.toISOString().split('T')[0];
         // Sunday = monday + 6 days
         const sunday = new Date(monday);
         sunday.setDate(monday.getDate() + 6);
         const weekEndStr = sunday.toISOString().split('T')[0];
         ```
       - Query completed_sessions for userId WHERE date >= weekStartStr AND date <= weekEndStr:
         - COUNT(*) as sessionsCompleted
         - SUM of duration in minutes (calculate from startedAt/completedAt difference, same pattern as existing todaySession durationMinutes in /stats)
         - AVG(rpe) WHERE rpe IS NOT NULL, cast to DECIMAL(3,1)
       - Query active subscription for the user to get classesPerWeek as sessionBudget:
         ```typescript
         const [sub] = await fastify.db
           .select({
             classesPerWeek: schema.subscriptionPlans.classesPerWeek,
           })
           .from(schema.subscriptions)
           .innerJoin(schema.subscriptionPlans, eq(schema.subscriptions.planId, schema.subscriptionPlans.id))
           .where(and(
             eq(schema.subscriptions.userId, userId),
             eq(schema.subscriptions.status, 'active'),
           ))
           .limit(1);
         ```
       - Return the response object.

    NOTE: Import `subscriptions` and `subscriptionPlans` from schema. The `subscriptions` table has `userId`, `planId`, `status`. The `subscriptionPlans` table has `classesPerWeek`.
