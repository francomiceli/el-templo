# Phase 80 — UI Design Contract

> Visual and interaction contract for the "Tu Dia" daily game plan — reorganizing Mi Camino into a personalized daily briefing with segment-driven cards, enhanced session CTA, weekly progress, and post-session RPE messages. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property          | Value                                                       |
| ----------------- | ----------------------------------------------------------- |
| Tool              | none (Quasar + SCSS brand tokens)                           |
| Preset            | not applicable                                              |
| Component library | Quasar 2 (q-card, q-btn, q-icon, q-linear-progress, q-page) |
| Icon library      | Material Icons (Quasar default)                             |
| Heading font      | Montserrat (700) via @fontsource                            |
| Body font         | Geologica (400) via @fontsource                             |

**Source:** Detected from `el-templo-app/src/css/app.scss` and `quasar.variables.scss`. Consistent with Phase 78 UI-SPEC.

**Visual context:** Phase 80 operates in the **light theme** (cream backgrounds, terracotta accents) — the standard in-app visual language. Unlike Phase 78 (onboarding quiz) which used the dark atmospheric LoginPage world, Tu Dia is part of the main app shell with bottom tab navigation.

**Focal point:** Primary focal point for most segments is the Session CTA card — largest interactive surface, highest-contrast arrow circle, first daily action item.

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage                                                          |
| ----- | ----- | -------------------------------------------------------------- |
| xs    | 4px   | Icon-text gaps, inline spacing, summary item gaps              |
| sm    | 8px   | Compact element gaps, stat card label margin                   |
| md    | 16px  | Default card padding, vertical gap between cards, page padding |
| lg    | 24px  | Section padding, card-section internal padding                 |
| xl    | 32px  | Not used in this phase                                         |
| 2xl   | 48px  | Not used in this phase                                         |
| 3xl   | 64px  | Not used in this phase                                         |

Exceptions:

| Value | Justification                                                                                                                                                                                                                                                            |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 12px  | Intra-card vertical rhythm between sub-elements — tighter than md (16px) but looser than sm (8px). Established pattern from GeneralContent.vue. Used for: progress bar margin-top below title, week label margin-top, RPE message margin-top, RPE message padding-block. |
| 12px  | Card border-radius (established pattern from GeneralContent.vue)                                                                                                                                                                                                         |
| 36px  | CTA arrow circle diameter (established pattern from GeneralContent.vue)                                                                                                                                                                                                  |

  |

Scroll behavior: Standard vertical scroll. No sticky headers. Page scrolls naturally with all cards in a single column. Bottom tab bar remains fixed (Quasar layout handles this).
