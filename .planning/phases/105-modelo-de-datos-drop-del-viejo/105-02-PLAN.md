Public method: `async applyDelta(tx, transaction, links, sign): Promise<void>`. Where:

- `tx` is the Drizzle transaction handle from `db.transaction(async (tx) => ...)`. Type it as `Parameters<DbInstance["transaction"]>[0] extends (tx: infer T) => any ? T : never` OR import the helper type from `drizzle-orm/mysql2` if cleaner.
- `transaction: FinancialTransactionRow` — the just-inserted ledger row (memberId, direction, currency are read off it).
- `links: TransactionLinkRow[]` — the just-inserted links.
- `sign: 1 | -1` — `+1` for create (apply effect), `-1` for void (reverse it).

Loop logic (per PATTERNS.md "balance-service.ts" + D-06/D-07/D-08):

- For each link, **skip** if `link.targetKind === 'transaction'` (transaction-to-transaction links don't move balances cache; only `subscription` and `debt_balance` are cacheable per balances enum).
- Compute `delta`. **Sign convention** (validated by tests): a `plan_charge inflow` of `allocatedAmount=A` against a subscription whose plan price was `P` should leave `balances.amount = P - A` (member still owes `P - A`). The cleanest way: `balances.amount` represents OUTSTANDING; `inflow` (member paid) DECREMENTS outstanding; `outflow` (refund) INCREMENTS outstanding.
- BUT SPEC §8 example says: `plan_charge` 90k against subscription `pricePaid=100k` → `balances.amount = 10000`. This means the `plan_charge` itself materializes the unpaid REMAINDER — i.e. the link's `allocatedAmount` is what was paid; the residual `(price - allocatedAmount)` becomes the balance. **That residual logic is NOT BalanceService's job — it's the caller's**. BalanceService applies the link as given. So the actual sign logic is simpler:
  - **`delta = sign * (direction === 'outflow' ? +allocatedAmount : -allocatedAmount)`**
  - For `plan_charge inflow` of `allocatedAmount = 90k` → delta = -90000. The caller (subscriptions service) is responsible for ALSO inserting a "residual link" or for choosing `allocatedAmount = priceTotal` and a separate `inflow link` of the cash received. **For Phase 105 we don't need to solve that**: the caller pattern is `transactionService.create({kind:'plan_charge', direction:'inflow', amount: pricePaid, links:[{...allocatedAmount: pricePaid}]})` (D-02), so amount === allocated, and balance moves by `-pricePaid`.
  - **The SPEC §8 test must be re-interpreted to match this model.** See Task 2 test cases for the exact expected numbers.
- Per link execute (raw SQL upsert; D-06):
  ```typescript

        ON DUPLICATE KEY UPDATE amount = amount + VALUES(amount), last_recomputed_at = NOW()`,
  ```

- D-08: `amount` can go negative — supported natively by signed `int`.

Implementation order (per PATTERNS.md "transaction-service.ts" + SPEC §7):

```typescript
return await this.db.transaction(async (tx) => {
  // 1. Validate invariants BEFORE any write.
  //    1a. Σ allocated_amount === amount (only when links non-empty).
  if (input.links.length > 0) {
    const sum = input.links.reduce((acc, l) => acc + l.allocatedAmount, 0);
    if (sum !== input.amount) {
      throw new BadRequestError(
        "La suma de los montos asignados no coincide con el monto de la transacción",
      );
    }
  } else if (input.kind !== "advance_payment" && input.kind !== "adjustment") {
    throw new BadRequestError(
      `La transacción de tipo '${input.kind}' requiere al menos un link`,
    );
  }

  //    1b. Member exists (FK probe via users).
  const memberExists = await tx
    .select({ id: users.id })
    .from(users)
    .where(eq(users.id, input.memberId))
    .limit(1);
  if (memberExists.length === 0)
    throw new NotFoundError("Miembro no encontrado");

  //    1c. Branch exists.
  // (similar select against branches table)

  //    1d. For each link, probe target_id exists in the matching table.
  for (const link of input.links) {
    let exists: { id: number }[];
    switch (link.targetKind) {
      case "subscription":
        exists = await tx
          .select({ id: subscriptions.id })
          .from(subscriptions)
          .where(eq(subscriptions.id, link.targetId))
          .limit(1);
        break;
      case "debt_balance":
        exists = await tx
          .select({ id: balances.id })
          .from(balances)
          .where(eq(balances.id, link.targetId))
          .limit(1);
        break;
      case "transaction":
        exists = await tx
          .select({ id: financialTransactions.id })
          .from(financialTransactions)
          .where(eq(financialTransactions.id, link.targetId))
          .limit(1);
        break;
      default:
        throw new BadRequestError(
          `target_kind desconocido: ${String(link.targetKind)}`,
        );
    }
    if (exists.length === 0) {
      throw new NotFoundError(
        `Concepto enlazado no existe: ${link.targetKind} ${link.targetId}`,
      );
    }
  }

  // 2. INSERT financial_transactions.
  const inserted = await tx.insert(financialTransactions).values({
    memberId: input.memberId,
    kind: input.kind,
    direction: input.direction,
    amount: input.amount,
    currency: input.currency ?? "ARS",
    paymentMethod: input.paymentMethod,
    transactionDate: input.transactionDate,
    effectiveDate: input.effectiveDate,
    branchId: input.branchId,
    recordedBy,
    notes: input.notes ?? null,
  });
  const transactionId = Number(inserted[0].insertId);

  // 3. INSERT transaction_links (UNIQUE constraint catches dup target tuples → MySQL ER_DUP_ENTRY).
  if (input.links.length > 0) {
    await tx.insert(transactionLinks).values(
      input.links.map((l) => ({
        transactionId,
        targetKind: l.targetKind,
        targetId: l.targetId,
        allocatedAmount: l.allocatedAmount,
      })),
    );
  }

  // 4. Re-read the ledger row + links for the full detail (and for balanceService).
  const [txRow] = await tx
    .select()
    .from(financialTransactions)
    .where(eq(financialTransactions.id, transactionId));
  const linkRows = await tx
    .select()
    .from(transactionLinks)
    .where(eq(transactionLinks.transactionId, transactionId));

  // 5. Apply cache delta in the SAME tx.
  await this.balanceService.applyDelta(tx, txRow, linkRows, +1);

  this.log.info(
    {
      transactionId,
      memberId: input.memberId,
      kind: input.kind,
      amount: input.amount,
      recordedBy,
      linkCount: linkRows.length,
    },
    "Financial transaction created",
  );

  return { ...txRow, links: linkRows };
});
```

```typescript
return await this.db.transaction(async (tx) => {
  const [existing] = await tx
    .select()
    .from(financialTransactions)
    .where(eq(financialTransactions.id, id));
  if (!existing) throw new NotFoundError("Transacción no encontrada");
  if (existing.voidedAt !== null)

  await tx
    .update(financialTransactions)
    .set({ voidedAt: new Date(), voidedBy, voidReason: input.reason })

  const linkRows = await tx
    .select()
    .from(transactionLinks)
    .where(eq(transactionLinks.transactionId, id));

  const [updatedRow] = await tx
    .select()
    .from(financialTransactions)
    .where(eq(financialTransactions.id, id));
  this.log.info(
    { transactionId: id, voidedBy, reason: input.reason },
    "Financial transaction voided",
  );
  return { ...updatedRow, links: linkRows };
});
```
