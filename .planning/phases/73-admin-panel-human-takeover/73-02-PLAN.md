  <action>
    Add three new methods to the existing useWhatsappApi composable, following the same pattern as getConversation (loading/error/try-catch-finally):

    **sendMessage(conversationId: number, content: string):**
    - POST to `/admin/whatsapp/conversations/${conversationId}/send` with body `{ content }`
    - Returns the MessageRecord from the response
    - Error message: 'Error enviando mensaje'

    **takeover(conversationId: number):**
    - PUT to `/admin/whatsapp/conversations/${conversationId}/takeover`
    - Returns the updated ConversationRecord from the response
    - Error message: 'Error tomando control'

    **resumeBot(conversationId: number):**
    - PUT to `/admin/whatsapp/conversations/${conversationId}/resume`
    - Returns the updated ConversationRecord from the response
    - Error message: 'Error devolviendo al bot'

    Add a separate `sending` ref (ref(false)) so message send loading state does not conflict with the main `loading` ref used for data fetching. The takeover/resume actions can reuse the main `loading` ref.

    Export all three new methods plus the `sending` ref from the composable return object. Also export in cleanup: `sending.value = false`.
