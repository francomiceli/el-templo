Define the shared expiry-cohort engine (the heart of both Block 1 churn and Block 2 renovacion) and the wire contracts both services will implement against. This is the contract-first plan: it ships pure SQL-fragment / predicate helpers plus the ChurnAnalytics / RenewalAnalytics types, so Plans 02 and 03 build against fixed interfaces with no codebase scavenging.

Output: expiry-cohort.ts (new shared primitive in the Phase 120 foundation style), new wire types in types.ts, and a primitive integration test.
</objective>
