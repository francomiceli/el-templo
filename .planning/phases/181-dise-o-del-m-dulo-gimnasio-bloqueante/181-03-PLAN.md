## Trust Boundaries

| Boundary                                   | Description                                                                          |
| ------------------------------------------ | ------------------------------------------------------------------------------------ |
| outbox del cliente → endpoint de sync      | El cliente manda `client_set_uid` y `recorded_at`: los dos son entrada no confiable  |
| dos dispositivos del mismo alumno → sesión | Escrituras concurrentes sobre la misma sesión, potencialmente con relojes distintos  |
| edición del profe → récords del alumno     | Escritura concurrente con el sync, sobre la fila derivada que el alumno está mirando |

| T-181-11  | Tampering   | `recorded_at` del cliente (reloj no confiable) | mitigate    | Doble sello `recorded_at` (cliente) + `synced_at` (servidor); fuera de ventana se marca, no se rechaza; el orden de merge es auditable     |
