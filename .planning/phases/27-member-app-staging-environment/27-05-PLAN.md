<task type="checkpoint:human-action" gate="blocking">
  <name>Task 1: Server and DNS setup</name>
  <action>
    The following steps require manual action via SSH to the EC2 server and DNS management:

    **1. DNS Records (in your DNS provider for eltemplo.org):**
    Add A records pointing to your EC2 public IP:
    - `api-staging.eltemplo.org` -> EC2 IP
    - `app-staging.eltemplo.org` -> EC2 IP
    - `admin-staging.eltemplo.org` -> EC2 IP

    **2. Server directories (SSH to EC2):**
    ```bash
    sudo mkdir -p /opt/el-templo-staging/{api,app,admin}
    sudo chown -R $USER:$USER /opt/el-templo-staging
    ```

    **3. MySQL staging database:**
    ```bash
    mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS eltemplo_staging;"
    mysql -u root -p -e "GRANT ALL ON eltemplo_staging.* TO 'eltemplo'@'localhost';"
    ```
    (Or create a separate `eltemplo_staging` user if preferred.)

    **4. Nginx config symlinks:**
    Copy the 3 staging Nginx configs from `deploy/nginx/` to the server:
    ```bash
    sudo cp api-staging.eltemplo.org /etc/nginx/sites-available/
    sudo cp app-staging.eltemplo.org /etc/nginx/sites-available/
    sudo cp admin-staging.eltemplo.org /etc/nginx/sites-available/
    sudo ln -sf /etc/nginx/sites-available/api-staging.eltemplo.org /etc/nginx/sites-enabled/
    sudo ln -sf /etc/nginx/sites-available/app-staging.eltemplo.org /etc/nginx/sites-enabled/
    sudo ln -sf /etc/nginx/sites-available/admin-staging.eltemplo.org /etc/nginx/sites-enabled/
    sudo nginx -t && sudo systemctl reload nginx
    ```

    **5. SSL certificates (after DNS propagation):**
    ```bash
    sudo certbot --nginx -d api-staging.eltemplo.org -d app-staging.eltemplo.org -d admin-staging.eltemplo.org
    ```

    **6. Weekly cron for staging reset:**
    Copy `deploy/staging/reset-staging.sh` to `/opt/el-templo-staging/` and configure:
    ```bash
    sudo cp reset-staging.sh /opt/el-templo-staging/
    sudo chmod +x /opt/el-templo-staging/reset-staging.sh
    # Add to crontab:
    # 0 4 * * 0 STAGING_DB_USER=eltemplo STAGING_DB_PASSWORD=<password> /opt/el-templo-staging/reset-staging.sh >> /var/log/staging-reset.log 2>&1
    ```

    **7. GitHub Secrets (in repo Settings > Secrets and variables > Actions):**
    Add these repository secrets:
    ```
    STAGING_API_DEPLOY_PATH=/opt/el-templo-staging/api
    STAGING_APP_DEPLOY_PATH=/opt/el-templo-staging/app
    STAGING_ADMIN_DEPLOY_PATH=/opt/el-templo-staging/admin
    STAGING_DB_HOST=localhost
    STAGING_DB_PORT=3306
    STAGING_DB_USER=eltemplo
    STAGING_DB_PASSWORD=<your staging db password>
    STAGING_DB_NAME=eltemplo_staging
    STAGING_JWT_SECRET=<generate a new random secret>
    STAGING_API_PORT=4001
    STAGING_VITE_API_URL=https://api-staging.eltemplo.org/api
    STAGING_FRONTEND_URL=https://app-staging.eltemplo.org
    STAGING_ADMIN_URL=https://admin-staging.eltemplo.org
    STAGING_SENTRY_DSN=<staging Sentry project DSN>
    STAGING_VITE_SENTRY_DSN=<staging Sentry Vue project DSN>
    STAGING_SEED_PASSWORD=<password for test users>
    ```

    **8. Create staging branch and trigger first deploy:**
    ```bash
    git checkout -b staging
    git push -u origin staging
    ```
    This should trigger the staging deploy workflow.

  </action>
