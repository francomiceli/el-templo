<objective>
Move all admin composable instantiations from inside function bodies to setup level.

Purpose: Composables instantiated inside functions create a new reactive instance on every call (new ref(), new error state), wasting memory and breaking the singleton-per-component pattern. Moving to setup level ensures one instance per component lifecycle.

Output: 9 admin files refactored with all composable calls at setup level.
</objective>
