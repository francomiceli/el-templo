<!-- Drizzle typed partial pattern -->
The pattern to replace `Record<string, unknown>` is:

```typescript
// Instead of:
const updateData: Record<string, unknown> = {};
// Use:
const updateData: Partial<typeof schema.tableName.$inferInsert> = {};
```

This gives full type safety on the `.set(updateData)` call — misspelled columns or wrong types are caught at compile time.

In `payments/service.ts`, replace the getMorososCount method (lines 532-535):

OLD:

```typescript
async getMorososCount(branchId?: number): Promise<number> {

}
```

NEW: Write a dedicated COUNT query that reuses the same WHERE/HAVING conditions as getOverdueMembers but only returns the count. This avoids fetching all member data + joins just to count rows.

```typescript
async getMorososCount(branchId?: number): Promise<number> {
  const conditions: ReturnType<typeof eq>[] = [
    sql`${schema.subscriptions.endDate} < CURDATE()`,
  ];

  if (branchId !== undefined) {
    conditions.push(eq(schema.subscriptions.branchId, branchId));
  }

  const [result] = await this.db
    .select({ count: sql<number>`COUNT(*)` })
    .from(schema.subscriptions)
    .innerJoin(schema.users, eq(schema.users.id, schema.subscriptions.userId))
    .innerJoin(
      schema.branches,
      eq(schema.branches.id, schema.subscriptions.branchId),
    )
    .innerJoin(
      schema.subscriptionPlans,
      eq(schema.subscriptionPlans.id, schema.subscriptions.planId),
    )
    .where(and(...conditions))
    .having(
      sql`COALESCE((
        SELECT SUM(p2.amount) FROM payments p2
        WHERE p2.subscription_id = ${schema.subscriptions.id}
        AND p2.voided_at IS NULL
      ), 0) < ${schema.subscriptions.pricePaid}`,
    );

  return Number(result?.count ?? 0);
}
```

Note: The joins to users, branches, and subscriptionPlans can be removed from the count query since we only need the count, not the member data. However, keep the subscriptions table + its conditions. Actually, the HAVING clause references subscriptions columns, and the WHERE references subscriptions — the other joins (users, branches, subscriptionPlans) are NOT needed for the count. Remove them:

