## Deviations from Plan

### Rule 1 — Auto-fix: T1 + T4 regex `\w+` → `\S+`

**Found during:** Task 2 GREEN verify gates (`pnpm test --run test/v5-3-3-date-grounding.test.ts` after directive landed).
**Issue:** CONTEXT.md D-04 #1 + #4 specified the directive regex as `\(\w+\)`, but JavaScript `\w` is ASCII-only (`[A-Za-z0-9_]`) and does NOT match `é` in `miércoles` — the worst-case Spanish day name CONTEXT.md D-03 explicitly locks for the frozen fixture. Without the fix, T1 fails post-GREEN against the frozen miércoles render even with the directive correctly inserted.
**Fix:** Substituted `\w+` with `\S+` (any non-whitespace token) in both T1 (line 56) and T4 (line 137) regexes. Preserves the structural lock semantics (capture-group for arbitrary day-name token) while actually matching the worst-case day name CONTEXT.md locks.
**Commit:** `c3c74909` (bundled with GREEN).

## Lessons / Observations

- **Snapshot regen executed within 10-minute budget** per execute-prompt pre-flag (regen + measurement < 30s total). Phase 96 5.5h timeout pattern not repeated.
- **`Intl.DateTimeFormat` Argentine path is hermetic** — no DST handling logic needed; future-proofed if Argentina ever resumes DST. The `en-CA` locale produces ISO `YYYY-MM-DD` directly with no string manipulation; the `en-US` `weekday: 'short'` + lookup-object pattern is safer than `weekday: 'long'` in `es-AR` (which can render `Miércoles` capitalized vs `miércoles` lowercase depending on Node.js ICU build).
- **`DAY_NAMES` kept file-private** (single consumer; export deferred per CONTEXT.md `<deferred>`).
- **The frozen-fixture pattern requires kwargs everywhere** — any test that byte-equals `pb1-e1a-lead-rendered.snap.txt` must pass the same date kwargs the fixture was regenerated with. The plan enumerated `renderE1ALead()` (in `v5-3-2-regression.test.ts`) but missed `rendered-prompt-snapshot.test.ts` (Phase 88 surgical tripwire — same byte-equal pattern). Worth noting for future date-dependent fixture regeneration: grep for ALL `readFileSync(.*snap.txt)` callers and update each helper coherently.
- **Regex character classes need explicit Unicode handling for Spanish day names.** `\w` is ASCII-only in JavaScript; either use `\S+`/`[a-záéíóúñ]+` or the `u` flag with `\p{L}+`. The CONTEXT.md-locked `\w+` regex was an authoring oversight; the executor caught it at the GREEN verify stage. Worth flagging in future plan-checker passes for any test asserting Spanish/UTF-8 token captures.
