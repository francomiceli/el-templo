  <action>
Create `src/modules/auth/routes.ts`:

**POST /register:**
- Use registerSchema for validation
- Check email uniqueness first (return 409 if exists)
- Verify branchId exists in branches table (return 400 if invalid)
- Hash password with argon2 (already installed)
- Insert user with role='member', level='alfa'
- Sign JWT with { userId, email, role }
- Return { token, user: { id, email, role, level, branchId } }

**POST /login:**
- Use loginSchema for validation
- Find user by email (return 401 if not found - use generic "Invalid credentials" message)
- Verify password with argon2.verify (return 401 if invalid)
- Sign JWT with { userId, email, role }
- Query branch name for response
- Return { token, user: { id, email, firstName, lastName, role, level, branchId, branchName } }

**GET /me:**
- Add onRequest: [fastify.authenticate] hook
- Extract userId from request.user
- Query user from database (return 404 if not found)
- Query branch name
- Return user profile object (same shape as login response, minus token)

Export as FastifyPluginAsync named `authRoutes`.

**Update `src/app.ts`:**
- Import authPlugin from './plugins/auth'
- Import authRoutes from './modules/auth/routes'
- Register authPlugin before routes
- Register authRoutes with prefix '/api/auth'
