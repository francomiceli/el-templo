Rigen DA-39, DA-48 y DA-52 (`201-36-PLAN.md`). Para este plan:
- Flujo de subida (igual que `useVideoUpload` de Ejercicios): elegir archivo (`accept="video/mp4,video/quicktime,.mp4,.mov"`) →
  tope de 200 MB del archivo original → si no es MP4, `transcodeToMp4` (fase "Convirtiendo…" con %) → el MP4 resultante también
  ≤ 200 MB → `POST /tutorials/upload-url` con `contentType: "video/mp4"` → `axios.put` pelado (sin auth) con

- A diferencia de Ejercicios, la subida NO depende de `uploadsEnabled` (DA-48): anda también en staging.
- Borrar: diálogo de confirmación "¿Borrar el tutorial de {nombre}? Los alumnos dejan de ver 'Ver cómo se hace'".
- `storageReady: false` → botones deshabilitados y un `q-banner` "El almacenamiento de videos no está configurado".
- Errores con `ConquerApiError`/`toConquerError` (prioriza el `error` en español del API); 4xx → `log.warn`. Colores
  `secondary`/`accent`, nunca `primary`/`info` (RULES, admin). Botones de 44 px de alto.
</decisions>
