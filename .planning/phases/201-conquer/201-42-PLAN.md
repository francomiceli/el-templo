  `conquer/tutorials/{tenant}/ejercicio-{id}-{uuid}.mp4`; combo → `conquer/tutorials/{tenant}/combo-{comboKey}-{uuid}.mp4`.
  `isTutorialKey(key, tenantId, target, ref)` con regex anclada (combo validado contra `COMBO_KEYS`).

  (400 `CONQUER_TUTORIAL_TIPO_INVALIDO`, "Subí el tutorial en MP4") → `{ uploadUrl, key, contentType, expiresIn: 900, maxBytes }`.
- Orden confirmación (`PUT /tutorials`): objetivo → ejercicio (404) → storage (503) → clave (400 `CONQUER_VIDEO_CLAVE_INVALIDA`) →
  HEAD (`null` → 409 `CONQUER_VIDEO_NO_SUBIDO`; con `checkUploadedVideo(head, TUTORIAL_VIDEO_MAX_BYTES, [TUTORIAL_CONTENT_TYPE])`
  distinto de ok → `deleteObject` + 400 `CONQUER_VIDEO_INVALIDO`, "El video pesa más de 200 MB o no es MP4") → leer la clave
  anterior → upsert (`onDuplicateKeyUpdate` de `videoKey` y `uploadedBy`) → si había otra clave, `deleteObject(anterior)`
  best-effort (`request.log.warn({ target, ref })` si falla, sin la clave) → vista del admin.
- `DELETE`: param inválido (combo fuera de `COMBO_KEYS` → 400 `CONQUER_TUTORIAL_OBJETIVO_INVALIDO`; ejercicio de otro gimnasio
  → 404) → sin fila → 200 con la vista (idempotente, sin storage) → storage (503) → `deleteObject` (si falla → 503 y la fila
  queda) → DELETE de la fila → vista.
- Vista del admin: `{ storageReady: boolean, exercises: [{ exerciseId, url }], combos: [{ comboKey, label, url: string | null }] }`
  (combos SIEMPRE los 6, en el orden de `COMBO_KEYS`, con `COMBOS[k].label`). Vista del alumno: `{ exercises: [{ exerciseId,
  url }], combos: [{ comboKey, url }] }` solo con URL no nula. `url = assembleVideoUrl(videoKey)`.
- DA-49: `GET /api/members/conquer/tutorials` exige sesión pero NO Conquer activo (contenido del gimnasio, sin datos personales).
