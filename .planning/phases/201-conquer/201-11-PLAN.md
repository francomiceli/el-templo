  `{ action: "deshacer_etapa" }` → `cut_stage > 0` (si no, 409 `CONQUER_SIN_ETAPA`), `cut_stage - 1`;
  `{ action: "bajar_escalon"; exerciseId: number; step: "e1" | "e2" | "e3" | "hold"; alertId?: number }` → el escalón del alumno baja al
  peldaño activo más fácil siguiente (`easierPosition`) con `applyRungChange` (since = hoy; E1 vuelve a calibrar); sin peldaño más

  Devuelve `FichaResponse`.
- `confirmLevelUp(db, ctx, actor, userId, body: { daysCount: number })` — `nextLevel` null → 409 `CONQUER_NIVEL_MAXIMO`; días inválidos
  para el nivel nuevo → 400 `CONQUER_DIAS_INVALIDOS`; en transacción: `level` nuevo, `days_count`, `level_since = hoy`,
  `ensureStepsForPlan` (no toca escalones existentes), y todas las alertas `paso_nivel` abiertas/vistas del alumno → `resuelta`.
  Devuelve `FichaResponse`.

  `FichaResponse = { member: AdminMemberView & { firstName: string; lastName: string; email: string | null }; progress: ProgressResponse; alerts: BoardAlert[]; cutProposal: CutProposal; levelUp: { to: Level | null; validDays: number[] } }`.
