  `daysDone` = días distintos del plan (sin `sabado`) y `maxPain`; `levelUpStreak(..., daysCount, PAIN_ALERT_MIN, monday actual) >= LEVEL_UP_WEEKS`
  → `dedupeKey "paso_nivel:<level>:<level_since>"`, `detail: { from, to, weeks }`. Una sola query de sesiones desde `level_since`.

  — pura: inactivo si `daysBetween(lastSessionDate ?? activationDate, today) >= 7`; control_vencido si `lastCheckDate` y

  alumnos; última sesión por alumno con GROUP BY; resumen de controles por alumno: MAX(check_date) y si tiene `dia0`), sin queries
  dentro de un loop.
  `BoardResponse = { counts: { rojo: number; amarillo: number; verde: number; ok: number; total: number }; members: BoardMember[] }`,
