  `daysBetweenIso(from: string, to: string): number` (to - from en días).
- `blockWeek(activationDate: string, today: string): number` — `floor(daysBetween(monday(activation), monday(today)) / 7) + 1`, mínimo 1 (A11).
- `nextPendingDay(planKeys: readonly string[], doneKeys: readonly string[]): string | null` — primer `planKeys[i]` que no está en
  `doneKeys`; `null` = "Semana completa" (D-16). El orden lo da el plan (4 días: plancha, front, vertical, dominadas y `sabado` al
  final para Toro; 3 días: empuje, traccion, mixto; 2 días: empuje, traccion).
- `comboSubirReady(weeks: readonly { monday: string; hit: boolean }[], n: number): boolean` — ordena por `monday`, toma las últimas
  `n`; `true` si hay `n`, todas `hit` y los lunes son consecutivos (7 días entre cada uno) (D-14).
- `levelUpStreak(weeks: readonly { monday: string; daysDone: number; maxPain: number }[], daysCount: number, painLimit: number, currentMonday: string): number`
  — semana completa = `daysDone >= daysCount && maxPain < painLimit`; racha de semanas completas consecutivas que termina en
  `currentMonday` si la semana actual está completa, o en la semana anterior si no; una semana que falta en la lista corta la racha.
