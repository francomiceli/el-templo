    Modify BlockHeader.vue to display protocol timer alongside block name.

    **New props to add:**
    ```typescript
    interface Props {
      blockName: string;
      blockRole: BlockRole;
      route?: string;
      // NEW timer props
      timerDisplay?: string;          // Formatted time text (e.g., "3/8 — 0:42", "4:23")

    }
    ```

    **Layout change:**
    Current: block-header is a simple vertical stack (name + route).
    New: block-header becomes a flex row — left side has name + route, right side has timer display.

    ```html
    <div class="block-header" :style="headerStyle">
      <div class="block-header__left">
        <div class="block-name text-h5 text-weight-bold text-uppercase">
          {{ blockName }}
        </div>
        <div v-if="route" class="block-route text-caption text-grey-7">
          {{ route }}
        </div>
      </div>
      <div v-if="showTimer && timerDisplay" class="block-header__right">
        <div class="block-timer text-h5 text-weight-bold" :class="timerColorClass">
          {{ timerDisplay }}
        </div>
      </div>
    </div>
    ```

    **Styling:**
    - `.block-header`: add `display: flex; justify-content: space-between; align-items: center;`
    - `.block-header__left`: flex-shrink, contains name + route
    - `.block-header__right`: flex-shrink-0, prevents timer from wrapping
    - `.block-timer`: monospace font (`font-family: 'Roboto Mono', monospace`), sized to match block name
    - Timer transitions: add CSS `transition: color 0.3s ease` for smooth color changes between normal/amber/red

    ```typescript
      blockRole: BlockRole;   // For accent color
    }
    ```

    **Emits:**
    - `stop` - User tapped stop
    - `play` - User tapped play/resume
    - `start` - User tapped start (initial start)

    **Template:**
    Three states:
    1. **Not started** (not running, not complete, not stopped): Show "Iniciar Timer" button — full-width, primary color, size lg. Emits `start`.
    2. **Running**: Show a centered round stop button with "pause" icon. Emits `stop`.
    3. **Stopped** (not running, not complete, was previously started): Show a centered round play button with "play_arrow" icon. Emits `play`.
    4. **Complete**: Component renders nothing (v-if="!isComplete").

    **Styling:**
    - Stop button: `q-btn round flat` with block accent color, icon "pause", size 48px
    - Play button: `q-btn round flat` with block accent color, icon "play_arrow", size 48px
    - Use `getBlockCSSColor(blockRole)` for dynamic button color
    - Center the button horizontally
    - Add a `wasStopped` internal ref to distinguish "not started" from "stopped after start"

    **Note:** The "Start Timer" button replaces the "Complete Block" button for timed blocks. The DayPlayer page (Plan 04) will handle this swap — TimerControls just emits the events.
