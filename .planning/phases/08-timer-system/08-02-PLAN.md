  <files>el-templo-app/src/modules/training/composables/useProtocolTimer.ts</files>
  <action>
    Create `useProtocolTimer.ts` that accepts protocol params and returns unified timer state.

    **Interface:**
    ```typescript
    import type { ProtocolParams, ProtocolType } from '../utils/timerFormats';

    interface ProtocolTimerReturn {
      // Display state
      displayText: ComputedRef<string>;        // Formatted time "3:42" or "3/8 — 0:42"
      secondsRemaining: Ref<number>;           // Countdown seconds (EMOM round / AMRAP total)
      secondsElapsed: Ref<number>;             // Count-up seconds (For Time)
      currentRound: Ref<number>;               // EMOM current round
      totalRounds: Ref<number>;                // EMOM total rounds
      progress: ComputedRef<number>;           // 0-1 progress fraction

      // State
      isRunning: Ref<boolean>;                 // Timer is actively ticking
      isStopped: Ref<boolean>;                 // Timer was stopped (can resume)
      isComplete: ComputedRef<boolean>;        // Timer finished naturally
      timerColorClass: ComputedRef<string>;    // 'text-grey-8' | 'text-amber' | 'text-red'

      // Controls
      start: () => void;
      stop: () => void;
      resume: () => void;

      // Lifecycle
      cleanup: () => void;

      // Events
      onComplete: (callback: () => void) => void;
    }
    ```

    **Implementation details:**

    1. **Drift-correcting timer core:**
       - Store `anchorTime = Date.now()` when started
       - Store `accumulatedMs = 0` for stop/resume tracking
       - On stop: `accumulatedMs += Date.now() - anchorTime`
       - On resume: `anchorTime = Date.now()` (accumulatedMs preserved)
       - Calculate elapsed: `accumulatedMs + (Date.now() - anchorTime)` when running
       - Use `setTimeout(tick, 100)` for 100ms polling (smooth display)

    2. **EMOM mode:**
       - `secondsRemaining` = 60 - (elapsedInRound % 60) — countdown within each round
       - `currentRound` = floor(totalElapsed / 60) + 1
       - Auto-advance rounds; when `currentRound > totalRounds` -> complete
       - `displayText` = `"${currentRound}/${totalRounds} — ${mins}:${secs}"`
       - On round transition: call audio.playBeep()
       - `timerColorClass`: amber when secondsRemaining <= 10, red when <= 5

    3. **AMRAP mode:**
       - `secondsRemaining` = (durationMinutes * 60) - totalElapsed
       - When secondsRemaining hits 0 -> complete
       - `displayText` = `"${mins}:${secs}"` countdown format
       - On complete: call audio.playComplete()
       - `timerColorClass`: amber when secondsRemaining <= 10, red when <= 5

    4. **FOR_TIME mode:**
       - `secondsElapsed` = totalElapsed (count up from 0)
       - Never auto-completes — user calls `stop()` then external code handles completion
       - `displayText` = `"${mins}:${secs}"` count-up format
       - `timerColorClass`: always 'text-grey-8' (no urgency on count-up)
       - `isComplete` is always false — external code (DayPlayer) handles "Done" action

    5. **STRAIGHT_SETS:** Return a no-op timer (all values zero, start/stop/resume are no-ops, isComplete always false). This avoids conditional logic in consuming components.

    6. **onComplete callback:** Store callback ref, invoke when timer naturally finishes (EMOM all rounds done, AMRAP countdown hits 0). NOT called for FOR_TIME or STRAIGHT_SETS.

    7. **Audio integration:** Accept optional `useTimerAudio` return value. If provided, call playBeep on EMOM round transitions, playWarning at 5s remaining, playComplete on natural finish.

    8. **cleanup():** Clear any active setTimeout, reset state. Called by consuming component on unmount.

    **Important:** Do NOT use onUnmounted inside this composable (per Phase 7 decision — composable may be called from computed context). Expose cleanup() method instead.
