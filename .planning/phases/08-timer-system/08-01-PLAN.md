<objective>
Parse block format name strings into protocol types and extract timer parameters from block data.

Purpose: Timer composables need to know which protocol to use (EMOM/AMRAP/For Time/Straight Sets) and what parameters (duration in minutes, number of rounds). The format field on Block is a string like "EMOM", "AMRAP", "For Time", "Tabata", etc. This utility maps those strings to a protocol type and derives timer params from the block's prescription data.

Output: `timerFormats.ts` utility with full test coverage via TDD.
</objective>

  <behavior>
    The format name from Block.format is a string like "EMOM", "AMRAP", "For Time", "Tabata", "Accumulate X", "Straight Sets", "Complex", etc.

    **ProtocolType enum:**
    - `EMOM` - formats: "EMOM", "EMOM + For Time", "Every X Seconds", "On the 2:00 / 3:00", "Death By", "Death By Unbroken"
    - `AMRAP` - formats: "AMRAP", "AMRAP Series"
    - `FOR_TIME` - formats: "For Time", "Rounds for Time", "Chipper", "Couplet", "Triplet", "Singlet", "Hero WOD", "Benchmark WOD", "Benchmark", "Open Style", "Time Cap", "Task Priority", "Task Priority vs Time Priority"
    - `STRAIGHT_SETS` - everything else: "Tabata", "HIIT", "Interval Training", "Complex", "Cluster", "Accumulate X", "Flow Guiado", "For Quality", "For Tech", "For Max (Carga)", "For Max (Reps)", "For Max (Tiempo)", "Ladder", "Ladder Block", "Ladder corta", "Broken Ladder", "Pyramid", "Wave Loading", "Drop Set", "Rest-Pause", "Tempo Sets", "Unbroken Reps", "Buy-in / Cash-out", "Circuito cooperativo", "I Go", and any unknown format

    **Note on Tabata/HIIT**: These are time-based formats but use fixed work/rest intervals (20s/10s for Tabata) which are prescribed in the exercise reps/seconds. They don't need a protocol countdown timer because the coach prescribes exact timing per exercise. Treat as STRAIGHT_SETS for timer purposes.

    **ProtocolParams:**
    - `type: ProtocolType` - which timer to use
    - `durationMinutes: number | null` - for AMRAP: total duration in minutes (default 10 if not derivable)
    - `rounds: number | null` - for EMOM: total rounds (derived from exercise count or default 10)
    - `intervalSeconds: number` - for EMOM: seconds per round (default 60)

    **getProtocolParams(block: Block): ProtocolParams**
    - For EMOM: rounds = block exercises count * sets (if format implies sets), or exercise count, intervalSeconds = 60
    - For AMRAP: durationMinutes = derive from repsBudget heuristic or default 10
    - For FOR_TIME: no duration (user-controlled), no rounds
    - For STRAIGHT_SETS: no params needed

    Test cases:
    - parseProtocolType("EMOM") -> "EMOM"
    - parseProtocolType("AMRAP") -> "AMRAP"
    - parseProtocolType("AMRAP Series") -> "AMRAP"
    - parseProtocolType("For Time") -> "FOR_TIME"
    - parseProtocolType("Rounds for Time") -> "FOR_TIME"
    - parseProtocolType("Chipper") -> "FOR_TIME"
    - parseProtocolType("Tabata") -> "STRAIGHT_SETS"
    - parseProtocolType("Complex") -> "STRAIGHT_SETS"
    - parseProtocolType("Flow Guiado") -> "STRAIGHT_SETS"
    - parseProtocolType("Unknown Format") -> "STRAIGHT_SETS"
    - parseProtocolType("EMOM + For Time") -> "EMOM"
    - parseProtocolType("Death By") -> "EMOM"
    - parseProtocolType("Every X Seconds") -> "EMOM"
    - getProtocolParams(emomBlock with 4 exercises) -> { type: "EMOM", rounds: 4, intervalSeconds: 60, durationMinutes: null }
    - getProtocolParams(amrapBlock) -> { type: "AMRAP", rounds: null, intervalSeconds: 60, durationMinutes: 10 }
    - getProtocolParams(forTimeBlock) -> { type: "FOR_TIME", rounds: null, intervalSeconds: 60, durationMinutes: null }
    - getProtocolParams(straightSetsBlock) -> { type: "STRAIGHT_SETS", rounds: null, intervalSeconds: 60, durationMinutes: null }
  </behavior>
  <implementation>
    Create a lookup map for format names to protocol types. Use case-insensitive matching.
    For getProtocolParams, use Block.exercises.length for EMOM rounds and a default duration for AMRAP.
    Export ProtocolType as a string union type (not enum) for tree-shaking.
  </implementation>
</feature>
