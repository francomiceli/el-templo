  <what-built>
    Complete timer system with 4 protocol modes integrated into Day Player:
    1. EMOM timer with round counting and auto-reset
    2. AMRAP timer with countdown
    3. For Time timer with count-up and "Listo!" button
    4. Straight Sets (unchanged from Phase 7)
    Plus: stop/play controls, audio/haptic cues, background auto-stop, auto-block-completion
  </what-built>
  <how-to-verify>
    Start the dev server: `cd el-templo-app && npx quasar dev`

    **Test 1: Straight Sets block (no timer)**
    1. Navigate to training -> tap today -> start session
    2. Initium block should show "Complete Block" button (no timer controls)
    3. Exercise list displays as before
    4. Tap "Complete Block" -> splash -> next block
    5. Verify: No timer in BlockHeader, behavior identical to Phase 7

    **Test 2: EMOM block**
    1. Find a block with EMOM format (may need to check which day has EMOM blocks)
    2. Verify "Iniciar Timer" button appears instead of "Complete Block"
    3. Tap "Iniciar Timer" -> timer appears in BlockHeader: "1/N — 0:59"
    4. Watch countdown from 60 to 0
    5. At 10s: timer text turns amber
    6. At 5s: timer text turns red
    7. At 0s: round advances (2/N), timer resets to 60
    8. Verify audio beep on round transition
    9. Let all rounds complete -> block auto-completes -> splash -> next block
    10. Verify: session elapsed timer (top right) keeps running throughout

    **Test 3: Stop/Play**
    1. Start a timed block
    2. Tap Stop button -> timer freezes, Play button appears
    3. Wait 5 seconds
    4. Tap Play -> timer resumes from where it stopped
    5. Verify: Session timer keeps running while block timer is stopped

    **Test 4: AMRAP block**
    1. Find a block with AMRAP format
    2. Tap "Iniciar Timer" -> countdown from total duration
    3. Timer counts down
    4. At 10s: amber, at 5s: red
    5. At 0: block auto-completes -> splash -> next block
    6. Verify audio cue on completion

    **Test 5: For Time block**
    1. Find a block with "For Time" format
    2. Tap "Iniciar Timer" -> timer counts UP from 0:00
    3. "Listo!" button appears alongside timer controls
    4. Let it run for ~15 seconds
    5. Tap "Listo!" -> block auto-completes with recorded time
    6. Verify: transition splash appears

    **Test 6: Background handling (if testing on mobile or simulating)**
    1. Start a timed block
    2. Switch to another app (or minimize browser)
    3. Return to app
    4. Verify: block timer is stopped, Play button shown
    5. Tap Play to resume
    6. Verify: session timer still shows correct elapsed time

    **Test 7: Full session flow**
    1. Play through a complete session with mixed block types
    2. Verify block transitions work correctly between timed and non-timed blocks
    3. Verify progress bar advances correctly
    4. Verify session completion works after all 4 blocks
  </how-to-verify>
