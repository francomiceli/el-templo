  <how-to-verify>
    1. **Start both apps:**
       ```bash
       # Terminal 1: API
       cd el-templo-api && npm run dev

       # Terminal 2: Admin app
       cd el-templo-admin && npm run dev

       # Terminal 3: Member app
       cd el-templo-app && npm run dev
       ```

    2. **Admin Login Test:**
       - Open http://localhost:9100
       - Should redirect to /login
       - Try logging in with a member account - should see "Acceso denegado"
       - Log in with admin/coach account - should redirect to /sessions
       - Verify drawer shows navigation with pending badge

    3. **Session Generation Test:**
       - Navigate to /generate
       - Select a week (e.g., week 2)
       - Click "Generar Semana Completa"
       - Should see "Generadas X sesiones" message
       - Week summary should show pending icons

    4. **Session List Test:**
       - Navigate to /sessions
       - Should see sessions grouped by week
       - Use day tabs (Lun, Mar, etc.) to filter
       - Status filter should work
       - Level group filter should work
       - Pending sessions should sort first

    5. **Approval Workflow Test:**
       - Click approve (checkmark) on a pending session
       - Status should change to "Aprobada" (green badge)
       - Pending count in drawer should decrease
       - Click revert on approved session
       - Status should change back to "Pendiente"

    6. **Discard Workflow Test:**
       - Click discard (trash) on a session
       - Enter optional reason in dialog
       - Session should disappear from main list
       - Navigate to /discarded
       - Session should appear with reason shown
       - Click restore - session should return to pending

    7. **Bulk Approve Test:**
       - Navigate to a day with multiple pending sessions
       - Click "Aprobar todas (N)"
       - Confirm in dialog
       - All sessions should become approved

    8. **Session Detail Test:**
       - Click "Ver detalles" on any session
       - Should show session header with status
       - Should show all blocks with colored cards
       - Each block should show format, intensity, rep budget
       - Exercises should show name, contraction badge, reps
       - Toggle "Mostrar detalles del algoritmo"
       - Should show difficulty values
       - Approve/discard buttons should work from detail view

    9. **Member Visibility Test:**
       - Open http://localhost:9000 (member app)
       - Log in as a member
       - Navigate to Weekly View
       - Days with pending sessions should show "Sesion no disponible"
       - Days with approved sessions should show full session
       - Confirm members cannot see pending/discarded sessions

    10. **Low Sessions Alert Test:**
       - In admin app, approve only current week sessions
       - Warning banner should appear in drawer area
       - Generate and approve next week sessions
       - Warning should disappear

    **Expected behavior summary:**
    - Admin sees all sessions, can approve/discard/revert
    - Members only see approved sessions
    - Pending count badge updates live
    - Spanish labels throughout admin app
    - Clean neutral admin design (no navy/bronze)
