Add the following columns to the sessions table schema:

1. `status` - varchar(20), default 'pending_review', not null
   - Values: 'pending_review' | 'approved' | 'discarded'

2. `approvedAt` - timestamp, nullable
   - When the session was approved

3. `approvedBy` - int, nullable, references users.id
   - User ID of the admin who approved

4. `approvedBySystem` - boolean, default false
   - True if auto-approved by cron job

5. `discardedAt` - timestamp, nullable
   - When the session was discarded

6. `discardedBy` - int, nullable, references users.id
   - User ID of the admin who discarded

7. `discardedReason` - text, nullable
   - Optional rejection notes for algorithm refinement

Add index on status column for efficient filtering:
`index('sessions_status_idx').on(table.status)`

Import text from drizzle-orm/mysql-core if not already imported.
Import users from './users' for the foreign key reference.
