## Interaction Patterns

### Admin: Day Mode Toggle (D-16)

- **Location:** SessionsPage, below the week selector row in the General tab
- **Pattern:** Row of 6 day chips (Lun-Sab) with a toggle icon or label indicating mode. Use `q-btn-toggle` group with two options per day: "Regular" / "ROM"
- **Simplified approach:** A single collapsible settings row with 6 `q-toggle` components (one per day), each labeled with the day abbreviation. Default: all off (regular) except Sabado (on = ROM). This matches the existing `q-toggle` pattern used in PlanFormDialog.
- **Save behavior:** Auto-save on toggle change via `PUT /admin/sessions/day-modes`. Show brief `$q.notify` success toast.
- **Loading state:** Toggles disabled while saving, with `q-spinner-dots` inline.

### Admin: ROM Badge on Day Card (D-19)

- **Pattern:** `<q-badge color="info" label="ROM" class="q-ml-sm" />` inline next to the day label text in the day card header row.
- **Position:** After the day name ("Sabado"), before the `<q-space />`.
- **Only shown when:** `dayGroup` contains ROM-mode sessions (check `session_mode === 'rom'`).

### Admin: 2-Level ROM Day (D-20)

- **Pattern:** Same level row markup as regular days, but `DISPLAY_LEVELS` filtered to `['alfa', 'delta']` for ROM day groups.
- **Level labels in level rows:** "Alfa" / "Delta" (same as current `memberLevelLabel()` — no rename to Basico/Avanzado in admin list view).
- **Route summary replacement (D-21):** Instead of route codes (FL, PL, etc.), show "Tren Inferior / Zona Media / Tren Superior" in the `text-caption text-grey-7` span.

### Admin: ROM Block Edit (D-22, D-23)

- **EditableBlockCard header:** Display `TREN INFERIOR`, `ZONA MEDIA`, or `TREN SUPERIOR` instead of raw `ROM_LOWER`, `ROM_CORE`, `ROM_UPPER`. Use a simple `ROLE_DISPLAY_NAMES` map.
- **No DESCANSO ACTIVO row:** When block role starts with `ROM_`, hide the mobility exercise slot entirely.
- **ExerciseSwapDialog:** When opened from a ROM block, pre-filter the recommended section by body zone. Add a "Zona" indicator badge in the dialog header: `<q-badge outline color="info">Tren Inferior</q-badge>`.

### Admin: ROM PDF Layout (D-25, D-26, D-27)

- **Block header text:** Spanish zone names in Cinzel font: `TREN INFERIOR`, `ZONA MEDIA`, `TREN SUPERIOR`.
- **Format subtitle:** "For Quality · 3 Rondas · Descanso 30s" below block header.
- **Tier layout:** 2-row stacked (NOT the existing 2x2 grid):
  - Row 1: Full-width box labeled "BASICO" (replaces alpha symbol) — contains 3 exercises
  - Row 2: Full-width box labeled "AVANZADO" (replaces delta symbol) — contains 3 exercises
- **Tier label font:** Cinzel Bold, same size as existing Greek symbols. Color: NAVY (`#24364A`).
- **No MOVILIDAD line:** ROM blocks omit the "MOVILIDAD · exercise" line since all exercises are mobility.
- **Box height:** Each tier box gets approximately half the available height (vs. quarter in 2x2). `targetBoxHeight` approximately 980pt per tier (full-page).

### Member App: ROM DayCard (D-28, D-31)

- **ROM badge:** `<q-badge color="info" label="ROM" class="q-ml-xs" />` next to the day name in `day-card__header-left`.
- **Route subtitle replacement:** Instead of route name (e.g., "Front Lever + Planche"), show "Movilidad" as the `day-card__route` text.
- **Block list:** 3 BlockCard components rendered sequentially (ROM_LOWER, ROM_CORE, ROM_UPPER). No BlockChoiceCard (no Deuteros selector).
- **Block card headers:** Display `TREN INFERIOR`, `ZONA MEDIA`, `TREN SUPERIOR` using the `.block-name` CSS class (Montserrat 700, uppercase, 0.08em letter-spacing).
- **Block card background:** All 3 ROM blocks use `block-bg--default` (aged-gold subtle gradient).

### Member App: ROM DayPlayer (D-29, D-30, D-32)

- **No Deuteros selector:** When session has no DEUTEROS roles, skip the block choice screen entirely.
- **Block sequence:** ROM_LOWER -> ROM_CORE -> ROM_UPPER. Standard block transition (slide animation matching existing pattern).
- **Exercise card format:** "For Quality" with 3 rounds. Rep display: "20 / 30 / 40" (one value per exercise, not a rep scheme). Rest: "30s" shown between rounds.
- **Completion:** Standard completion flow — logs ROM block roles in completion tracking.
- **Tier assignment (invisible to member):** alfa-level members see Basico tier, all others see Avanzado. No visible tier label in the player — member just sees their exercises.
