# Phase 118 — UI Design Contract

> Visual and interaction contract for the 3 new admin analytics dashboards (Funnel,
> Retención, Finanzas avanzadas) plus the engagement-card deletion (D-09). Generated by
> gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Context:** `el-templo-admin` (Quasar v2 + Vue 3, web-only admin/coach console). The design
> system is the EXISTING Quasar "light brand alignment" theme (Phase 39). This is NOT a new
> design system — the contract below codifies the already-shipped tokens and the established
> analytics-tab patterns from `FinanzasTab.vue` / `AsistenciaTab.vue` / `MiembrosTab.vue` /
> `AnaliticasPage.vue`. UI copy is in **Spanish** (app UI language). No shadcn gate applies
> (Quasar app, not a shadcn/React project). No new charting deps — `chart.js` + `vue-chartjs`
> are already installed (D-10) and the no-new-dependencies-without-asking rule is strict.

## Spacing Scale

The app uses Quasar's spacing utility classes (`q-pa-*`, `q-mb-*`, `q-col-gutter-*`,
`q-gutter-*`) and the responsive grid (`row` / `col-12 col-sm-6 col-md-3`). Quasar's scale maps
to multiples of 4. Use the named utility classes, NOT hardcoded px, to stay consistent with the
existing tabs.

| Token | Quasar class                              | Value | Usage                                                         |
| ----- | ----------------------------------------- | ----- | ------------------------------------------------------------- |
| xs    | `q-pa-xs` / `q-mb-xs` / `q-gutter-xs`     | 4px   | Icon gaps, chip-to-tooltip spacing, KPI sub-line spacing      |
| sm    | `q-pa-sm` / `q-mb-sm` / `q-col-gutter-sm` | 8px   | Card-section subtitle gap, dense card padding, tight grids    |
| md    | `q-pa-md` / `q-mb-md` / `q-col-gutter-md` | 16px  | DEFAULT: page padding, card/grid gutters, section gaps        |
| lg    | `q-pa-lg`                                 | 24px  | Reserved (rarely used in current tabs)                        |
| xl    | `q-pa-xl`                                 | 48px  | Empty-state / no-data centered blocks (`text-center q-pa-xl`) |

Exceptions:

- Chart containers use a fixed inline `height: 300px; position: relative` wrapper (matches
  every existing chart in `FinanzasTab`/`AsistenciaTab`). Funnel/retention/cash-vs-accrued
  charts MUST use the same `style="height: 300px; position: relative"` wrapper.
- `vue-chartjs` charts MUST set `responsive: true, maintainAspectRatio: false` in options
  (established convention; required for the fixed-height wrapper to work).

## Typography

The app uses Quasar's typographic utility classes (no custom font-size declarations in
component templates). Geologica font, weights 400/500/600 only. Use these EXACT roles — do not
introduce new sizes.

| Role                | Quasar class           | Size (rem→px)   | Weight                     | Usage                                                                              |
| ------------------- | ---------------------- | --------------- | -------------------------- | ---------------------------------------------------------------------------------- |
| Display (KPI value) | `text-h4`              | 2.125rem ≈ 34px | 400                        | Big KPI number in a metric card (e.g. ARPU, ciclo-1 count, conversion %)           |
| Heading (page)      | `text-h5`              | 1.5rem ≈ 24px   | 400                        | Page title ("Analiticas") and per-tab section title (`text-h6` for in-tab headers) |
| In-tab header       | `text-h6`              | 1.25rem ≈ 20px  | 500                        | Tab-level section heading (matches "Programas — Resumen…")                         |
| Card title          | `text-subtitle2`       | 0.875rem ≈ 14px | 500 (`text-weight-medium`) | Chart/card titles ("Funnel de conversión", "Retención por ciclos") + `q-mb-sm`     |
| Body / value        | `text-body2` / default | 0.875rem ≈ 14px | 400                        | Table cells, tooltip body                                                          |
| Label / caption     | `text-caption`         | 0.75rem ≈ 12px  | 400, `text-grey-7`         | KPI labels, "(ARS/EUR por separado)" qualifiers, helper text                       |
| Emphasis            | `text-weight-bold`     | —               | 700                        | Monetary values inline (matches FinanzasTab method breakdown)                      |

Line heights: inherited from Quasar typography (headings ~1.2, body ~1.5). Do not override.

Note: 3 primary text sizes carry the layout (h4 display, subtitle2 titles, caption labels);
body2/h5/h6 are reused Quasar roles already present in the existing tabs. Two weights dominate
(400 regular, 500 medium); 700 bold is reserved for inline monetary values only.

## Color

Brand palette is WCAG AA contrast-safe on the cream surface. Source:
`src/css/quasar.variables.scss` and `src/utils/chart-colors.ts`. Reuse the `COLORS` /
`chartColors` constants — do NOT hardcode new hex values in new chart components.

| Role                | Value                             | Usage                                                                                         |
| ------------------- | --------------------------------- | --------------------------------------------------------------------------------------------- |
| Dominant (60%)      | `#f2ede5` Marble Cream            | Page background, `q-card` background (set globally in `app.scss`)                             |
| Secondary (30%)     | `q-card flat bordered` surfaces   | Cards/panels — bordered, flat, transparent-on-cream (no white fills)                          |
| Accent (10%)        | `#96593a` Terracotta (`primary`)  | See reserved-for list below                                                                   |
| Destructive / alert | `#b34a4a` Warm Red (`negative`)   | Negative deltas, debt > 0, >90% occupancy; NOT used as a primary action color here            |
| Positive            | `#3b7249` Warm Green (`positive`) | Positive deltas, healthy metrics                                                              |
| Warning surface     | `bg-orange-2 text-orange-10`      | The forward-only caveat banner + low-adoption banner (established `q-banner` warning pattern) |

Accent (Terracotta `primary`) reserved for:

- KPI value emphasis (`text-primary` on the big number, e.g. unique-members cards)
- Active tab indicator + active tab label (`active-color="primary" indicator-color="primary"`)
- KPI/section icons (`color="primary"`)
- Primary chart series color (`COLORS.primary`) — first/most-important dataset
- Filter "Aplicar" button (`color="primary" flat`)

Chart series palette (multi-series charts — retention cohorts, funnel stages):

- Use `chartColors[]` from `src/utils/chart-colors.ts` cycled by index
  (`chartColors[i % chartColors.length]`), exactly as `revenueByBranchData` does.
- **Caja vs Devengado (D-08):** two overlaid series per currency — Caja = `COLORS.primary`
  (terracotta), Devengado = `COLORS.accent` (charcoal). This mirrors FinanzasTab's ARS/EUR
  dataset coloring so the visual gap reads as the insight.

Staging marker: `body.staging-env` recolors `--q-primary` to blue-9 — do not fight this; new
components inherit it automatically by using `primary`/`COLORS.primary`.

### Excluded-data caveat (Devengado, D-07)

When subs with invalid windows (null/0/`end < start`) are excluded from accrued revenue, show
a caption under the chart:
`Se excluyeron N suscripciones con ventana inválida (sin fecha de fin o duración 0).`
(Only render when N > 0.)

### Loading states

`q-skeleton type="rect"` blocks matching each tab's layout (one ~300px chart skeleton + a
shorter block), identical to `FinanzasTab`/`AsistenciaTab` loading branches. KPI-style metric
cards use `q-skeleton type="text"` pairs (matching `AnaliticasPage` KPI skeletons).

### Error state

No inline error UI in the existing analytics tabs — fetch errors are logged via
`createLogger().error()` (which forwards to Sentry) and the tab falls back to the no-data
empty state. New tabs MUST follow this exact pattern: `catch (err: unknown)` →
`log.error(...)` → leave `data = null` so the empty state renders. Do NOT add toast/alert UI.

### Primary CTA

This phase has **no primary action CTA** — all three tabs are read-only dashboards. The only
interactive controls are the existing global filters (país/sucursal/rango de fechas) plus a
per-tab `plan_category` filter on Retención (see Interaction Contract). No new buttons.

### Destructive actions

D-09 deletes 2 engagement cards from `AsistenciaTab.vue` (segment-count card + nominal
en_riesgo/ghost worklist with WhatsApp button) plus dead code, and removes `getEngagement`
from `ReportesPage.vue`'s `Promise.all`. This is a **code/template deletion**, not a runtime
destructive user action — no confirmation UI required. Backend, `EngagementService`,
`engagement.test.ts`, the `getEngagement` composable method, and the `segmentation` module are
PRESERVED. Removing the WhatsApp contact path is intentional (operational contact lives in
Reportes → Inactivos / Vencimientos).

## Interaction Contract (new dashboards)

Prescriptive layout/interaction rules for the 3 new tabs. Each tab is a separate component in
`src/components/analytics/` (do NOT inflate FinanzasTab/MiembrosTab — D-10): suggested
`FunnelTab.vue`, `RetencionTab.vue`, `FinanzasAvanzadasTab.vue`, lazy-loaded via the existing
`watch(activeTab)` pattern.

### Shared per-tab shell (every new tab)

1. Loading branch: `q-skeleton` blocks (see Loading states).
2. No-data branch: centered italic grey empty state.
3. Content branch (`<template v-else>`): caveat banner (where required) → metric cards →
   chart cards. Each chart wrapped in `q-card flat bordered` → `q-card-section` →
   `text-subtitle2 q-mb-sm` title → `div style="height: 300px; position: relative"` → chart.
4. Inherit global filters (`AnalyticsFilters`: branchId, country, dateFrom, dateTo) as a prop;
   refetch on `onFilterChange`, exactly like existing tabs.

### Funnel tab

- Visualization: horizontal stacked/funnel bars (Chart.js `Bar` with `indexAxis: 'y'`) showing
  freemium → prueba → activo counts per cohort OR a 3-stage funnel; planner picks exact shape
  (D-10 leaves viz to planner/UI). Use `COLORS.primary`/`secondary`/`accent` for the 3 stages.
- Stage conversion % shown as labels/tooltips; median days per stage in a small metric row
  (`text-h4 text-primary` value + `text-caption text-grey-7` label cards) above/below the chart.
- Permanent caveat banner at top.

### Retención tab

- Visualization: multi-cohort line curve (Chart.js `Line`). X-axis = ciclo N (NOT calendar
  months). One line per cohort, colored via `chartColors[i % len]`. `tension: 0.3` to match
  the daily-checkins line styling.
- Secondary view: "Distribución de ciclos completados" — a small Bar (ciclo 1 / 2 / 3+) or a
  metric-card row showing counts among current actives.
- Filter control: a `plan_category` `q-select` (dense, outlined) local to this tab, options
  `Presencial / Online regular / Online goal / Online coach / Todas`. Default `Todas`.
  Re-filters the cohort curve client- or server-side (planner decides).
- Permanent caveat banner at top.

### Finanzas avanzadas tab

- Visualization: one Caja-vs-Devengado dual-series chart **per currency** (ARS chart and EUR
  chart rendered separately — NEVER one chart summing currencies). Caja = `COLORS.primary`,
  Devengado = `COLORS.accent`, overlaid as two Bar/Line datasets on the same time axis. The
  visual gap between the two series is the intended insight.
- ARPU shown per currency as a metric card (`text-h4` value, `text-caption` label
  `ARPU mensual (ARS)` / `(EUR)`), or as a small line. Denominator uses the canonical
  `activeMemberExists` predicate (data concern, surfaced here as a caption note if helpful).
- Currency separation rule (D-08): mirror FinanzasTab — only render currencies with data; if a
  currency has zero, show an explicit `0` rather than nothing.
- Excluded-invalid-window caption when N > 0 (see Copywriting).
