```vue
    <AppFooter />
  </div>

.page__content {
  padding-top: 64px; /* Offset for fixed nav */
  min-height: calc(100vh - 64px); /* Ensure content fills viewport minus nav */

  .page__content {
    padding-top: 56px;
    min-height: calc(100vh - 56px);
  }
}
</style>
```

Notes:

- AppNav, AppPrefooter, and AppFooter are auto-imported by Nuxt from `components/`.
- The `page__content` padding-top compensates for the fixed nav.
- `min-height` ensures the footer is pushed to the bottom on short pages.
