Implementation:

1. Accept an array of section IDs to observe (e.g., `['metodo', 'niveles', 'sedes', 'sesion-prueba']`).
2. Return a reactive `activeSection` ref containing the currently visible section ID (or empty string if none).
3. Use `IntersectionObserver` with `rootMargin: '-64px 0px -50% 0px'` (offset for nav height, trigger when section is in upper half of viewport).
4. When multiple sections intersect, pick the one closest to the top of the viewport.
5. Provide a `cleanup()` function that disconnects the observer (following project composable pattern from CLAUDE.md — expose cleanup, no onUnmounted inside composable).
6. Use `onMounted` to set up observers (elements must exist in DOM).
7. Handle SSR gracefully — only set up IntersectionObserver on client side (check `import.meta.client` or `process.client`).
8. Use proper TypeScript types — no `any`.

The composable should be auto-imported by Nuxt from the `composables/` directory.

**Script setup:**

1. Import and use `useActiveSection` composable with section IDs from navLinks.
2. `isScrolled` ref — updated by scroll listener, true when `window.scrollY > 20`.
3. `isDrawerOpen` ref — toggled by hamburger button.
4. `toggleDrawer()` and `closeDrawer()` methods.
5. When drawer opens, prevent body scroll (`document.body.style.overflow = 'hidden'`). Restore on close.
6. Close drawer on route change (watch `useRoute().path`).
7. Close drawer when a nav link is clicked (for anchor links on same page).
8. Add/remove scroll listener with proper cleanup on unmount.
9. Handle SSR: Only add scroll/resize listeners on client.
