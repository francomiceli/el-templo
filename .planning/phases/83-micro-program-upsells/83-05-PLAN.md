**Add method to `el-templo-api/src/modules/programs/service.ts`:**

Add a new method `recordSessionForProgram` that is called after each session completion:

```typescript
/**
 * Record a completed session for program progression.
 * Called from session completion route. Increments weekly counter,
 * checks advancement criteria, awards AURA on week/program completion.
 *
 * Per D-04: next week unlocks when BOTH conditions are met:
 *   (a) sessions threshold met (sessionsCompletedThisWeek >= sessionsPerWeekToAdvance)
 *   (b) calendar week has arrived (current date >= enrolledAt + (currentWeek * 7 days))
 *
 * Per D-05: catch-up allowed — if member completes required sessions later,
 *   advancement happens retroactively once BOTH conditions are met.
 */
async recordSessionForProgram(userId: number, auraService: AuraService): Promise<void>
```

Logic:

1. Get active enrollment for userId (status='active'). If none, return early.
2. Increment `sessionsCompletedThisWeek` by 1.
3. Load the joined program to get `sessionsPerWeekToAdvance`, `durationWeeks`, `auraWeeklyBonus`, `auraCompletionBonus`, and `enrolledAt`.
4. **Check BOTH advancement conditions (per D-04):**

   **Condition (a) — sessions threshold:** `sessionsCompletedThisWeek >= sessionsPerWeekToAdvance`

   **Condition (b) — calendar week arrived:** Calculate the earliest date the next week can start:

   ```typescript
   // Week N's calendar window starts at enrolledAt + ((currentWeek) * 7 days)
   // E.g., if enrolled Mon Jan 1 and currentWeek=1, week 2 can start Jan 8
   const enrolledDate = new Date(enrollment.enrolledAt);
   const nextWeekStartDate = new Date(
     enrolledDate.getTime() + enrollment.currentWeek * 7 * 24 * 60 * 60 * 1000,
   );
   const calendarWeekArrived = new Date() >= nextWeekStartDate;
   ```

   **If BOTH (a) AND (b) are met AND `currentWeek < durationWeeks`:**
   - Award AURA weekly bonus: `auraService.award({ userId, sourceType: 'program_week_completion', referenceType: 'program_enrollment', referenceId: enrollment.id, amount: program.auraWeeklyBonus, description: 'Semana completada' })`. Wrap in try/catch with log.warn on failure (graceful degradation pattern).
   - Advance: set `currentWeek += 1`, `sessionsCompletedThisWeek = 0`, `weekUnlockedAt = now()`.

   **If BOTH (a) AND (b) are met AND `currentWeek >= durationWeeks`:**
   - This is program completion! Award weekly bonus (same as above) PLUS completion bonus: `auraService.award({ userId, sourceType: 'program_completion', referenceType: 'program_enrollment', referenceId: enrollment.id, amount: program.auraCompletionBonus, description: 'Experiencia completada' })`. Wrap in try/catch.
   - Set `status = 'completed'`, `completedAt = now()`.

   **If (a) is met but (b) is NOT met (sessions done but calendar week hasn't arrived):**
   - Save the incremented sessionsCompletedThisWeek (member did the work). Do NOT advance the week yet. Per D-05, when the calendar week does arrive and the threshold is already met, the next session will trigger advancement check again. Alternatively, a scheduled job or the next session completion can re-check. For simplicity, advancement is checked on each session completion — if conditions (a) AND (b) are both true at that point, advancement occurs.

   **If (a) is NOT met (sessions threshold not reached):**
   - Just save the incremented count.

5. Use a transaction for the increment + potential advancement to ensure atomicity.
