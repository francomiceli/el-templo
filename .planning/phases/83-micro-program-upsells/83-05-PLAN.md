**Add method to `el-templo-api/src/modules/programs/service.ts`:**

Add a new method `recordSessionForProgram` that is called after each session completion:

```typescript
/**
 * Record a completed session for program progression.
 * Called from session completion route. Increments weekly counter,
 * checks advancement criteria, awards AURA on week/program completion.
 *
 * Per D-04: next week unlocks when (a) sessions threshold met AND (b) calendar week arrived.
 * Per D-05: catch-up allowed — if threshold met later, advancement happens retroactively.
 */
async recordSessionForProgram(userId: number, auraService: AuraService): Promise<void>
```

Logic:

1. Get active enrollment for userId (status='active'). If none, return early.
2. Increment `sessionsCompletedThisWeek` by 1.
3. Load the joined program to get `sessionsPerWeekToAdvance`, `durationWeeks`, `auraWeeklyBonus`, `auraCompletionBonus`.
4. Check if advancement criteria met: `sessionsCompletedThisWeek >= sessionsPerWeekToAdvance`:
   a. If met AND `currentWeek < durationWeeks`:
   - Award AURA weekly bonus: `auraService.award({ userId, sourceType: 'program_week_completion', referenceType: 'program_enrollment', referenceId: enrollment.id, amount: program.auraWeeklyBonus, description: 'Semana completada' })`. Wrap in try/catch with log.warn on failure (graceful degradation pattern).
   - Advance: set `currentWeek += 1`, `sessionsCompletedThisWeek = 0`, `weekUnlockedAt = now()`.
     b. If met AND `currentWeek >= durationWeeks`:
   - This is program completion! Award weekly bonus (same as above) PLUS completion bonus: `auraService.award({ userId, sourceType: 'program_completion', referenceType: 'program_enrollment', referenceId: enrollment.id, amount: program.auraCompletionBonus, description: 'Experiencia completada' })`. Wrap in try/catch.
   - Set `status = 'completed'`, `completedAt = now()`.
     c. If NOT met: just save the incremented count (UPDATE statement already handles this).
5. Use a transaction for the increment + potential advancement to ensure atomicity.

fastify.get(

  { onRequest: [fastify.authenticate] },
