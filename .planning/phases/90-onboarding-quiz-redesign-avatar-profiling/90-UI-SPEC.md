# Phase 90 — UI Design Contract

> Visual and interaction contract for the onboarding quiz redesign and avatar profiling system. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property          | Value                                            |
| ----------------- | ------------------------------------------------ |
| Tool              | Quasar Framework (not shadcn — Vue/Quasar stack) |
| Preset            | not applicable                                   |
| Component library | Quasar v2 (QBtn, QIcon, QBadge, QSelect, QChip)  |
| Icon library      | Material Icons (already bundled via Quasar)      |
| Font — body       | Geologica 400                                    |
| Font — heading    | Montserrat 700                                   |
| Font — elegance   | Cormorant Garamond 400i (welcome subtitle only)  |

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage                                                                    |
| ----- | ----- | ------------------------------------------------------------------------ |
| xs    | 4px   | Icon-to-text inline gaps, AURA label margin-top                          |
| sm    | 8px   | Option check icon margin-left, compact gaps                              |
| md    | 8px   | Option stack gap, summary row icon gap, progress dot gap                 |
| lg    | 16px  | Content top padding, progress dots bottom margin                         |
| xl    | 24px  | Glass card horizontal padding, screen horizontal padding, section breaks |
| 2xl   | 24px  | Glass card vertical padding, question-to-options gap                     |
| 3xl   | 32px  | Glass card top padding                                                   |

Exceptions:

- Back arrow touch target: 44px (accessibility minimum for mobile tap)
- Option button min-height: 48px (touch target)
- AURA glow circle: 80px diameter (visual emphasis, not spacing)

All values derived from the existing onboarding components. No new sizes introduced.

| Role             | Size             | Weight | Line Height | Font Family |
| ---------------- | ---------------- | ------ | ----------- | ----------- |
| Body / Option    | 15px (0.9375rem) | 400    | 1.5         | Geologica   |
| Label / Caption  | 13px (0.8125rem) | 400    | 1.5         | Geologica   |
| Question heading | 18px (1.125rem)  | 700    | 1.3         | Montserrat  |

Additional typography rules:

- Question heading: `letter-spacing: 0.06em`, `text-shadow: 0 1px 8px rgba(0,0,0,0.5)`, `text-align: center`
- Screen heading (welcome/result): `letter-spacing: 0.08em`, `text-shadow: 0 1px 8px rgba(0,0,0,0.5)`
- CTA button text: Montserrat 700, 15px (0.9375rem), `letter-spacing: 0.12em`
- AURA number: Montserrat 700, 22px (1.375rem), color `$amber`
- AURA label: Montserrat 700, 13px (0.8125rem), `letter-spacing: 0.15em`, `text-transform: uppercase`
- Welcome subtitle: Cormorant Garamond italic via `.text-elegance` utility class

## Color

The onboarding flow uses a DARK theme (charcoal background), distinct from the app's cream-based light theme.

| Role            | Value                                               | Usage                                                      |
| --------------- | --------------------------------------------------- | ---------------------------------------------------------- |
| Dominant (60%)  | `#2e2a26` (charcoal)                                | Full-screen page background                                |
| Secondary (30%) | `rgba(#3d3732, 0.85)` (charcoal-mid at 85% opacity) | Glass card backgrounds with `backdrop-filter: blur(10px)`  |
| Accent (10%)    | `#96593a` (terracotta)                              | See reserved-for list below                                |
| Text primary    | `#f2ede5` (cream)                                   | All text on dark background                                |
| Text muted      | `rgba(#f2ede5, 0.5)`                                | Welcome subtitle, summary labels, back arrow default state |
| Amber           | `#d4a843`                                           | AURA number, AURA glow, ember particles                    |
| Bronze          | `#d4b896`                                           | Celebration particles (alternating with amber)             |
| Positive        | `#3b7249`                                           | Success feedback (recommendation confidence indicator)     |
| Negative        | `#b34a4a`                                           | Error states only                                          |

Accent (terracotta `#96593a`) reserved for:

1. Glass card top border: `2px solid rgba(#96593a, 0.6)`
2. Selected option border: `rgba(#96593a, 0.8)`
3. Selected option background tint: `rgba(#96593a, 0.15)`
4. Selected option check icon color
5. Progress dot — completed state fill
6. Progress dot — active state fill (with pulse animation)
7. CTA button gradient: `linear-gradient(135deg, #96593a 0%, #ad6540 100%)`
8. Background glow radial gradient (subtle, 12% opacity)
9. Logo ember-pulse drop-shadow

Admin avatar badge uses terracotta QBadge on cream background (standard admin light theme).

## Interaction Contract

### Quiz Flow (Member App)

| Interaction            | Behavior                                                                                                                                                                                                                    |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Welcome screen CTA tap | Transition forward (slide-left) to Q1. Record `quiz_started` analytics.                                                                                                                                                     |
| Option tap             | Highlight selected option immediately (terracotta border + tint). Auto-advance after 400ms delay (slide-left transition). Record `question_answered` analytics with question key and value.                                 |
| Back arrow tap         | Slide-right transition to previous question. Back arrow visible on Q2-Q5, hidden on Q1.                                                                                                                                     |
| Q3 option filtering    | Before rendering Q3, read `gender` from user store. Filter options per D-09: universal always shown, women-only for `female`, men-only for `male`, ALL options for `other`/`unspecified`. 41+ age adds `longevidad` option. |
| Q5 completion          | Submit answers to API. API returns `avatarType` + `suggestedProgram`. Transition to recommendation screen.                                                                                                                  |
| Recommendation screen  | Show program name, 1-2 sentence description, AURA reward (+50), CTA button.                                                                                                                                                 |
| Recommendation CTA tap | Mark onboarding complete in user store. 800ms fade-out exit animation. Navigate to home.                                                                                                                                    |
| Slide transitions      | 300ms ease, translateX 100%/-100% with opacity 0-1. Same as current implementation.                                                                                                                                         |
| Progress dots          | 5 dots. Completed=solid terracotta. Active=solid terracotta with 1.5s pulse (scale 1.2-1.4). Upcoming=transparent with 1px cream border at 25% opacity.                                                                     |

### Scrollable Options (Q3 with up to 7 options)

When a question has more than 5 options (Q3 for gender `other`/`unspecified` shows all 7+):

- Options container gets `max-height: 360px` with `overflow-y: auto`
- Smooth scroll behavior
- Subtle top/bottom fade gradient (8px) to indicate scrollability
- All other questions (3-6 options) show without scroll

### Admin Avatar Display

| Interaction                   | Behavior                                                                                                                                                                  |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Avatar badge                  | QBadge with avatar letter (A-K), terracotta background, cream text. Positioned inline after member name or in info row.                                                   |
| Avatar filter on members list | QSelect dropdown with options: "Todos" (no filter), A through K (with display labels), "Sin avatar" (null filter). Single-select. Triggers list refetch with query param. |

## State Catalog

| State                       | Visual Treatment                                                                                                                     |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| Welcome (step 0)            | Glass card centered. Logo 150px. No progress dots. Greeting + CTA.                                                                   |
| Question active (steps 1-5) | Glass card centered. Logo 80px. 5 progress dots visible. Question text + options stack. Back arrow on steps 2-5.                     |
| Option hover                | `border-color: rgba(cream, 0.3)`, `background: rgba(charcoal, 0.6)`                                                                  |
| Option selected             | Terracotta border + 15% tint background + check_circle icon. Holds for 400ms then auto-advances.                                     |
| Option tap (active)         | `transform: scale(0.98)` for 100ms tactile feedback.                                                                                 |
| Submitting                  | CTA button shows QBtn `:loading` spinner. Button disabled during submission.                                                         |
| Recommendation (step 6)     | Glass card centered. Logo 120px. No progress dots. Program name + description + AURA reward + CTA.                                   |
| AURA reward                 | 80px circle with amber pulse glow (2s infinite). Celebration particles (10 particles, burst animation).                              |
| Exit transition             | 800ms opacity fade to 0 on entire page. Then router.replace to home.                                                                 |
| Submission error            | Quasar Notify toast, type `negative`, message `Error al guardar tu perfil. Intenta de nuevo.` No screen change — user can retry CTA. |

## Accessibility Contract

| Requirement        | Implementation                                                                                                                                                      |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Touch targets      | All option buttons min-height 48px. Back arrow 44x44px. CTA full-width with 12px vertical padding.                                                                  |
| Progress indicator | `role="progressbar"` with `aria-valuenow` and `aria-valuemax` on dots container. Each dot has `aria-label="Pregunta N de 5"`. Active dot has `aria-current="step"`. |
| Back navigation    | `aria-label="Volver a la pregunta anterior"` on back arrow button.                                                                                                  |
| Option selection   | `aria-pressed` attribute on each option button reflects selection state.                                                                                            |
| Color contrast     | All text on charcoal background meets WCAG AA: cream on charcoal is 10.0:1, terracotta on charcoal is 4.75:1.                                                       |
| Motion sensitivity | All animations use CSS only (no JS animation loops). Users with `prefers-reduced-motion` should see instant transitions (add media query).                          |
| Screen reader flow | Linear reading order: heading -> options -> (back button at DOM start is positioned absolute, acceptable for visual-only reorder).                                  |
