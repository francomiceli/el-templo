  <action>
    **styler.py** — Frame compositing module that transforms a raw BGR frame + person confidence mask into a styled output frame.

    Implement `style_frame(frame_bgr: np.ndarray, person_mask: np.ndarray) -> np.ndarray`:

    The algorithm, step by step:

    1. **Resize mask** if dimensions differ from frame: `cv2.resize(person_mask, (w, h))`.

    2. **Smooth mask edges**: Apply `cv2.GaussianBlur(mask, (MASK_BLUR_SIZE, MASK_BLUR_SIZE), 0)` to reduce jagged edges from segmentation.

    3. **Create binary mask**: `binary = (smooth_mask > CONFIDENCE_THRESHOLD).astype(np.uint8)`.

    4. **Create navy background**: `canvas = np.full((h, w, 3), NAVY_BGR, dtype=np.uint8)`.

    5. **Create cream edge glow**:
       - Dilate binary mask: `kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (GLOW_KERNEL_SIZE, GLOW_KERNEL_SIZE))`, `dilated = cv2.dilate(binary, kernel, iterations=1)`
       - Compute edge ring: `edge_ring = (dilated - binary).astype(np.float32)`
       - Blur for soft glow: `glow = cv2.GaussianBlur(edge_ring, (GLOW_BLUR_SIZE, GLOW_BLUR_SIZE), 0)`
       - Apply cream color to canvas: for each channel c, `canvas[:, :, c] = np.clip(canvas[:, :, c].astype(np.float32) + glow * float(CREAM_BGR[c]) * GLOW_INTENSITY, 0, 255).astype(np.uint8)`

    6. **Create bronze silhouette**:
       - Convert to grayscale: `gray = cv2.cvtColor(frame_bgr, cv2.COLOR_BGR2GRAY)`
       - Normalize brightness: `gray_norm = cv2.normalize(gray, None, 60, 240, cv2.NORM_MINMAX)`
       - Tint with bronze: create `bronze = np.zeros_like(frame_bgr)`, for each channel c: `bronze[:, :, c] = (gray_norm.astype(np.float32) * (float(BRONZE_BGR[c]) / 255.0)).astype(np.uint8)`

    7. **Composite**: `mask_3ch = np.stack([smooth_mask] * 3, axis=-1)`, then `result = np.where(mask_3ch > CONFIDENCE_THRESHOLD, bronze, canvas)`.

    8. Return `result.astype(np.uint8)`.

    Import all constants from config.py: `NAVY_BGR`, `BRONZE_BGR`, `CREAM_BGR`, `CONFIDENCE_THRESHOLD`, `GLOW_KERNEL_SIZE`, `GLOW_BLUR_SIZE`, `GLOW_INTENSITY`, `MASK_BLUR_SIZE`.

    Use numpy type hints (`np.ndarray`). No `any` types.

  </action>
