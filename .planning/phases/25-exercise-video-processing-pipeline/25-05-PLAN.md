  <name>Task 1: Source and process a test video end-to-end</name>
  <files></files>
  <action>
    Run the pipeline end-to-end with a single exercise to validate all stages:

    1. Source a test video:
       ```bash
       cd el-templo-video-pipeline
       uv run pipeline source --level alfa --dry-run 2>&1 | head -20
       ```
       Pick one common exercise from the list (e.g., "Squat" or "Bench Press").

    2. Source just that one exercise manually or use the sourcer:
       ```bash
       uv run pipeline source --level alfa --output-dir test-input/
       ```
       (Cancel after first download with Ctrl+C if batch mode — we only need 1)

       If sourcing fails due to network/API issues, manually download any exercise demo video from YouTube and place in `test-input/` as `test-exercise.mp4`.

    3. Generate a preview frame:
       ```bash
       uv run pipeline preview test-input/<video-file>.mp4 --output test-output/preview.png
       ```

    4. Process the full video:
       ```bash
       mkdir -p test-output
       uv run pipeline process test-input/<video-file>.mp4 test-output/test-exercise.mp4
       ```

    5. Verify output:
       ```bash
       # Check video specs
       ffprobe -v error -show_entries stream=width,height,codec_name,pix_fmt,r_frame_rate -show_entries format=duration,size -of json test-output/test-exercise.mp4

       # Check thumbnail exists
       ls -la test-output/test-exercise.png

       # Check file size
       du -h test-output/test-exercise.mp4
       ```

    6. Copy the preview PNG and a frame from the output video somewhere accessible for the user to review.

    The preview.png and output video will be examined by the user in the checkpoint task.

  </action>
  <verify>
    - Output video exists at test-output/test-exercise.mp4
    - ffprobe shows: codec=h264, pix_fmt=yuv420p, width=720, height=1280
    - Thumbnail PNG exists at test-output/test-exercise.png
    - Preview PNG exists at test-output/preview.png
    - File size is reasonable (< 5MB for a 5-10 second clip)
  </verify>
