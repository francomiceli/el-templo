  <action>
    **encoder.py** — FFmpeg operations via subprocess. Implement:

    1. `probe_video(path: Path) -> dict` — Calls ffprobe with `-print_format json -show_format -show_streams` and returns parsed JSON. Used to get duration, resolution, rotation metadata, FPS.

    2. `get_video_info(path: Path) -> VideoInfo` — Returns a dataclass/NamedTuple with `width`, `height`, `duration`, `fps`, `rotation` extracted from probe results. Handle rotation metadata (some phone videos have rotation=90 in metadata).

    3. `encode_video(input_path: Path, output_path: Path, width: int = 720, height: int = 1280, fps: int = 30, crf: int = 28) -> None` — Encodes with FFmpeg:
       - `-c:v libx264 -pix_fmt yuv420p -r {fps} -crf {crf} -preset medium -movflags +faststart -an`
       - Scale filter: `scale={width}:{height}:force_original_aspect_ratio=decrease,pad={width}:{height}:(ow-iw)/2:(oh-ih)/2:color={NAVY_HEX}`
       - Raises RuntimeError on failure with stderr output
       - Use config.py constants for defaults (TARGET_FPS, CRF, FFMPEG_PRESET)

    4. `loop_video(input_path: Path, output_path: Path, min_seconds: float = 5.0) -> bool` — If video is shorter than min_seconds, loops it using `-stream_loop N -t {min_seconds} -c copy`. Returns True if looping was applied, False if video was already long enough.

    5. `extract_thumbnail(video_path: Path, output_path: Path) -> None` — Extracts the middle frame as PNG. Use ffprobe to get duration, calculate midpoint, then `ffmpeg -ss {mid} -i {input} -vframes 1 -q:v 2 {output.png}`.

    6. `has_watermark(path: Path) -> bool` — Basic watermark detection heuristic: look for semi-transparent overlays or text in corners using ffprobe metadata or frame analysis. Simple approach: extract first frame, check for text-like patterns in corner regions using OpenCV template matching or edge density analysis. Per CONTEXT.md: "Flag and skip for manual review". Return True if suspected watermark detected, False otherwise. Keep this simple — false negatives are acceptable; false positives get manually reviewed.

    Import constants from config.py. All subprocess calls must capture stderr and check returncode.

    **cropper.py** — Person-centered smart crop. Implement:

    1. `detect_person_bbox(person_mask: np.ndarray) -> tuple[int, int, int, int] | None` — From a segmentation confidence mask, find the bounding box of the person. Returns (x, y, w, h) or None if no person detected (mask is empty). Use `np.where(mask > 0.5)` to find person pixels, compute min/max coords.

    2. `compute_crop_region(frame_width: int, frame_height: int, person_bbox: tuple[int, int, int, int], target_width: int = 720, target_height: int = 1280, padding_ratio: float = 0.15) -> tuple[int, int, int, int]` — Computes the crop rectangle (x, y, w, h) that:
       - Centers on the person bounding box
       - Has the target aspect ratio (720:1280 = 9:16 portrait)
       - Includes padding around the person (padding_ratio of bbox dimensions) for breathing room / range of motion
       - Stays within frame bounds (clamp to 0..frame_width, 0..frame_height)
       - If source is already portrait and person fills frame, may return the full frame

    3. `smart_crop(frame: np.ndarray, crop_region: tuple[int, int, int, int], target_width: int = 720, target_height: int = 1280) -> np.ndarray` — Crops the frame to the crop region and resizes to target dimensions using `cv2.resize` with `cv2.INTER_AREA` (for downscaling) or `cv2.INTER_LANCZOS4` (for upscaling).

    4. `compute_stable_crop(masks: list[np.ndarray], frame_width: int, frame_height: int, target_width: int = 720, target_height: int = 1280) -> tuple[int, int, int, int]` — Analyzes multiple masks (e.g., sampled every 30 frames) to compute a single stable crop region for the entire video. Takes the union bounding box of all person positions to avoid camera-follow jitter. This is called once before processing all frames.

    **trimmer.py** — Movement detection for auto-trimming. Implement:

    1. `detect_movement_range(video_path: Path, min_duration: float = 5.0, max_duration: float = 10.0) -> tuple[float, float]` — Analyzes the video to find the exercise demonstration portion:
       - Open video with OpenCV, sample frames at ~2fps
       - Compute frame-to-frame difference (absolute pixel diff or optical flow magnitude)
       - Build a "movement signal" array
       - Find the window where movement is sustained (exercise is happening vs. static intro/outro)
       - Return (start_seconds, end_seconds) for the active exercise portion
       - Ensure the window is between min_duration and max_duration
       - If entire video is active, return (0, min(duration, max_duration))
       - If no significant movement detected, return (0, min(duration, max_duration)) as fallback

    2. `trim_video(input_path: Path, output_path: Path, start: float, end: float) -> None` — Uses FFmpeg to trim: `ffmpeg -y -ss {start} -to {end} -i {input} -c copy {output}`. Copy codec for speed since we'll re-encode later anyway.

    Algorithm for movement detection:
    - Compute absolute difference between consecutive sampled frames
    - Sum the differences per frame to get a "movement score" timeseries
    - Smooth with a rolling average (window = ~1 second)
    - Find the region above a threshold (e.g., 20th percentile of max movement)
    - Expand slightly to include the start/end of movements
    - Clamp to min/max duration constraints

    Use type hints throughout. Import config constants where applicable.

    **processor.py** — Orchestrates the complete single-video processing pipeline.

    First, prepare a logo watermark asset:
    - Copy the El Templo logo from `el-templo-app/assets/logo.png` to `el-templo-video-pipeline/assets/logo.png`
    - Create `el-templo-video-pipeline/assets/` directory
    - The logo will be overlaid semi-transparently in a corner of each frame

    Implement:

    1. `load_watermark(logo_path: Path, target_size: int = 40) -> np.ndarray | None` — Loads the logo PNG, resizes it to `target_size` pixels on its longest dimension (maintaining aspect ratio), and returns it as a BGR numpy array with alpha channel. Returns None if logo file doesn't exist (graceful degradation). Use `cv2.IMREAD_UNCHANGED` to preserve alpha.

    2. `apply_watermark(frame: np.ndarray, watermark: np.ndarray, position: str = "bottom-right", margin: int = 10, opacity: float = 0.3) -> np.ndarray` — Composites the watermark onto the frame at the specified corner position. Uses alpha blending with the given opacity. Positions: "top-left", "top-right", "bottom-left", "bottom-right".

    3. `process_video(input_path: Path, output_path: Path, thumbnail_path: Path | None = None, logo_path: Path | None = None, skip_watermark_check: bool = False) -> ProcessResult` — The main orchestration function. ProcessResult is a dataclass with fields: `status` ("completed"|"failed"|"flagged_watermark"|"skipped"), `error` (str|None), `duration` (float), `file_size` (int), `source_duration` (float), `output_duration` (float).

    Pipeline steps:
    a. **Probe input** — Get video info (resolution, duration, fps)
    b. **Watermark check** — If not skip_watermark_check, call `has_watermark()`. If detected, return status="flagged_watermark"
    c. **Trim** — Call `detect_movement_range()` to find exercise portion, then `trim_video()` to extract it. Output to temp file.
    d. **Analyze crop** — Sample ~10 frames from trimmed video, run segmentation on each, call `compute_stable_crop()` to get a single stable crop region
    e. **Frame-by-frame processing** — Open trimmed video with OpenCV. For each frame:
       - Apply `smart_crop()` using the pre-computed stable crop region
       - Run `segment_frame()` on the cropped frame
       - Run `style_frame()` with the confidence mask
       - Apply watermark if logo loaded
       - Write styled frame to temp video via `cv2.VideoWriter` (use MJPEG codec for intermediate, not final output)
    f. **Encode** — Call `encode_video()` on the intermediate file to produce final H.264/yuv420p/faststart output
    g. **Loop** — If output is shorter than MIN_DURATION_SECONDS, call `loop_video()`
    h. **Thumbnail** — Call `extract_thumbnail()` on the final output. Default thumbnail path is `output_path.with_suffix('.png')`
    i. **Cleanup** — Remove temp files (trimmed intermediate, pre-encode intermediate)
    j. **Return result** — ProcessResult with stats

    4. `preview_frame(input_path: Path, output_path: Path, logo_path: Path | None = None) -> None` — Preview mode: processes a single frame from the middle of the video and saves as PNG. Useful for QA before running a full batch. Runs the full pipeline on one frame: probe → trim estimate → crop → segment → style → watermark → save PNG.

    Important implementation notes:
    - Create segmenter ONCE at the start of process_video and close it at the end (not per-frame)
    - Write frames to `cv2.VideoWriter` immediately — do NOT accumulate in memory (per research anti-patterns)
    - Use `tempfile.NamedTemporaryFile` for intermediate files, clean up in finally block
    - All errors should be caught and returned in ProcessResult, not raised (batch runner needs non-throwing)
    - Import from config.py: MIN_DURATION_SECONDS, MAX_DURATION_SECONDS, MODEL_PATH, TARGET_FPS
    - Logo asset path defaults to `Path(__file__).parent.parent.parent / "assets" / "logo.png"`

    Use type hints throughout. No `any` types.
