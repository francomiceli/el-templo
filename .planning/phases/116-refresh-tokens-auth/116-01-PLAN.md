Schema esperado (Req 1): refresh_tokens columnas mínimas:

- id (PK autoincrement)
- userId -> users.id (FK, NOT NULL, ON DELETE CASCADE — D-05 defensa futura)
- tokenHash (varchar, unique, sha256 hex del token plano)
- expiresAt (timestamp NOT NULL)
- revokedAt (timestamp NULLABLE)
- replacedById -> refresh_tokens.id (self-FK NULLABLE, rotación, ON DELETE SET NULL)
- createdAt (timestamp NOT NULL default now)
  Index en user_id (token_hash ya cubierto por unique).

RefreshTokenService (constructor DI: db, log):

- issue(userId: number): Promise<string> // devuelve token plano, persiste sha256 + expiresAt = now+30d
- rotate(plainToken: string): Promise<{ newToken: string; userId: number }> // valida; si revokedAt!=null -> revoca familia del user + lanza señal 401; marca viejo revokedAt=now + replacedById=nuevo; devuelve { newToken (plano, expiresAt sliding now+30d), userId del dueño de la fila }. La fila de refresh_tokens (con su user_id) YA está en memoria durante rotate por la query de validación, así que devolver userId es gratis y evita que la ruta tenga que re-derivarlo.
- revoke(plainToken: string): Promise<void> // idempotente
- revokeAllForUser(userId: number): Promise<void> // UPDATE refresh_tokens SET revoked_at=NOW() WHERE user_id=? AND revoked_at IS NULL

Firma access (auth.ts): el access nuevo se firma con fastify.jwt.sign(payload, { expiresIn: process.env.JWT_ACCESS_EXPIRES_IN || "30m" }); el token legacy mantiene el default 7d.

    - issue(userId): genera token plano con `crypto.randomBytes(32).toString("base64url")`, persiste solo `sha256(plain)` hex en token_hash, expires_at = now + 30d, devuelve el plano. El plano NUNCA se persiste.
    - rotate(validPlain): valida existe + no revocado + no expirado; lee la fila (incluye user_id); marca el viejo revoked_at=now y replaced_by_id=nuevo.id; emite nuevo refresh con expires_at = now + 30d (sliding); devuelve `{ newToken: <nuevoPlano>, userId: <user_id de la fila validada> }`.
    - rotate(rotatedPlain) [reuse]: token cuyo revoked_at != null -> revoca TODOS los refresh del mismo user_id (revoked_at IS NULL -> NOW()) y lanza señal 401 (error tipado que la ruta mapea a 401). NO devuelve el objeto.
    - rotate(expiredPlain) / rotate(unknownPlain): señal 401, sin tocar otras filas.
    - revoke(plain): idempotente — marca revoked_at=now si existe y no estaba; no-op si ya revocado/inexistente; nunca lanza.
    - revokeAllForUser(userId): UPDATE refresh_tokens SET revoked_at=NOW() WHERE user_id=? AND revoked_at IS NULL.
  </behavior>
