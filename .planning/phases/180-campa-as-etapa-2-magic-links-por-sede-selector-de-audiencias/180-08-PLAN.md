| API → Resend (envío masivo)                   | Salida a un tercero con direcciones de socios reales              |

| T-180-34  | Tampering              | segmento arbitrario en el body de creación                               | mitigate    | JSON Schema con `enum` derivado de `CAMPAIGN_SEGMENTS` + `additionalProperties: false`; el dispatcher del resolver rechaza desconocidos                   |
| T-180-35  | Elevation of Privilege | admin de un país/tenant envía a la audiencia de otro                     | mitigate    | Se conservan `ADMIN_ROLES`, `attachCountryScope`, `assertTenant` y `scopeCountry` sin cambios; la audiencia se resuelve con `tenantWhere`                 |
