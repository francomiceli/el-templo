## Visual Lineage: LoginPage Continuity

The onboarding flow is a **visual continuation of LoginPage.vue** — same atmospheric world, same tokens, same mood. The user should feel they never left the temple entrance. Every visual decision below derives from the existing login/register pattern.

## Typography

| Role    | Font       | Size             | Weight | Line Height | Letter Spacing | Usage                                                    |
| ------- | ---------- | ---------------- | ------ | ----------- | -------------- | -------------------------------------------------------- |
| Display | Montserrat | 22px (1.375rem)  | 700    | 1.2         | 0.08em         | Welcome screen heading ("Bienvenido, [Nombre]")          |
| Heading | Montserrat | 18px (1.125rem)  | 700    | 1.3         | 0.06em         | Question text on each card                               |
| Body    | Geologica  | 15px (0.9375rem) | 400    | 1.5         | normal         | Option button labels, body copy, result screen summaries |
| Caption | Geologica  | 13px (0.8125rem) | 400    | 1.5         | normal         | Progress indicator labels, subtitle text, secondary info |

**Style variant:** `.text-elegance` applies Cormorant Garamond 400 italic at the Body size (15px) — used for welcome screen subtitle (motivational phrase). This is a typeface/style override, not a separate size tier.

**Weight constraint:** 2 weights only — 700 (Montserrat, for headings and CTAs) and 400 (Geologica, for all body text). CTA labels use Montserrat 700 (not 600) to maintain the 2-weight limit. Summary row values use Geologica 400 (not 500); differentiation from labels is handled by opacity levels, not weight.

Text color: `$cream` (#f2ede5) for all text. Reduced opacity for secondary text:

- Primary text: `$cream` at 100%
- Secondary text: `rgba($cream, 0.7)`
- Tertiary/hint text: `rgba($cream, 0.5)`
- Disabled/ghost text: `rgba($cream, 0.35)`

Text shadow on headings: `0 1px 8px rgba(0, 0, 0, 0.5)` (matches LoginPage `.brand-welcome`).

**Source:** LoginPage.vue `.brand-welcome` (1.35rem, 700, 0.08em), `.brand-subtitle` (0.95rem), `.motivational-hint` (0.8rem).

## Loading & Error States

### Quiz Submission (Result Screen CTA)

When user taps "Entrar al Templo":

1. CTA enters loading state (Quasar `:loading` prop)
2. API call: POST profile + award AURA
3. **Success:** Fade-out transition (same as LoginPage `.login-page--exiting`, opacity 0 over 800ms), then route to `/`
4. **Failure:** CTA exits loading state. `Notify.create({ type: 'negative', message: extractError(err, 'Error al guardar tu perfil. Intenta de nuevo.') })`. CTA remains tappable for retry. Quiz answers preserved in local state.

### Network Failure Mid-Quiz

No network calls during Q1-Q4 (answers stored in local component state). Network only needed on final submission. If the app loses connectivity, the user can still navigate all quiz screens freely. Error surfaces only on submit.

## Transition Specifications

| Transition              | Duration | Easing | Description                                                                                                                         |
| ----------------------- | -------- | ------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| Card forward            | 300ms    | `ease` | Current card slides left + fades out. New card slides in from right + fades in. Use `translateX(-100%)` out, `translateX(100%)` in. |
| Card backward           | 300ms    | `ease` | Current card slides right + fades out. Previous card slides in from left + fades in.                                                |
| Welcome to Q1           | 300ms    | `ease` | Same slide-left as forward.                                                                                                         |
| Q4 to Result            | 300ms    | `ease` | Same slide-left. AURA celebration fires 200ms after card is fully visible.                                                          |
| Exit to app             | 800ms    | `ease` | Full page opacity fade to 0 (matches LoginPage `--exiting` class).                                                                  |
| Progress dot activation | 200ms    | `ease` | Color fill + scale(1.2) on current dot.                                                                                             |
| Option select           | 200ms    | `ease` | Border color + background + shadow transition. Check icon fades in.                                                                 |

Vue implementation: Use `<Transition name="slide-left">` and `<Transition name="slide-right">` with dynamic `:name` binding based on navigation direction.

## Accessibility Notes

- All option buttons are `<button>` elements (or Quasar `q-btn`), not divs with click handlers
- Selected state communicated via `aria-pressed="true"` on option buttons
- Progress dots have `aria-label="Pregunta {n} de 4"` with `aria-current="step"` on active dot
- Back arrow has `aria-label="Volver a la pregunta anterior"`
- CTA buttons have descriptive text (no icon-only buttons)
- Minimum touch target: 48x48px on all interactive elements
- Color contrast: cream (#f2ede5) on charcoal (#2e2a26) = ratio ~11:1 (AAA compliant)
