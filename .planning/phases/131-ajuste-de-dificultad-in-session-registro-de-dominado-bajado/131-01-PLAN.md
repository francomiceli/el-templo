<objective>
Create the persistence layer and member-scoped endpoint for the in-session difficulty adjustment: a new `exercise_adjustments` log table (ADJUST-03), and a `POST /api/exercise-adjustments` endpoint that resolves the neighbor exercise via Phase 126's `getNeighbor` (ADJUST-02), persists a `dominado|bajado` record for the origin exercise, and returns the new exercise (or "no neighbor"). This is the backend foundation the player UI (Plan 03) and the % enrichment + coach view (Plan 02) build on.

Purpose: Today only "completado local + RPE de la sesión entera" exists (`completed_sessions.rpe`). This per-node record is new and is the data model the in-session adjustment rests on (D-01).
Output: New schema + migration 0142, `exercise-adjustments` module (service/routes/schemas/plugin), app registration, integration tests.
</objective>
