Swap rule (D-03): replace ONLY the exercise identity (exerciseId→neighbor.id, exerciseName→neighbor.name, contraction→neighbor.contraction, refetch/clear videoUrl as needed) on the current block's Prescription; KEEP reps/repsMax/seconds/secondsMax/increment/rest/sortOrder and the block format/dose. One step per tap. neighbor null → show message, change nothing.
