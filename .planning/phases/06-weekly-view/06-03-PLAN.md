- `colorClass`: string (for block identity - optional, default 'bg-grey-1')

Template structure using QExpansionItem:
```vue
<template>
  <q-expansion-item
    :class="['block-card', colorClass]"
    expand-separator
    :label="blockLabel"
    :caption="blockCaption"
    header-class="block-card__header"
  >
    <q-card>
      <q-card-section>
        <q-list dense>
          <q-item v-for="(ex, idx) in block.exercises" :key="idx">
            <q-item-section>
              <q-item-label>{{ ex.exerciseName }}</q-item-label>
              <q-item-label caption>
                {{ formatPrescription(ex) }}
              </q-item-label>
            </q-item-section>
            <q-item-section side>
              <q-badge :label="ex.contraction" />
            </q-item-section>
          </q-item>
        </q-list>
      </q-card-section>
    </q-card>
  </q-expansion-item>
</template>
```

Helper function:
- `formatPrescription(ex)`: Returns "X reps" or "X seg" based on which is defined
