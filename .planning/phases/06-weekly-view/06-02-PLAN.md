
Use CSS scroll-snap for smooth snapping:
```css
.week-carousel__scroll {
  display: flex;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
  scroll-behavior: smooth;
  gap: 12px;
  padding: 16px;
  -webkit-overflow-scrolling: touch;
  overscroll-behavior-x: contain;
}

.week-carousel__item {
  flex: 0 0 calc(100% - 64px);
  scroll-snap-align: center;
  transition: opacity 0.2s ease;
}

.week-carousel__item--adjacent {
  opacity: 0.7;
}
```

Logic:
- On mount, scroll to center today's card using scrollIntoView({ behavior: 'smooth', inline: 'center' })
- Track selectedDate from store
- isAdjacent() returns true for days not currently centered
- Use IntersectionObserver to detect which card is centered and update store.selectedDate
- Emit 'day-selected' when user scrolls to a new day
