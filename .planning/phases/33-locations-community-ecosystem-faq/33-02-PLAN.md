- Gallery lightbox: On click of any gallery item, show a fullscreen overlay (`position: fixed; inset: 0; z-index: 1000; background: rgba(61,55,50,0.9)`) displaying the clicked PlaceholderBox at larger size with a close button (X in top-right). Close on click outside or close button. Use a reactive `lightboxIndex` ref (-1 when closed, >= 0 when open). Wire `@click` on each gallery item to open lightbox. Each card: Marble Cream bg, Sandy Beige border, 8px radius, 28px padding, hover translateY(-2px) + shadow-medium. Meta (level + time): Geologica 12px Olive Stone.
- Stats counters: 4 in flex row desktop (gap 64px, centered), 2x2 grid mobile. Each stat: number in Montserrat ExtraBold 40px/32px mobile, Terracotta separator bar (24px wide, 2px high), label in Geologica 14px uppercase Olive Stone. Count-up animation: use a second `useScrollReveal` instance on the stats container. When `revealed` becomes true, animate each stat from 0 to target value over 1500ms with ease-out-cubic easing using `requestAnimationFrame`. Format numbers with `toLocaleString('es-AR')`.
