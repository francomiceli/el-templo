**Create `el-templo-web/components/SectionFaq.vue`:**

Structure per spec10:

- Section: `<section id="faq" class="faq">` with Marble Cream background
- Header: tag "FAQ", H2 "LO QUE TODOS PREGUNTAN." (no subtitle per spec)
- Accordion container: max-width 800px, centered

Accordion logic (in `<script setup>`):

- Reactive `openIndex` ref initialized to `0` (first item open by default)
- `toggle(index)` function: if `openIndex === index`, set to `-1` (close all); otherwise set to `index` (open clicked, close previous). This ensures only 1 open at a time.
- Template: `v-for` over faqItems with index. Each item:
  - `<div class="faq__item" :class="{ 'faq__item--active': openIndex === index }">`
  - `<button class="faq__question" :aria-expanded="openIndex === index ? 'true' : 'false'" @click="toggle(index)">`
    - `<span>{{ question }}</span>` (use HTML entities for accents)
    - `<span class="faq__icon">` -- render `+` when closed, CSS rotates to minus via `transform: rotate(45deg)` on the `+` character when active (per spec10 CSS and CONTEXT.md decision: "CSS-only with ::before pseudo-element")
  - `<div class="faq__answer" role="region" :hidden="openIndex !== index">`
    - `<p>{{ answer }}</p>`

CONTEXT.md decision: Icon toggle uses CSS-only with pseudo-element. Implementation: Use a `+` character in the icon span. When active, CSS `transform: rotate(45deg)` makes it look like an `x` (close to minus). The spec10 CSS uses this exact pattern: `.faq__item--active .faq__icon { transform: rotate(45deg); }`.

CSS per spec10-pt2 (full specs provided):

- `.faq` padding: 80px desktop, 64px mobile
- `.faq__container` max-width: 800px, centered
- `.faq__item` border-bottom: 1px solid Warm Stone
- `.faq__question`: flex space-between, no border/bg, 20px padding vertical, Montserrat Semibold 16px/14px mobile, hover color Terracotta
- `.faq__icon`: Montserrat Light 24px, Terracotta color, `transition: transform 300ms ease`, flex-shrink 0, margin-left 16px
- `.faq__item--active .faq__icon`: `transform: rotate(45deg)`
- `.faq__answer`: `max-height: 0; overflow: hidden; opacity: 0; transition: max-height 400ms ease, opacity 300ms ease`
- `.faq__item--active .faq__answer`: `max-height: 500px; opacity: 1`
- `.faq__answer p`: Geologica Regular 15px/14px mobile, Charcoal Mist color, line-height 1.6, padding-bottom 20px

Note: The `hidden` attribute on `.faq__answer` provides accessibility semantics. The CSS max-height/opacity handles the visual animation. When `openIndex !== index`, the answer div gets `hidden` attribute AND CSS max-height: 0. When active, `hidden` is removed and CSS transitions to max-height: 500px.

Include `@media (prefers-reduced-motion: reduce)` to disable transition animations.

Use HTML entities for all accented characters in the template (question marks included: `&iquest;`).
