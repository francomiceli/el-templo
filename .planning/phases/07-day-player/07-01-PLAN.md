**useWakeLock.ts:**
Create composable managing screen wake lock with dual implementation:
1. Web: Use Screen Wake Lock API (navigator.wakeLock.request('screen'))
2. Native: Use @capacitor-community/keep-awake plugin

Key behaviors:
- requestWakeLock(): Acquire lock, track active state
- releaseWakeLock(): Release lock on cleanup
- Re-acquire on visibility change (document.visibilityState === 'visible')
- Conditional import of Capacitor plugin (only on native)
- Returns { isActive, isSupported, requestWakeLock, releaseWakeLock }

Reference RESEARCH.md "Pattern 2: Screen Wake Lock Composable".

**useSessionPlayer.ts:**
Create composable managing session playback state:

1. Accept Session as parameter
2. State refs: currentBlockIndex, selectedExerciseIndex, elapsedSeconds
3. Computed for block flow (filters to 4 blocks after Deuteros choice)
4. Timer management: startTimer(), pauseTimer() with setInterval
5. Block completion: completeBlock() updates store and advances
6. Deuteros selection: selectDeuteros(choice) saves to store
7. Cleanup: clear timer on unmount

Key insight: Progress is based on 4 blocks (Initium, Nucleus, one Deuteros, Athlos), not 5.

Reference RESEARCH.md "Pattern 1: Session Player Composable".
