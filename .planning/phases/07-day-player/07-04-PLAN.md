  <name>Task 2: Implement block flow, exit confirmation, and wake lock</name>
  <files>el-templo-app/src/modules/training/pages/DayPlayer.vue</files>
  <action>
Complete the DayPlayer.vue with block flow logic, exit confirmation, and wake lock.

**Block flow implementation:**
1. On splash complete: dismiss splash, start timer, request wake lock
2. After Nucleus completion: check if Deuteros choice needed, show DeuterosChoice
3. On Deuteros select: save choice, advance to chosen Deuteros block
4. On block complete:
   - Call completeBlock() from useSessionPlayer
   - If all 4 blocks done: release wake lock, navigate away or show completion
   - Otherwise: advance to next block
5. Exercise selection: when selectedIndex changes, update video URL (placeholder for now)

**Exit confirmation (onBeforeRouteLeave):**
Reference RESEARCH.md "Pattern 3: Exit Confirmation with Navigation Guard".
- If !hasUnsavedProgress: return true (allow navigation)
- If hasUnsavedProgress: show Quasar dialog
  - Title: "Salir del entrenamiento?"
  - Message: "Tu progreso en este bloque se perdera. Puedes continuar desde el inicio del bloque actual mas tarde."
  - Cancel: "Cancelar" (flat)
  - OK: "Salir" (negative color)
- Return Promise that resolves based on dialog result
- Also add beforeunload handler for browser close/refresh

**Wake lock management:**
- Request wake lock when splash completes (workout starts)
- Release wake lock when:
  - Session completes (all 4 blocks)
  - User exits via navigation
- Re-acquire on visibility change (handled by useWakeLock)

**Lifecycle:**
- onMounted: Load session, load persisted progress
- onUnmounted: Release wake lock, clear timers

**Session completion handling:**
- After all 4 blocks complete:
  - Clear persisted progress (clearProgress)
  - Show brief completion message (toast or inline)
  - Navigate back to training view

**Style (scoped, SCSS):**
- .day-player: full height, flex column
- .day-player__header: padding, flex row, space-between
- .day-player__action: fixed bottom, full width, padding, z-index above content
- Account for safe areas (padding-bottom for notch devices)
