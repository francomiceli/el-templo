**Navigation guard (onBeforeRouteLeave):**
Reference RESEARCH.md "Pattern 3: Exit Confirmation with Navigation Guard".

```typescript
onBeforeRouteLeave(async (_to, _from) => {
  if (!hasUnsavedProgress.value) {
    return true // Allow navigation
  }

  return new Promise<boolean>((resolve) => {
    $q.dialog({
      title: 'Salir del entrenamiento?',
      message: 'Tu progreso en este bloque se perdera. Puedes continuar desde el inicio del bloque actual mas tarde.',
      cancel: {
        label: 'Cancelar',
        flat: true
      },
      ok: {
        label: 'Salir',
        color: 'negative'
      },
      persistent: true
    }).onOk(() => {
      wakeLock.release()
      resolve(true)
    }).onCancel(() => {
      resolve(false)
    })
  })
})
```

**beforeunload handler:**
```typescript
const handleBeforeUnload = (e: BeforeUnloadEvent) => {
  if (hasUnsavedProgress.value) {
    e.preventDefault()
    e.returnValue = ''
  }
}
```

**Lifecycle hooks:**

onMounted:
- Add beforeunload listener: window.addEventListener('beforeunload', handleBeforeUnload)
- Load persisted progress from sessionPlayerStore if exists
- Initialize sessionPlayer with session data

onUnmounted:
- Remove beforeunload listener: window.removeEventListener('beforeunload', handleBeforeUnload)
- Clear timer if running: if (timerInterval.value) clearInterval(timerInterval.value)
- Release wake lock if active: wakeLock.release()

**Wake lock integration:**
- Initialize: const wakeLock = useWakeLock()

**Session completion handling:**
