**FIX-01: Scheduler column name mismatches**

**FIX-02: OpenAI tool_calls on assistant messages**

In `el-templo-bot/src/ai/openai.ts`, the `mapMessage` method for `assistant` role currently returns `{ role: "assistant", content: msg.content }` and does NOT include `tool_calls` when `msg.toolCalls` is present. OpenAI's API requires that if a subsequent message has `role: "tool"` referencing a `tool_call_id`, the preceding `assistant` message MUST include the `tool_calls` array.

Update the `case "assistant"` in `mapMessage` to:

```typescript
case "assistant": {
  if (msg.toolCalls && msg.toolCalls.length > 0) {
    return {
      role: "assistant" as const,
      content: msg.content,
      tool_calls: msg.toolCalls.map((tc) => ({
        id: tc.id,
        type: "function" as const,
        function: {
          name: tc.name,
          arguments: JSON.stringify(tc.arguments),
        },
      })),
    };
  }
  return { role: "assistant", content: msg.content };
}
```

This mirrors what the Anthropic provider already does correctly in its `mapMessages` method (lines 128-147 of anthropic.ts).
