<interfaces>
Contrato del endpoint que consume el plan 07:

```
POST /api/admin/gym/exercises/:id/copy      (sin body)
  201 → ExerciseDetail de la copia (scope: 'copia', status: 'publicado')
  403 → el id no es un ejercicio global
  404 → el id no existe o no es visible para este gimnasio
  409 → { error, code: "EXERCISE_COPY_EXISTS", message,
          existingExerciseId: number, existingStatus: GymExerciseStatus }
```

`GymExerciseScope` pasa de `'global' | 'propio'` a `'global' | 'propio' | 'copia'`.
</interfaces>
