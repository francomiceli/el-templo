<interfaces>
```
PATCH /api/admin/gym/exercises/:id/status
  body: { status: 'publicado' | 'desactivado' }   (additionalProperties: false)
  200 → ExerciseDetail actualizado
  403 → el ejercicio es global (los estados del catálogo global los maneja la plataforma)
  404 → no existe o es de otro gimnasio
  409 → { code: "EXERCISE_TRANSITION_INVALID" } transición no permitida desde el estado actual
```
`borrador` no es un destino admitido por API: no hay forma de "despublicar a borrador" (Definición 2).
</interfaces>
