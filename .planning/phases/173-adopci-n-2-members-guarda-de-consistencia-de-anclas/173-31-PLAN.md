<threat_model>

## Trust Boundaries

| Boundary                      | Description                                                                             |
| ----------------------------- | --------------------------------------------------------------------------------------- |
| rama local → `origin/staging` | un push publica código a medio verificar en el entorno que el staff prueba              |
| rama local → `origin/master`  | master es **producción**: un merge equivocado deploya la fase sin el milestone completo |
| merge → deploy                | `git log` prueba el merge, no el deploy ni la migración                                 |
| diff vacío → confianza        | un `truncado: true` en la captura haría comparar contra una base incompleta en silencio |

## STRIDE Threat Register

| Threat ID   | Category               | Component                                            | Disposition | Mitigation Plan                                                                               |
| ----------- | ---------------------- | ---------------------------------------------------- | ----------- | --------------------------------------------------------------------------------------------- |
| T-173-31-01 | Elevation of Privilege | merge a master en vez de staging                     | mitigate    | D-17 explícito en el checkpoint; el destino es `origin/staging` y el OK humano es por escrito |
| T-173-31-02 | Repudiation            | snapshot "después" truncado                          | mitigate    | criterio de verificación que exige `truncado: false` en todos los endpoints antes de comparar |
| T-173-31-03 | Repudiation            | divergencia del diff ignorada                        | mitigate    | cada divergencia se explica campo por campo; si alguna no se explica, no se mergea            |
| T-173-31-04 | Denial of Service      | migración 0198 no aplicada en el deploy              | mitigate    | verificación post-merge de que el runner la registró en `_migrations` de la base de staging   |
| T-173-31-05 | Denial of Service      | bomba FK latente re-barajada por los archivos nuevos | mitigate    | diagnóstico documentado: `ER_ROW_IS_REFERENCED_2` en archivo ajeno es limpieza, no sentinel   |

| T-173-31-07 | Repudiation            | cambio de orden de listados                          | mitigate    | el diff no lo compara a propósito; el punto 5 del UAT lo mira explícitamente                  |
