**1. Create MemberFormDialog.vue** (`el-templo-admin/src/components/MemberFormDialog.vue`):

A QDialog component used for both creating and editing members. Props:

- `modelValue: boolean` (v-model for dialog open/close)
- `member?: MemberProfile | null` (null = create mode, object = edit mode)
- `branches: Array<{ id: number; name: string }>` (for branch dropdown)

Emits: `update:modelValue`, `saved` (when create/update succeeds — parent reloads list)

Structure:

- Dialog title: "Crear Alumno" or "Editar Alumno" based on mode
- Form fields organized in sections using QCard sections:
  - **Datos Personales**: firstName (required), lastName (required), email (required, disabled in edit mode), password (required in create only, hidden in edit), phone (required), dni (required)
  - **Sede y Nivel**: branchId (QSelect dropdown, required), level (QSelect dropdown, default 'alfa')
  - **Datos Adicionales** (collapsible QExpansionItem): dateOfBirth (QInput type="date"), gender (QSelect: Masculino/Femenino/Otro mapping to male/female/other)
  - **Contacto de Emergencia** (collapsible QExpansionItem): emergencyContactName, emergencyContactPhone, emergencyContactRelationship
- All fields use QInput/QSelect with `dense outlined` style, validation rules on required fields
- DNI field: Add `@update:model-value` with debounce (500ms). Call `useMembersApi().checkDni(dni, member?.id)`. Show inline warning message below the field if `available === false`: "DNI ya registrado para [existingMemberName]" in orange text. Show green check icon if available.
- Submit button: "Crear" or "Guardar" based on mode. Disabled while loading.
- On submit: validate form (QForm ref + validate()), call createMember or updateMember via composable, emit 'saved', close dialog.
- Use `createLogger('MemberFormDialog')` for error logging.
