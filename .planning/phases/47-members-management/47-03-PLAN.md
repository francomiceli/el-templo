**1. Create MemberProfileTab.vue** (`el-templo-admin/src/components/MemberProfileTab.vue`):

A read-only display component showing all member profile fields. Props:

- `member: MemberProfile`

Layout — three QCard sections:

- **Datos Personales**: Display fields in a 2-column responsive grid (`row q-col-gutter-md`). Fields: Email, Telefono, DNI, Fecha de Nacimiento (formatted), Genero (translated: male→Masculino, female→Femenino, other→Otro). Each field: label in `text-caption text-grey-7`, value below in `text-body1`. Show "—" for null values.
- **Sede y Nivel**: Branch name, Level (display full name like "Alfa" not just Greek letter), Fecha de Alta (createdAt formatted).
- **Contacto de Emergencia**: Name, phone, relationship. If all three are null, show "Sin contacto de emergencia registrado" in italic grey.

No edit functionality here — editing is done through MemberFormDialog triggered from the header.

**2. Create MemberNotesTab.vue** (`el-templo-admin/src/components/MemberNotesTab.vue`):

Props:

- `userId: number`
- `currentUserId: number` (the logged-in coach/admin)
- `currentUserRole: string` (for edit/delete permission checks)

State: `notes` ref, `newNoteContent` ref, `editingNoteId` ref, `editContent` ref.

Layout:

- **Add note section** at top: QInput (type textarea, rows 2, outlined) with "Agregar nota" placeholder + QBtn "Agregar" (disabled if content empty or loading). On submit: call createNote, clear input, prepend to notes list.
- **Notes timeline**: QList with separator. Each note item:
  - Left: QAvatar with author initials (first letter of firstName + lastName)
  - Content: Author name in bold, date/time in caption (`formatDistance` or simple date format), note content text
  - Right side: QBtn icons for edit (pencil) and delete (trash) — only shown if `canEdit(note)`. canEdit logic: note.authorId === currentUserId OR currentUserRole is 'admin' or 'superadmin'.
  - Edit mode: When editing, replace the content text with a QInput textarea + Save/Cancel buttons. On save: call updateNote, update in list. On cancel: reset editingNoteId.
  - Delete: QDialog confirmation "Eliminar esta nota?" then call deleteNote, remove from list.
- **Empty state**: "Sin notas" italic grey text when notes array is empty.
- **Loading**: QSpinner while notes are being fetched.

On mount: load notes via useMembersApi().getNotes(userId). Use `createLogger('MemberNotesTab')`.
