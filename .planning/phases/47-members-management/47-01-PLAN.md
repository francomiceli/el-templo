**5. Create members module types** (`el-templo-api/src/modules/members/types.ts`):
Define interfaces:

- `MemberListParams`: { search?, branchId?, level?, isActive?, page, limit }
- `MemberListItem`: { id, email, firstName, lastName, phone, dni, level, branchId, branchName, isActive, createdAt }
- `MemberProfile`: Full member profile including all new fields
- `CreateMemberInput`: { email, password, firstName, lastName, phone, dni, branchId, level?, dateOfBirth?, gender?, emergencyContactName?, emergencyContactPhone?, emergencyContactRelationship? }
- `UpdateMemberInput`: Partial of profile fields (no password, no id)
- `MemberNote`: { id, userId, authorId, authorName, content, createdAt, updatedAt }
- `CreateNoteInput`: { userId, content }
- `UpdateNoteInput`: { content }

**6. Create Fastify JSON schemas** (`el-templo-api/src/modules/members/schemas.ts`):
Request/response validation schemas for each endpoint. Follow the pattern in journeys/schemas.ts. Include body schemas for create/update member, query schemas for list params, param schemas for :userId and :noteId.

**7. Create MemberService** (`el-templo-api/src/modules/members/service.ts`):
Constructor DI pattern: `constructor(private db: DB, private log: FastifyBaseLogger)`.
Methods:

- `listMembers(params: MemberListParams)` — Build dynamic WHERE with search (LIKE on firstName, lastName, email, dni), optional branchId eq, optional level eq, optional isActive eq. Return paginated results with total count. Join branches for branchName.
- `getMemberById(id: number)` — Full profile with branch name. Return null if not found.
- `createMember(input: CreateMemberInput)` — Hash password with argon2, insert user, return created member.
- `updateMember(id: number, input: UpdateMemberInput)` — Partial update, return updated member. Do NOT allow changing email or password through this method.
- `toggleActive(id: number, isActive: boolean)` — Set isActive, return updated member.
- `checkDniUniqueness(dni: string, excludeUserId?: number)` — Return { available: boolean, existingMemberName?: string }.
- `getNotes(userId: number)` — List notes for user, ordered by createdAt DESC. Join users on authorId for authorName (firstName + lastName).
- `createNote(authorId: number, input: CreateNoteInput)` — Insert note, return it with author info.
- `updateNote(noteId: number, input: UpdateNoteInput)` — Update content, return updated note.
- `deleteNote(noteId: number)` — Delete note.
- `canEditNote(noteId: number, userId: number, userRole: string)` — Author can edit their own notes; admin/superadmin can edit/delete any note. Return boolean.

**8. Create routes** (`el-templo-api/src/modules/members/routes.ts`):
All routes require authentication and coach/admin/superadmin role. Use the `ADMIN_ROLES` pattern from journeys/routes.ts.

Endpoints:

- `GET /admin/members` — List members (MEMB-01). Query params: search, branchId, level, isActive, page, limit.
- `GET /admin/members/:userId` — Get member profile (MEMB-02). Return full profile.
- `POST /admin/members` — Create member (MEMB-03). Body: CreateMemberInput. Return 201 with member.
- `PUT /admin/members/:userId` — Update member (MEMB-04). Body: UpdateMemberInput. Return updated member.
- `PATCH /admin/members/:userId/status` — Toggle active status (MEMB-05). Body: { isActive: boolean }. Return updated member.
- `GET /admin/members/check-dni?dni=X&excludeUserId=Y` — DNI uniqueness check. Return { available, existingMemberName? }.
- `GET /admin/members/:userId/notes` — List notes (MEMB-06).
- `POST /admin/members/:userId/notes` — Create note. Body: { content }.
- `PUT /admin/members/:userId/notes/:noteId` — Update note. Check canEditNote first.
- `DELETE /admin/members/:userId/notes/:noteId` — Delete note. Check canEditNote first.

Register as Fastify plugin, prefix handled by app registration.
