<objective>
Implementar el endpoint backend `POST /api/bar-challenge/result` con enforcement atómico de single-attempt vía UPDATE condicional. Body validado con zod inline, response shape definido para éxito (200) y conflicto (409). Integration test cubre los 4 casos de aceptación del SPEC R2 + R11.

Purpose: Persistir el intento del usuario y bloquear reintentos en una sola query atómica (no SELECT + UPDATE), evitando race conditions. Frontend (Plan 05) hace POST optimistic y muestra UI inmediatamente; este endpoint es la única fuente de verdad para "ya participó".
Output: Módulo backend nuevo, montado en `/api/bar-challenge`, con tests verdes.
</objective>
