## Typography

**Base UI scale (4 sizes, 2 weights — applies to all interactive surfaces):**

| Role                                                           | Size | Weight                            | Line Height                                                         | Family                                                                                               |
| -------------------------------------------------------------- | ---- | --------------------------------- | ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Meta / muted / chip label                                      | 12px | 400 (meta) / 600 (chip uppercase) | 1.4 (meta) / 1.2 (chip)                                             | Geologica (meta) / Montserrat uppercase, letter-spacing 0.5px (chip — matches `UpsellBadge.vue:219`) |
| Body / CTA / timer status label                                | 14px | 400 (body) / 600 (CTA + status)   | 1.5 (body) / 1.2 (CTA) / 1.4 (status uppercase, letter-spacing 1px) | Geologica (body) / Montserrat (CTA + status)                                                         |
| Card heading                                                   | 20px | 600                               | 1.2                                                                 | Montserrat                                                                                           |
| Screen heading (explainer + resultado headline when text-only) | 28px | 600                               | 1.2                                                                 | Montserrat                                                                                           |

**Sizes declared: 4 (12, 14, 20, 28). Weights declared: 2 (400 regular, 600 semibold).**

The chip's visual distinction from 12px meta is carried by `text-transform: uppercase` + `letter-spacing: 0.5px` + `Montserrat 600` (vs Geologica 400 for meta) — typography variant, not size variant. CTA at 14/600 is unified with body+status at 14 — weight + casing differentiate role, not size.

---

**Display tokens (presentation-only, outside the UI scale):**

These are reserved exclusively for the two display moments (timer digit cluster, resultado headline numeric). They do not appear in any interactive UI surface and are not counted against the base scale.

| Role                                 | Size  | Weight | Line Height | Family                                                                            | Where                                                                                                           |
| ------------------------------------ | ----- | ------ | ----------- | --------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Timer digits                         | 120px | 800    | 1.0         | Montserrat, `font-variant-numeric: tabular-nums`, `font-feature-settings: 'tnum'` | `Timer.vue` centered digit cluster only                                                                         |
| Resultado seconds (numeric headline) | 64px  | 800    | 1.0         | Montserrat tabular-nums                                                           | `Resultado.vue` "Aguantaste {N} segundos" — the `{N}` token only; surrounding words use the 28px screen heading |

**Why 800 weight on display tokens:** the gold-gradient success state on `Timer.vue` (when `secondsHeld >= 90`) and the gold-gradient resultado headline (when `completed=true`) need the heaviest stroke to render the gradient legibly at the digit's optical scale. Dropping to 600 visibly thins the gradient — locked at 800 for these two display moments only.

**Tabular-nums enforcement:** `Timer.vue` and `Resultado.vue` MUST apply `font-variant-numeric: tabular-nums` on any element rendering numeric values (timer ticks, second counts). This prevents horizontal jitter as digits change each second.

**Accent reserved for:**

1. The shimmer border around the premium card (existing pattern).
2. The "Desafío" chip label on `BarChallengeCard`.
3. The "Iniciar desafío" / "Comenzar" / "Finalizar" / "Tomar foto" / "Compartir" CTAs (gradient `#c4956a → #a07850`).
4. The success state on `/timer` (digits + status label switch to gold gradient when `secondsHeld >= 90`).
5. The "Aguantaste Xs" headline on `/resultado` when `completed=true` (gold gradient).
6. The non-blocking retry banner on `/resultado` (gold-tinted, low alpha).

**Accent NOT used for:**

- Body text, navigation chrome, system UI, status bar, or any non-event surface.
- The motivational message when `completed=false` (cream, not gold — gold is earned).

## Interaction & State Contract

| State                      | Trigger                                                      | Visual change                                                                                                                                                                                                                                     |
| -------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Timer running, pre-90s     | `secondsHeld < 90`                                           | Cream digits (`#f0e6d6`), status label `AGUANTÁ` in cream                                                                                                                                                                                         |
| Timer success transition   | `secondsHeld === 90` (exact)                                 | Digits + status label switch to gold gradient (`#c4956a → #dcbe82`). Label text changes to `¡LO LOGRASTE! SEGUÍ AGUANTANDO`. No haptic, no sound (SPEC R6 lock). Transition is `200ms ease` color fade. Cronómetro does NOT pause                 |
| Timer with camera open     | User taps "Tomar foto"                                       | Native Capacitor camera takes over fullscreen. Timer continues in background. On return, digits jump-update to real elapsed (D-09) — no animation, just correct value                                                                             |
| Timer finalize             | User taps "Finalizar"                                        | Cronómetro stops on current value. Navigate to `/desafio-barra/resultado`. No confirmation dialog                                                                                                                                                 |
| Resultado optimistic       | Navigation arrival                                           | Show full UI immediately with cached `secondsHeld` + `photoBase64`. POST happens in background (D-10)                                                                                                                                             |
| Resultado retry-pending    | POST failed all 3 retries                                    | Show gold-tinted non-blocking banner at top of content area. UI remains fully interactive                                                                                                                                                         |
| Card "ya participaste"     | `user.barChallengeAttemptedAt !== null` after window refresh | Chip remains `DESAFÍO`. Heading swaps to `Lograste el desafío` or `Tu intento quedó`. CTA swaps to `Compartir foto` (if photo cached) or `Ver mi intento` (no photo). Tap navigates direct to `/resultado` (single-attempt enforcement, SPEC R11) |
| Permission denied — camera | OS returns denied                                            | Inline cream error message under "Tomar foto" CTA. CTA stays visible but disabled. Timer and Finalizar flow unaffected (SPEC acceptance criterion)                                                                                                |

**Touch targets:** All CTAs minimum 44px tall (iOS HIG + Material) — existing `cta.radius:10px + padding:8px 18px + label:14/600` produces ~36px; bump padding on this phase's CTAs to `12px 20px` for a 44px target on `Timer.vue` (critical — operated by staff possibly with sweaty hands).

**Animation budget:** Only the existing shimmer border animation (already in `UpsellBadge.vue`). The 90s success transition is a 200ms color fade. No other animations introduced — keep the timer screen visually calm.
