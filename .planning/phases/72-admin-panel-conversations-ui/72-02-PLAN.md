**1. Create types/whatsapp.ts:**
Mirror the API types (from el-templo-api/src/modules/whatsapp/types.ts but updated):
- ConversationStatus = "active" | "human_takeover" | "closed"
- ClientState = "lead" | "trial" | "active_member" | "inactive_member" | "expired_member"
- MessageDirection = "inbound" | "outbound_bot" | "outbound_human"
- ConversationRecord interface (id, phone, contactName, status, clientState, linkedMemberId, linkedMemberName, lastMessageAt, lastMessagePreview, messageCount, createdAt, updatedAt)
- MessageRecord interface (id, conversationId, direction, content, messageType, createdAt)
- ConversationListParams (status?, clientState?, search?, page, limit)

**2. Create composables/useWhatsappApi.ts:**
Follow useMembersApi.ts pattern exactly:

- `const loading = ref(false)` and `const error = ref<string | null>(null)`
- `getConversations(params?: Partial<ConversationListParams>)` -> GET `/admin/whatsapp/conversations` with params, returns `{ conversations, total, page, limit }`
- `getConversation(id: number, messagePage?: number, messageLimit?: number)` -> GET `/admin/whatsapp/conversations/${id}` with query params, returns `{ conversation, messages, totalMessages }`
- `getActiveCount()` -> GET `/admin/whatsapp/conversations?status=active&limit=1` to get total count for badge (reuses list endpoint, uses limit=1 not limit=0 to avoid Fastify schema validation rejection). Extract and return `data.total` as number.
- `cleanup()` method that resets loading and error
- All methods: set loading, clear error, try/catch with extractError, finally set loading false
- Use `api` from `src/boot/axios`

**3. Create pages/ConversacionesPage.vue:**
Follow AlumnosPage.vue as layout reference. Use Quasar components.

Template structure:

- q-page with padding
- Header row: h5 "WhatsApp Conversaciones" + filter controls
- Filter bar: q-input for search (with debounce 300ms, clearable, prepend search icon), q-select for status filter (options: all/active/human_takeover/closed), q-select for clientState filter (options: all/lead/trial/active_member/inactive_member/expired_member)
- q-table displaying conversations with columns: contactName (or phone if null), phone, status (q-badge with color), clientState (q-badge), last message preview (truncated to 50 chars), lastMessageAt (formatted relative time), messageCount
- Row click navigates to `/conversaciones/${row.id}` using router.push
- Pagination: use q-pagination component bound to current page, total pages computed from total/limit
- Loading state: q-inner-loading on the table area
- Empty state: "No hay conversaciones" message

Script setup:

- Import useWhatsappApi, useRouter
- Reactive state: conversations ref, total ref, filters (search, status, clientState, page, limit=20)
- watch filters with immediate: true to call loadConversations
- Status badge colors: active=green, human_takeover=orange, closed=grey
- ClientState badge colors: lead=blue, trial=purple, active_member=green, inactive_member=orange, expired_member=red
- Format lastMessageAt as relative time (e.g., "hace 5 min") using simple date helper or just Intl.DateTimeFormat
- Use createLogger from src/utils/logger.ts for any error logging (never console.log)

Script setup:

- Get conversation id from route.params.id

- Format timestamps: use Intl.DateTimeFormat for HH:mm display
