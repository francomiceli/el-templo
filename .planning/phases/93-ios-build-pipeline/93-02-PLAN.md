**5. Add version extraction step (after CocoaPods install, before certificate import):**

```yaml
- name: Extract version
  id: version
  run: |
    VERSION=$(grep 'MARKETING_VERSION' el-templo-app/src-capacitor/ios/App/App.xcodeproj/project.pbxproj | head -1 | sed 's/.*= *\(.*\);/\1/' | tr -d ' ')
    SHORT_SHA=$(echo "${{ github.sha }}" | cut -c1-7)
    echo "name=v${VERSION}-${SHORT_SHA}" >> $GITHUB_OUTPUT
    echo "Version: $VERSION, Build: ${{ github.run_number }}, SHA: ${SHORT_SHA}"
```

**6. xcodebuild archive with CURRENT_PROJECT_VERSION override:**

```yaml
- name: Build and archive
  working-directory: el-templo-app/src-capacitor/ios/App
  run: |
    xcodebuild -workspace App.xcworkspace \
      -scheme App \
      -sdk iphoneos \
      -configuration Release \
      -archivePath $RUNNER_TEMP/app.xcarchive \
      archive \
      CODE_SIGN_STYLE=Manual \
      CURRENT_PROJECT_VERSION=${{ github.run_number }}
```

Key addition: `CURRENT_PROJECT_VERSION=${{ github.run_number }}` mirrors Android's `VERSION_CODE: ${{ github.run_number }}`. This auto-increments the CFBundleVersion with each workflow run.

**7. Version-tagged artifact upload with 90-day retention:**

```yaml
- name: Upload IPA as artifact
  if: always()
  uses: actions/upload-artifact@v4
  with:
    name: production-ipa-${{ steps.version.outputs.name }}
    path: ${{ runner.temp }}/export/*.ipa
    retention-days: 90
    if-no-files-found: warn
```

Changed from staging's 30-day to production's 90-day retention. Name includes version tag.

**8. Keep ALL other steps identical to staging:** Certificate import, provisioning profile import, ExportOptions.plist creation, IPA export, TestFlight upload, and keychain cleanup. These are the same for both staging and production (both use App Store distribution signing, both upload to App Store Connect via altool).

<threat_model>

## Trust Boundaries

| Boundary                        | Description                                                        |
| ------------------------------- | ------------------------------------------------------------------ |
| GitHub Secrets -> macOS Runner  | Certificate .p12 and API .p8 key decoded on ephemeral runner       |
| macOS Runner -> Apple servers   | altool authenticates and uploads IPA to App Store Connect          |
| GitHub Actions -> Xcode project | Workflow injects build settings (signing, version) into xcodebuild |

## STRIDE Threat Register

| Threat ID | Category               | Component                         | Disposition | Mitigation Plan                                                                                  |
| --------- | ---------------------- | --------------------------------- | ----------- | ------------------------------------------------------------------------------------------------ |
| T-93-04   | Spoofing               | workflow_dispatch from non-master | mitigate    | Master branch guard rejects non-master triggers with explicit error message                      |
| T-93-05   | Information Disclosure | .p12 cert on runner filesystem    | mitigate    | Keychain cleanup step (`security delete-keychain`) runs in `if: always()` block, even on failure |
| T-93-06   | Information Disclosure | .p8 API key on runner filesystem  | mitigate    | Runner temp directory is ephemeral; key exists only for upload step duration                     |
| T-93-07   | Denial of Service      | macOS runner costs                | accept      | workflow_dispatch (manual only) prevents accidental triggers; no push/PR triggers                |
| T-93-08   | Tampering              | Build number manipulation         | accept      | github.run_number is monotonically increasing and controlled by GitHub, not user input           |

</threat_model>
