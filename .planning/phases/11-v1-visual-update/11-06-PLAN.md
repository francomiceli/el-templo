<task type="auto">
  <name>Task 2: Install @capacitor/assets and generate platform icons</name>
  <files>
    el-templo-app/src-capacitor/ios/App/App/Assets.xcassets
    el-templo-app/src-capacitor/android/app/src/main/res
  </files>
  <action>
1. Install @capacitor/assets as dev dependency in src-capacitor:
   ```bash
   cd el-templo-app/src-capacitor
   pnpm add -D @capacitor/assets
   ```

2. Navigate back to el-templo-app root (where assets/ folder is):
   ```bash
   cd el-templo-app
   ```

3. Run the asset generation command:
   ```bash
   npx @capacitor/assets generate \
     --iconBackgroundColor '#f5f0e8' \
     --iconBackgroundColorDark '#1a2a3e' \
     --splashBackgroundColor '#f5f0e8' \
     --splashBackgroundColorDark '#1a2a3e' \
     --logoSplashScale 0.3 \
     --ios \
     --android
   ```

   This generates:
   - iOS: All AppIcon sizes (20x20 to 1024x1024) in Assets.xcassets
   - iOS: LaunchImage for splash screen
   - Android: mipmap-* folders with all density icons (mdpi to xxxhdpi)
   - Android: Adaptive icon foreground/background
   - Android: Splash screen drawable

4. If generation fails, try without dark mode:
   ```bash
   npx @capacitor/assets generate \
     --iconBackgroundColor '#f5f0e8' \
     --splashBackgroundColor '#f5f0e8' \
     --logoSplashScale 0.3
   ```

5. Verify generated files exist:
   ```bash
   ls el-templo-app/src-capacitor/ios/App/App/Assets.xcassets/AppIcon.appiconset/
   ls el-templo-app/src-capacitor/android/app/src/main/res/mipmap-xxxhdpi/
   ```

Important: The background colors (#f5f0e8 cream and #1a2a3e navy) match the brand palette for consistent appearance.
  </action>
  <verify>
Check iOS icons: `ls el-templo-app/src-capacitor/ios/App/App/Assets.xcassets/AppIcon.appiconset/*.png | wc -l`
Should show multiple PNG files (varies by iOS version requirements).

Check Android icons: `ls el-templo-app/src-capacitor/android/app/src/main/res/mipmap-xxxhdpi/`
Should show ic_launcher.png and potentially ic_launcher_foreground.png for adaptive icons.
  </verify>
  <done>
@capacitor/assets installed in src-capacitor
iOS AppIcon.appiconset populated with icon PNGs
Android mipmap-* folders populated with launcher icons
Splash screen assets generated with cream background
  </done>
