<task type="auto">
  <name>Task 2: Set up app.scss with font imports and global styles</name>
  <files>
    el-templo-app/src/css/app.scss
  </files>
  <action>
Update `app.scss` with:

1. Font imports from @fontsource/cinzel:
   ```scss
   // Import Cinzel font (classical serif for headings)
   @import '@fontsource/cinzel/400.css';
   @import '@fontsource/cinzel/700.css';
   ```

2. Custom heading font family variable:
   ```scss
   $heading-font: 'Cinzel', Georgia, 'Times New Roman', serif;
   ```

3. Apply Cinzel to Quasar heading classes:
   ```scss
   h1, h2, h3, h4,
   .text-h1, .text-h2, .text-h3, .text-h4, .text-h5, .text-h6 {
     font-family: $heading-font;
   }
   ```

4. Block name specific styling utility class:
   ```scss
   .block-name-styled {
     font-family: $heading-font;
     font-weight: 700;
     letter-spacing: 0.1em;
     text-transform: uppercase;
   }
   ```

5. Marble texture mixin (using SVG feTurbulence for subtle noise):
   ```scss
   @mixin marble-texture($opacity: 0.04) {
     position: relative;
     background-color: $cream;

     &::before {
       content: '';
       position: absolute;
       inset: 0;
       background-image: url("data:image/svg+xml,%3Csvg viewBox='0 0 400 400' xmlns='http://www.w3.org/2000/svg'%3E%3Cfilter id='n'%3E%3CfeTurbulence type='fractalNoise' baseFrequency='0.8' numOctaves='4' stitchTiles='stitch'/%3E%3C/filter%3E%3Crect width='100%25' height='100%25' filter='url(%23n)'/%3E%3C/svg%3E");
       opacity: $opacity;
       pointer-events: none;
       z-index: 0;
     }

     > * {
       position: relative;
       z-index: 1;
     }
   }
   ```

6. Ready-to-use marble background class:
   ```scss
   .marble-bg {
     @include marble-texture(0.05);
   }
   ```

Important: The $cream variable must be imported from quasar.variables.scss. Quasar automatically makes these available, but verify the mixin compiles correctly.
  </action>
