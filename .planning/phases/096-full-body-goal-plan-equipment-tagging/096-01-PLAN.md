```typescript
// POST /admin/exercises/bulk-update-equipment - Bulk update equipment field
fastify.post<{
  Body: { exerciseIds: number[]; equipment: string };
}>(
  "/exercises/bulk-update-equipment",
  {
    schema: {
      body: {
        type: "object",
        required: ["exerciseIds", "equipment"],
        properties: {
          exerciseIds: {
            type: "array",
            items: { type: "integer" },
            minItems: 1,
          },
          equipment: {
            type: "string",
            enum: ["barras", "anillas", "cajon", "ninguno"],
          },
        },
      },
    },
  },
  async (request, reply) => {
    const { exerciseIds, equipment } = request.body;

    const result = await fastify.db
      .update(schema.exercises)
      .set({ equipment })
      .where(inArray(schema.exercises.id, exerciseIds));

    request.log.info(
      { exerciseIds, equipment, affected: result[0].affectedRows },
      "Bulk equipment update",
    );

    return {
      success: true,
      updatedCount: result[0].affectedRows,
    };
  },
);
```

Make sure `inArray` is imported from `drizzle-orm` at the top of the file. Check if it's already imported — the file likely already imports `eq` from drizzle-orm. Add `inArray` to that import if not present.

Also ensure `schema` import covers exercises (it should already since admin routes use `schema.exercises`).
