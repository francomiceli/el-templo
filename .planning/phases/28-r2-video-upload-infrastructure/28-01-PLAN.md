**4. Create video-service.ts** (`src/modules/admin/video-service.ts`):
Class `VideoService` that takes `r2: S3Client, bucket: string, log: FastifyBaseLogger` in constructor. Methods:

- `generateUploadUrl(exerciseId: number)`: Creates presigned PUT URL for key `exercises/${exerciseId}.mp4` with `ContentType: "video/mp4"`, 15-minute expiry (900s). Returns `{ uploadUrl: string, key: string }`.

- `confirmUpload(exerciseId: number, db: MySql2Database)`: Updates `exercises.video_url` to `exercises/${exerciseId}.mp4` in DB. Then fires off async post-processing (does NOT await — fire-and-forget pattern). Returns immediately with `{ videoUrl: key, thumbnailUrl: thumbnails/${exerciseId}.jpg }`.

- `processVideo(exerciseId: number)`: The async post-processing pipeline:
  1. Download video from R2 to `/tmp/el-templo-video-${exerciseId}.mp4` using `GetObjectCommand` + stream to file
  2. Probe with `ffprobe` (using `child_process.execFile` promisified): extract codec, bitrate, duration, width, height
  3. Validate duration <= 20s. If exceeds, delete the upload from R2, clear video_url in DB, log error. Return early.
  4. Conditional compression: if `needsCompression(metadata)` is true (not H.264, or bitrate > 4Mbps for <=720p / 6Mbps for >720p), compress with ffmpeg: `-c:v libx264 -crf 28 -preset medium -vf scale='min(720,ih)':-2 -movflags +faststart -an`. Upload compressed version back to R2 (same key), replacing the original.
  5. Extract thumbnail at 25% of duration: `ffmpeg -y -ss {timestamp} -i {input} -vframes 1 -q:v 5 -vf scale=320:-2 {output.jpg}`. Upload to R2 key `thumbnails/${exerciseId}.jpg` with `ContentType: "image/jpeg"`.
  6. Clean up temp files.
     Wrap entire pipeline in try/catch. On error, log to Sentry-capable logger (use `log.error({ err, exerciseId }, 'Post-processing failed')`). Do NOT rethrow — this is fire-and-forget.

- `deleteVideo(exerciseId: number, db: MySql2Database)`: Delete `exercises/${exerciseId}.mp4` and `thumbnails/${exerciseId}.jpg` from R2 (both via `DeleteObjectCommand`, ignore 404 on thumbnail). Clear `exercises.video_url` to null in DB.

- `needsCompression(meta: VideoMetadata): boolean`: Private method. Returns false if codec is `h264` AND bitrate <= threshold (4Mbps for height<=720, 6Mbps for >720). Returns true otherwise.

- `probeVideo(filePath: string): Promise<VideoMetadata>`: Private method using `execFileAsync("ffprobe", [...])` per research code examples.

- `compressVideo(inputPath: string, outputPath: string): Promise<void>`: Private method using `execFileAsync("ffmpeg", [...])` with 120s timeout.

- `extractThumbnail(inputPath: string, outputPath: string, duration: number): Promise<void>`: Private method per research code examples.

For downloading from R2, use `GetObjectCommand` and pipe `Body` (a ReadableStream) to a file using `fs.createWriteStream`. For uploading back to R2, use `PutObjectCommand` with `fs.createReadStream`.

Define `VideoMetadata` interface in the same file: `{ codec: string, bitrate: number, duration: number, width: number, height: number }`.

**1. Create assembleVideoUrl utility** (`src/modules/shared/video-url.ts`):
```typescript
/**
 * Assemble a full video URL from an R2 key.
 * Stores only the key in DB (e.g., "exercises/42.mp4"),
 * prepends R2_PUBLIC_URL at read time.
 */
export function assembleVideoUrl(key: string | null | undefined): string | null {
  if (!key) return null;
  const baseUrl = process.env.R2_PUBLIC_URL;
  if (!baseUrl) return null;
  return `${baseUrl}/${key}`;
}

/\*\*

- Assemble a thumbnail URL from an exercise ID.
  \*/
  export function assembleThumbnailUrl(exerciseId: number): string | null {
  const baseUrl = process.env.R2_PUBLIC_URL;
  if (!baseUrl) return null;
  return `${baseUrl}/thumbnails/${exerciseId}.jpg`;
  }

```
