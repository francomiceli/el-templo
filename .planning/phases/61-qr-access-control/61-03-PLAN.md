    **New component: SlotAttendancePanel.vue**

    A panel/dialog that shows attendance status for a specific schedule slot on a specific date. This is the coach's attendance view per CONTEXT.md: "Each class slot in Horarios page shows booking list with attendance status."

    Props:
    - `scheduleId: number`
    - `date: string` (YYYY-MM-DD)
    - `activityName: string`
    - `startTime: string`

    Behavior:
    1. On mount, call `useAttendanceApi().getSlotAttendance(scheduleId, date)` to fetch the merged booking+attendance list
    2. Display a list of members:
       - Checked in (QR or manual): green checkmark icon + scan time + source badge (QR/Manual)
       - Booked but no show: empty checkbox (no attendance record)
       - Walk-in QR (no booking): green checkmark + "(sin reserva)" note
    3. "+ Agregar alumno" button at the bottom: opens a member search dialog
       - Uses QSelect with `use-input` and filter handler (same pattern as existing manual check-in dialog from Phase 50)
       - Searches ALL members, not just booked ones
       - Shows subscription status warnings next to each search result (active=green, expired=red, no sub=grey)
       - On select: calls `coachCheckIn(scheduleId, date, memberId)` and refreshes the list
       - Optional reason field (QInput) shown before confirm
    4. Each checked-in member row has a "X" (remove) icon button
       - On click: confirmation dialog "Eliminar asistencia de [name]?"
       - On confirm: calls `removeCheckIn(attendanceId)` and refreshes the list
    5. Auto-refresh every 30 seconds (same pattern as Phase 50's polling)

    Visual style:
    - QCard with QList inside
    - Each item: QItem with avatar (initials or green check), member name, time, action buttons
    - Green background tint for checked-in members
    - Empty/outlined style for booked-not-shown members

    **HorariosPage.vue integration:**

    The HorariosPage already shows a weekly calendar grid with schedule slots. Need to add a way to open the SlotAttendancePanel when clicking a slot.

    1. Read the existing HorariosPage structure (it has a grid with slot cells). When admin clicks a slot cell for the CURRENT or PAST dates (not future), open a SlotAttendancePanel.
    2. Implementation approach:
       - Add a `selectedSlot` ref: `{ scheduleId: number, date: string, activityName: string, startTime: string } | null`
       - When a slot cell is clicked and the date is <= today: set `selectedSlot`
       - Show SlotAttendancePanel as a side panel or dialog (QDialog is simpler, side panel is nicer UX -- use a QDrawer on the right side or a QDialog)
       - RECOMMENDATION: Use a QDialog (right side, maximized on mobile) since the grid already takes full width. Title: "{activityName} - {date formatted} {startTime}"
    3. For each slot cell in the grid, add a small attendance indicator:
       - If date is today or past and there are bookings: show a small badge with "3/5" (checked-in / total booked)
       - This requires fetching booking counts for the visible week. The scheduling API may already return this data -- check the existing grid data endpoint.
       - If fetching per-slot attendance counts for the whole week is expensive, only show the indicator for "today" slots (simpler). Per CONTEXT.md: "Attendance Visibility in Horarios Page" -- each class slot shows booking list. The indicator count is nice-to-have but the main feature is the click-to-view panel.
    4. Import and register SlotAttendancePanel in HorariosPage

    Edge cases:
    - Slot cell for future dates: no attendance panel (can't check in for the future)
    - Slot cell for past dates: attendance panel shows data, removal allowed (coach can correct past attendance per CONTEXT.md)
    - For manual check-in: restrict to today only (can't retroactively add a check-in for a past date)
