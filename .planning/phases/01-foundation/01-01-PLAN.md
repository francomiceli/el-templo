<task type="auto">
  <name>Task 2: Add Capacitor mode and configure for mobile</name>
  <files>
    el-templo-app/src-capacitor/capacitor.config.json
    el-templo-app/quasar.config.js
  </files>
  <action>
Add Capacitor mode to the Quasar project:

1. From el-templo-app directory: `quasar mode add capacitor`
   - This creates src-capacitor/ directory with capacitor.config.json
2. Edit src-capacitor/capacitor.config.json:
   - Set appId: "com.eltemplo.app"
   - Set appName: "El Templo"
3. Edit quasar.config.js to add Capacitor configuration:
   ```javascript
   capacitor: {
     hideSplashscreen: true,
     iosStatusBarPadding: true,
   },
   framework: {
     config: {
       capacitor: {
         iosStatusBarPadding: true,
         backButtonExit: false,
       },
     },
   },
   ```
4. Pin Capacitor packages to v6 in package.json to avoid version mismatch:
   - Ensure @capacitor/core is ^6.x.x (should be default from Quasar CLI)
   - Check with `pnpm list @capacitor/core`

IMPORTANT: Do NOT upgrade Gradle when Android Studio prompts later - this breaks Capacitor.
  </action>
  <verify>
- `ls el-templo-app/src-capacitor/` shows capacitor.config.json
- `cat el-templo-app/src-capacitor/capacitor.config.json` shows appId "com.eltemplo.app"
- `grep -q "capacitor:" el-templo-app/quasar.config.js` returns 0
  </verify>
  <done>Capacitor mode added with iOS/Android configuration, pinned to v6</done>
</task>
