<threat_model>

## Trust Boundaries

| Boundary                     | Description                                                                               |
| ---------------------------- | ----------------------------------------------------------------------------------------- |
| kiosco (device token) -> API | Unico canal del TV en operacion; el token vive en `localStorage` de un aparato compartido |
| kiosco -> logs del backend   | `client-log` deja que un dispositivo escriba en los logs del servidor                     |

## STRIDE Threat Register

| Threat ID | Category               | Component                                    | Disposition | Mitigation Plan                                                                                                                                                                               |
| --------- | ---------------------- | -------------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-164-31  | Elevation of Privilege | Lectura cross-sede desde `/api/tv/state`     | mitigate    | La sede sale de `request.tvDevice.branchId`; criterio de aceptacion prohibe cualquier lectura de `branchId` desde query/params/body en `device-routes.ts`                                     |
| T-164-32  | Spoofing               | Token revocado o inexistente                 | mitigate    | Hook de device auth: 401 (no 403) + `log.warn`, para que el TV borre `localStorage` y vuelva a pairing sin llenar Sentry                                                                      |
| T-164-33  | Information Disclosure | Mensajes internos visibles para socios       | mitigate    | D-09: la respuesta de reposo no incluye claves de error, verificado por test                                                                                                                  |
| T-164-34  | Tampering              | Log injection / HTML por `client-log`        | mitigate    | JSON Schema con `enum` + `maxLength`, corte a 500 chars y descarte de `<`/`>`; siempre `warn` y con campos estructurados                                                                      |
| T-164-35  | Denial of Service      | Spam de `client-log` desde un kiosco en loop | accept      | Requiere device token valido y el volumen esta acotado por `maxLength` + `warn`. Si aparece abuso, revocar el dispositivo desde el admin. Rate limiting implicaria instalar un paquete (C-08) |
| T-164-SC  | Tampering              | npm/pnpm installs                            | mitigate    | Cero paquetes nuevos. Cualquier `pnpm add` requiere checkpoint humano bloqueante (C-08)                                                                                                       |

</threat_model>
