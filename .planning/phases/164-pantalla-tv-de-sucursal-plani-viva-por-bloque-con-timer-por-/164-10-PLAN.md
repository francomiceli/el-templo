Las escrituras del profe: el contexto que alimenta la botonera ciega, el endpoint unico de estado con valores absolutos y clamp, y el "terminar clase".

<interfaces>
```
GET  /api/admin/tv/control/context?branchId=NN   -> 200 TvControlContext (contrato del plan 164-02)
POST /api/admin/tv/control/state                 body TvStateWrite -> 200 TvControlContext (estado nuevo COMPLETO)
POST /api/admin/tv/control/end-class             body { branchId } -> 200 { ok: true }
```
Semantica de `TvStateWrite` (todos los campos opcionales salvo `branchId`; se aplican en este orden):
  1. `blockRole`  -> valida contra el roster. Si CAMBIA: `exerciseIndex = 0`, timer a `idle`
                     (`timer_started_at`, `paused_at` y `paused_accum_ms` reseteados) — D-15.
                     El `level` NO se toca (persiste al cambiar de bloque) — D-15.
  2. `level`      -> valida contra `classDay.levels`. NO resetea el timer ni el bloque.
                     Clampea `exerciseIndex` a la lista del nuevo (rol, nivel).
  3. `exerciseIndex` -> clamp a `[0, n-1]`. NO resetea el timer.
  4. `timer`:
       "start"  -> si ya esta `running`, NO-OP (idempotente, evita el doble tap). Si no:
                   `status = running`, `timer_started_at = NOW(3)`, `paused_at = null`,
                   `paused_accum_ms = 0`. Sin cuenta previa (D-16).
       "pause"  -> si no esta `running`, NO-OP. Si no: `status = paused`, `paused_at = NOW(3)`.
       "resume" -> si no esta `paused`, NO-OP. Si no: `paused_accum_ms += NOW(3) - paused_at`,
                   `paused_at = null`, `status = running` (D-17: reanuda exacto donde quedo).
       "reset"  -> `status = idle`, los tres campos de tiempo a null/0.
     No existen "saltar ronda" ni "ajustar" (D-18).
  5. `soundEnabled` -> booleano directo (D-19: arranca en false).
  6. `screen` -> "class" | "closing" (D-08: pantalla de cierre tras el ultimo bloque).
Si no hay fila para la sede, la primera escritura la CREA con `class_date = todayInTz(branch.tz)`,
`level = "alfa"` (D-15), `blockRole` = primer rol del roster, `exerciseIndex = 0`, timer `idle`.
