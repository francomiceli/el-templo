## Trust Boundaries

| Boundary                 | Description                                                                       |
| ------------------------ | --------------------------------------------------------------------------------- |
| celular del profe -> API | Sesion JWT en un dispositivo personal, potencialmente desbloqueado en el gimnasio |
| UI -> estado de la sede  | Cada tap cambia lo que ven todos los socios de la sala                            |

## STRIDE Threat Register

| Threat ID | Category               | Component                                       | Disposition | Mitigation Plan                                                                                               |
| --------- | ---------------------- | ----------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------- |
| T-164-51  | Elevation of Privilege | Control de una sede ajena desde el selector     | mitigate    | El selector solo lista sedes del scope; la autoridad real es `requireBranchAccess` en el API (plan 164-10)    |
| T-164-52  | Tampering              | Doble tap accidental en medio de la clase       | mitigate    | Botones deshabilitados mientras la request esta en vuelo + comandos absolutos e idempotentes del lado del API |
| T-164-53  | Repudiation            | No saber que profe cambio el estado             | mitigate    | `updated_by` en cada escritura (plan 164-10)                                                                  |
| T-164-54  | Denial of Service      | Refresco de contexto cada 30 s dejado corriendo | mitigate    | `clearInterval` en el `onUnmounted` de la pagina                                                              |
| T-164-SC  | Tampering              | npm/pnpm installs                               | mitigate    | Cero paquetes nuevos. Cualquier `pnpm add` requiere checkpoint humano bloqueante (C-08)                       |

</threat_model>
