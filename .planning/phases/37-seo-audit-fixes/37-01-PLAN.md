<task type="auto">
  <name>Task 2: Enable HTTP/2 and gzip compression in Nginx configs</name>
  <files>
    deploy/nginx/eltemplo.org
    deploy/nginx/web-staging.eltemplo.org
  </files>
  <action>
    1. Edit `deploy/nginx/eltemplo.org`:
       - Add a gzip configuration block INSIDE the existing `server {}` block, BEFORE the location blocks:
         ```nginx
         # Gzip compression
         gzip on;
         gzip_vary on;
         gzip_proxied any;
         gzip_min_length 256;
         gzip_comp_level 6;
         gzip_types
           text/plain
           text/css
           text/javascript
           application/javascript
           application/json
           application/xml
           image/svg+xml
           font/woff2;
         ```
       - Add a SECOND server block for SSL/HTTP/2 AFTER the existing server block. This block will be found and modified by certbot when SSL is provisioned. Certbot will add the ssl_certificate and ssl_certificate_key directives:
         ```nginx
         # SSL + HTTP/2 (certbot will add certificate paths)
         server {
             listen 443 ssl http2;
             listen [::]:443 ssl http2;
             server_name eltemplo.org;

             root /var/www/el-templo-web;
             index index.html;

             # Gzip compression (mirror from port 80 block)
             gzip on;
             gzip_vary on;
             gzip_proxied any;
             gzip_min_length 256;
             gzip_comp_level 6;
             gzip_types
               text/plain
               text/css
               text/javascript
               application/javascript
               application/json
               application/xml
               image/svg+xml
               font/woff2;

             # SSG: serve pre-rendered HTML files, fallback to index.html
             location / {
                 try_files $uri $uri/index.html $uri.html /index.html =404;
             }

             # Cache static assets aggressively
             location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot|webp|avif)$ {
                 expires 1y;
                 add_header Cache-Control "public, immutable";
             }

             # Security headers
             add_header X-Frame-Options "SAMEORIGIN" always;
             add_header X-Content-Type-Options "nosniff" always;
             add_header X-XSS-Protection "1; mode=block" always;
             add_header Referrer-Policy "strict-origin-when-cross-origin" always;
         }
         ```
       - NOTE: The server runs Nginx 1.18.0 (per seoptimer audit), so HTTP/2 MUST be on the `listen` line as `listen 443 ssl http2;` — the standalone `http2 on;` directive only works on Nginx 1.25.1+. The SSL server block will fail to start until certbot adds certificates, which is expected — certbot will be run during deployment.

    2. Apply the SAME gzip block + SSL/HTTP/2 server block to `deploy/nginx/web-staging.eltemplo.org`, adjusting the server_name to match.
    3. Both configs keep the existing `listen 80` server block as-is.

  </action>
