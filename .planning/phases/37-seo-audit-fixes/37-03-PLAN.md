  <name>Task 3: Audit and reduce inline :style bindings</name>
  <files>

  <action>
    There are ~40 `:style` bindings across components. Most fall into 3 categories:
    1. **Staggered animation delays** — `:style="{ transitionDelay: '200ms' }"` (fixed values)
    2. **Index-based animation delays** — `:style="{ transitionDelay: \`${index * 100}ms\` }"` (dynamic)
    3. **Parallax transforms** — `:style="{ transform: parallaxTransform }"` (runtime calculated)

    **Strategy per CONTEXT.md**: "Move dynamic values to CSS custom properties or classes where possible. Accept Vue scoped style data attributes as framework standard."

    **Category 1: Fixed transition delays (CONVERT)**
    These are hardcoded values like `200ms`, `500ms`, `800ms` that never change. Convert to CSS classes:

    For `SectionHero.vue`, `FranHero.vue`, `GladHero.vue`:
    - Create CSS utility classes or BEM modifier classes:
      ```css
      .hero--delay-1 { transition-delay: 200ms; }
      .hero--delay-2 { transition-delay: 500ms; }
      .hero--delay-3 { transition-delay: 800ms; }
      .hero--delay-4 { transition-delay: 1000ms; }
      .hero--delay-5 { transition-delay: 1200ms; }
      ```
    - Replace `:style="{ transitionDelay: '200ms' }"` with `class="hero--delay-1"` etc.
    - Scope the delay classes within each component's `<style scoped>` block using appropriate BEM prefixes (hero, fran-hero, glad-hero)

    **Category 2: Index-based dynamic delays (CONVERT to CSS classes for bounded sets)**
    For `AppNav.vue` (drawer links), `GladCatalog.vue` (products), and similar:
    - For items with a small bounded set (nav links = ~7, products = ~6), convert to indexed CSS classes and use `:class` binding with index.
    - Example: `.nav__link--delay-0 { transition-delay: 0ms; }` through `.nav__link--delay-6 { transition-delay: 600ms; }`
    - For truly dynamic lists (v-for with unknown length), keep `:style` — it's the pragmatic choice.

    **Category 3: Parallax transforms (KEEP)**
    These are runtime-computed values from `requestAnimationFrame` scroll handlers. There's no CSS-only alternative. Keep these `:style` bindings as-is. Add a brief code comment: `<!-- :style kept: runtime parallax value, no CSS-only alternative -->`

    **Category 4: Scroll reveal staggered delays (CONVERT to CSS custom property)**
    For `SectionMethod.vue`, `SectionLocations.vue`, `SectionCommunity.vue`:
    - Use `:style="{ '--stagger-delay': \`${index * 100}ms\` }"` and `transition-delay: var(--stagger-delay);` in CSS
    - This is a single custom property instead of a direct style property

    **Implementation order:**
    1. Convert fixed delays in hero components (Category 1) — 3 files, ~15 bindings
    2. Convert bounded index delays in nav and catalog (Category 2) — 2 files, ~4 bindings
    3. Keep parallax and truly dynamic bindings — document why in a code comment
    4. Convert scroll reveal staggered delays to CSS custom property approach (Category 4)

    **Expected outcome**: Reduce inline `style=""` attributes from ~40 to ~15 (parallax + truly dynamic only).

  </action>
