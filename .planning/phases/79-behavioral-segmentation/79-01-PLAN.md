**5. Create SegmentationService (el-templo-api/src/modules/segmentation/service.ts):**

Uses constructor DI pattern (per Phase 56 convention). Constructor takes `db` and `log`.

Key methods:

`async getThresholds(): Promise<SegmentThresholds>` — Queries all `segment.*` keys from system_settings in one query. Falls back to SEGMENT_DEFAULTS for any missing key. Parses string values to numbers.

`async calculateSegment(userId: number): Promise<MemberSegment>` — The core logic (per D-02 through D-10):

1. Get user's `createdAt` from users table.
2. If `(now - createdAt) < nuevoGuerreroDays days` -> return `'nuevo_guerrero'` (per D-07).
3. Get the user's most recent attendance `checkedInAt` and most recent login `loggedInAt` and most recent session completion `completedAt`.
4. Compute `lastActivityDate` = max of (last attendance, last login, last session completion). If no activity at all, return `'ghost'`.
5. Compute `weeksSinceLastActivity` = floor((now - lastActivityDate) / 7 days).
6. If `weeksSinceLastActivity >= ghostWeeks` -> return `'ghost'` (per D-09).
7. If `weeksSinceLastActivity >= enRiesgoWeeks` -> return `'en_riesgo'` (per D-09).
8. Get user's active/paused subscription to find `classesPerWeek` from joined subscription_plans. If no active subscription, use fallback logic: if they have attendance in window, treat as attending member with 0% budget -> `'en_riesgo'`.
9. Compute `expectedClasses` = `classesPerWeek * (windowDays / 7)`.
10. Count attendance records in the rolling window (last `windowDays` days).
11. Compute `attendancePct` = `(attendanceCount / expectedClasses) * 100`.
12. Count app usage signals in window: session completions + distinct login days.
13. Determine Digital Warrior (per D-04): if `attendancePct < intermitentePct` AND `appUsageCount >= 4` (at least ~1/week in 28 days) -> return `'digital_warrior'`.
14. If `attendancePct >= espartanoPct` -> return `'espartano'`.
15. If `attendancePct >= intermitentePct` -> return `'intermitente'`.
16. Return `'en_riesgo'`.

`async calculateAndUpdate(userId: number): Promise<MemberSegment>` — Calls `calculateSegment`, then updates `member_profiles` SET `segment = result, segmentUpdatedAt = NOW()` WHERE `userId = userId`. Returns the segment. Skip recalculation if `segmentUpdatedAt` is within the last 1 hour (cache per D-discretion to avoid recalculating on every /auth/me call).

`async recordLogin(userId: number): Promise<void>` — INSERT into member_logins (userId, loggedInAt = NOW()).
