**Route layer (`subscriptions/routes.ts`):**

Locate the GET /plans handler (grep `"/plans"` or similar). Extend its query schema to accept optional `branchId` and `country`:

```typescript
// Query schema (Zod or similar — match existing pattern in the file):
{
  isActive: z.boolean().optional(),
  includeArchived: z.boolean().optional(),
  branchId: z.coerce.number().int().optional(),
  country: z.enum(["AR", "ES"]).optional(),
}
```

In the handler body, resolve the effective country in this priority (delegate to service — keep route thin):

1. Non-owner: use `request.scope.country` — IGNORE the query.
2. Owner with explicit `?country=AR|ES`: use that (preHandler already set `request.scope.country` from this param; just use scope.country).
3. Owner with `?branchId=<n>` but no country: service looks up the branch's country.
4. Owner with neither: use `request.scope.country` (which defaults to `AR` per Plan 02's fallback logic, OR the owner's own branch country if query absent).

Pass to service:

```typescript
const plans = await subscriptionService.getPlans({
  isActive: query.isActive,
  includeArchived: query.includeArchived,
  branchId: query.branchId,
  country: request.scope.country,
  isOwner: request.scope.isOwner,
});
```

**Service layer (`subscriptions/service.ts`):**

Modify `getPlans` (or whatever the listing method is called — find via grep for the route's call site). Extend its input type:

```typescript
interface GetPlansFilters {
  isActive?: boolean;
  includeArchived?: boolean;
  branchId?: number;
  country?: "AR" | "ES";
  isOwner?: boolean;
}
```

In the method body, resolve effective country:

```typescript
let effectiveCountry = filters.country;
if (filters.branchId !== undefined) {
  const [branch] = await this.db
    .select({ country: schema.branches.country })
    .from(schema.branches)
    .where(eq(schema.branches.id, filters.branchId));
  if (branch?.country === "AR" || branch?.country === "ES") {
    effectiveCountry = branch.country;
  }
}
```

Add country to the WHERE clause:

```typescript
const where = and(
  eq(schema.subscriptionPlans.isActive, filters.isActive ?? true),
  // ... existing conditions
  effectiveCountry
    ? eq(schema.subscriptionPlans.country, effectiveCountry)
    : undefined,
);
```

Ensure the SELECT returns `country` and `currency` on each plan row (additive per REQ-98-11).

**TypeScript:** no `any`. Use existing Zod schema patterns. Update any response-type declaration (`PlanResponse` or inline) to include country/currency so the admin frontend composable compiles.
