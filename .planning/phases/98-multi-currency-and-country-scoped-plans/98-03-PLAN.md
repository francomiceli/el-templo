<objective>
Register the `attachCountryScope` preHandler on every Fastify plugin that serves country-scoped data: members, subscriptions (admin + member-facing), payments, promo-plans, gladius. The hook runs at the END of the existing `onRequest` block (after authenticate + role guard), so every route handler in these plugins has `request.scope` populated.

Purpose: This is the single point at which non-owner country enforcement is wired. Without this registration, the hook exists but never runs. Every subsequent service-layer scoping task depends on `request.scope` being present.

Output: Six route files with `await attachCountryScope(request, fastify.db)` appended to their existing `onRequest` hook block. No new hooks — keep one block per plugin per PATTERNS §2.
</objective>
