<objective>
Register the `attachCountryScope` preHandler on every Fastify plugin that serves country-scoped data: members, subscriptions (admin + member-facing, which also hosts the nested promo-plans routes), payments, gladius, reports, analytics. The hook runs at the END of the existing `onRequest` block (after authenticate + role guard), so every route handler in these plugins has `request.scope` populated.

Purpose: This is the single point at which non-owner country enforcement is wired. Without this registration, the hook exists but never runs. Every subsequent service-layer scoping task (Plans 05, 06) depends on `request.scope` being present on every admin plugin — including reports and analytics. This plan unambiguously OWNS plugin-level hook registration for the entire phase.

Output: Seven route files with `await attachCountryScope(request, fastify.db)` appended to their existing `onRequest` hook block. No new hooks — keep one block per plugin per PATTERNS §2. (Promo-plans is nested in subscriptions/routes.ts per grep evidence — not a separate file; covered by the subscriptions registration. No hedging.)
</objective>
