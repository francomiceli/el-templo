| T-182-20 | Information Disclosure | Credenciales del super-owner | mitigate | La contraseña se pide por stdin, nunca por argv (no queda en el historial del shell ni en `ps`), nunca se imprime, y el hash nunca entra a git ni a una migración (D-07) |

| T-182-24 | Tampering | Alta del demo en la base equivocada | mitigate | El runbook obliga a verificar `SELECT DATABASE()` antes de cada alta (staging y prod comparten host MySQL) |
