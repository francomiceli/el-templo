<objective>
Implementar la resolución de tenant **pre-login** por `Origin` / `X-Tenant-Slug` (D-18, que
reinterpreta H-3 del doc 08: el hostname que identifica al gimnasio es el del FRONT, no el de la
API — la API sigue en un solo hostname) y convertir el `origin` de CORS de array estático a
función con regex anclada.

Purpose: es la precondición para que la app/panel de un gimnasio nuevo pueda hablar con la API
antes de que exista un usuario logueado. La regla dura es D-05: si el request no cae bajo
`PLATFORM_DOMAIN` y no trae `X-Tenant-Slug`, **el hook no hace absolutamente nada**.
Output: función pura testeada, hook global, CORS dinámico y una batería de integración que incluye
la no-regresión de El Templo.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| navegador → API (header `Origin`) | Header controlado por el cliente, usado para elegir gimnasio antes del login |
| cliente nativo → API (header `X-Tenant-Slug`) | Header arbitrario, sin autenticación previa |
| nginx → Fastify | `proxy_set_header Host $host` propaga lo que llega del cliente |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-182-03 | Spoofing | `originToSlug` / CORS | mitigate | Regex anclada `^…$` sobre el dominio escapado; `endsWith` prohibido y verificado por grep; unit test explícito con `https://evil-<dominio>` |
| T-182-04 | Information Disclosure | Slug no resoluble | mitigate | 404 con `code: TENANT_NOT_FOUND` y mensaje genérico idéntico para "no existe" y "no es un slug"; nunca revela si el gimnasio existe (D-04) |
| T-182-09 | Spoofing | `X-Tenant-Slug` arbitrario | mitigate | El header solo alcanza rutas **sin usuario**; el tenant de un request autenticado sigue saliendo de `users.tenant_id` vía `attachScope`, que este plan no toca. El valor se valida contra el regex de label antes de la query y el lookup es por igualdad exacta parametrizada |
| T-182-16 | Elevation of Privilege | Fallback a tenant 1 | mitigate | `?? 1`, `\|\| 1` y `!` prohibidos y verificados por grep en el archivo; sin fila ⇒ 404, nunca default |
| T-182-17 | Denial of Service | Regresión de CORS sobre la TV | mitigate | `maxAge: 86400` intacto (verificado por grep) y los 5 orígenes de producción conservados literalmente; la función devuelve `cb(null,false)` sin throw |
</threat_model>
