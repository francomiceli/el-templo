# Block Specifications

## Overview
Session structure: 5 blocks (Initium, Nucleus, Deuteros 1, Deuteros 2, Athlos/Epikos)

## Initium Block
### Purpose
Warmup and preparation

### Specifications
| Attribute | Value |
|-----------|-------|
| Route | None (uses "INITIUM" marker) |
| Pattern | FLOW or Movilidad |
| Intensity | Fixed ~30% |
| Reps Budget | N/A (not used) |
| Exercise Count | 2-4 (no cap) |
| Contextual | Yes - relates to day's main Nucleus stimulus |
| Compatible Formats | Tabata, Interval Training, HIIT |

### Selection Logic
- Bypasses SPOM pipeline (no route lookup)
- Uses FLOW pattern or Movilidad category
- Should relate to day's Nucleus route (e.g., shoulder mobility if Nucleus is PUSH)

## Nucleus Block
### Purpose
Main training focus for the day

### Specifications
| Attribute | Value |
|-----------|-------|
| Route | From weekly rotator |
| Primary Block | Yes - determines day's main stimulus |
| Exercise Count | 2-3 (capped at 3) |
| Alfa-Delta Correlation | Same pattern, same logic, different difficulty |
| All Levels Together | Yes - planned as coherent unit |
| Difficulty Average | Within +/-0.5 of target |

### Selection Logic
- Route from weekly rotator (SPOM lookup)
- Intensity determines difficulty bucket
- Alpha and Delta follow same logical progression

## Deuteros 1 Block

Secondary complementary work

### Specifications
| Attribute | Value |

Secondary complementary work (alternative to Deuteros 1)

### Specifications
| Attribute | Value |

| Secondary Work | Yes - complements Nucleus |

| Difficulty | Matches route's intensity bucket |

### Purpose
Challenge or play element to end session

### Specifications
| Attribute | Value |
|-----------|-------|
| Type Selection | Athlos (odd weeks) / Epikos (even weeks) |
| Athlos | Structured technical challenge |
| Epikos | Playful physical game |
| Direction | Complementary to Nucleus |
| Exercise Count | 2-3 (capped at 3) |

### Week Alternation
- Odd weeks (1, 3, 5...): Athlos - structured challenge
- Even weeks (2, 4, 6...): Epikos - playful exploration

Add function to apply cap:
```typescript
function getExerciseCountCap(role: BlockRole): number | null {
  // Initium has no cap - uses full intensity-based count
  if (role === 'INITIUM') {
    return null; // No cap
  }
  // All other blocks capped at 3
  return 3;
}
```

In deriveBudget() function:
```typescript
// After getting exerciseCount from intensity rules:
const cap = getExerciseCountCap(ctx.role);
const exerciseCount = cap !== null
  ? Math.min(rule.exerciseCount, cap)
  : rule.exerciseCount;
```

2. Add trace event when cap is applied:
```typescript
if (cap !== null && rule.exerciseCount > cap) {
  const capTrace = createTraceEvent(
    ctx,
    'EXERCISE_COUNT_CAPPED',
    'INFO',
    {
      original: rule.exerciseCount,
      capped: cap,
      role: ctx.role,
      reason: `Non-Initium blocks capped at ${cap} exercises`,
    }
  );
  ctx = appendTrace(ctx, capTrace);
}
```
