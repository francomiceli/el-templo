**4. Extend BlogService** in `el-templo-api/src/modules/blog/service.ts` with these new methods:

- `listTags()` — SELECT all tags ordered by name. Return `{ id, name, slug }[]`.
- `listTagsWithPosts()` — SELECT tags that have >= 1 published post, with post count, ordered by count DESC. For the popular tags bar on blog index.
- `createTag(data: { name: string; slug?: string })` — INSERT tag, auto-generate slug from name if not provided using existing slugify function.
- `updateTag(id: number, data: { name?: string; slug?: string })` — UPDATE tag.
- `deleteTag(id: number)` — DELETE tag (also delete related blog_post_tags rows first).
- `assignTagsToPost(postId: number, tagIds: number[])` — DELETE all existing post_tags for postId, then INSERT new ones. Transaction-safe.
- `getPostTags(postId: number)` — SELECT tags for a specific post. Returns `{ id, name, slug }[]`.
- `getRelatedPosts(slug: string, limit: number = 3)` — Algorithm: find current post by slug, get its tag IDs, query other published posts sharing those tags with COUNT of shared tags as rank, ORDER BY rank DESC then publishedAt DESC, LIMIT. If fewer than `limit` results, fill remaining with most recent published posts (excluding current and already-selected). Return array of `{ id, title, slug, excerpt, coverImage, publishedAt, readingTime, tags }`.
- `listPostsByTag(tagSlug: string, page: number, limit: number)` — Paginated published posts that have the given tag. Return same shape as `listPublishedPosts` but filtered.

**Public routes (no auth):**

1. `GET /tags` — Returns all tags with post counts (for tag bar on blog index). Calls `service.listTagsWithPosts()`. Response: `{ tags: [{ id, name, slug, postCount }] }`.

2. `GET /tags/:slug/posts` — Paginated published posts for a tag. Query params: `page`, `limit`. Calls `service.listPostsByTag(slug, page, limit)`. Response: same shape as GET /posts plus `{ tag: { id, name, slug } }` for the page header.

3. `GET /posts/:slug/related` — Related posts for a post. Query param: `limit` (default 3, max 6). Calls `service.getRelatedPosts(slug, limit)`. Response: `{ posts: [...] }`.

**Admin routes (admin/superadmin):**

4. `GET /admin/tags` — All tags ordered by name (for tag selector in editor). Calls `service.listTags()`.

5. `POST /admin/tags` — Create tag. Body: `{ name, slug? }`. Schema validates name required, 1-100 chars. Returns 201.

6. `PUT /admin/tags/:id` — Update tag. Body: `{ name?, slug? }`. Params: id (integer).

7. `DELETE /admin/tags/:id` — Delete tag.

8. `PUT /admin/posts/:id/tags` — Assign tags to post. Body: `{ tagIds: number[] }`. Calls `service.assignTagsToPost(id, tagIds)`. Returns updated post with tags.
