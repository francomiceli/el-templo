| Boundary                  | Description                                                                                              |
| ------------------------- | -------------------------------------------------------------------------------------------------------- |
| payload FCM → app         | El `data` de una push es texto que llega de la red y se convierte en navegación y en una URL de WhatsApp |
| query `?text=` → WhatsApp | El texto de la URL interna termina en el mensaje pre-cargado                                             |

## STRIDE Threat Register

| Threat ID | Category          | Component                             | Disposition | Mitigation Plan                                                                                                                        |
| --------- | ----------------- | ------------------------------------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| T-193-33  | Tampering         | `data.destinationSection` desconocida | mitigate    | `resolveTapRoute` solo acepta keys de `APP_SECTIONS`; cualquier otra cosa cae a `data.route` y después a `/mi-templo` (test explícito) |
| T-193-34  | Tampering         | número de ventas inyectado            | mitigate    | `setServerSalesNumber` acepta solo `^[0-9]{8,15}$`; si no, se queda el hardcode                                                        |
| T-193-35  | Tampering         | `?text=` con contenido arbitrario     | mitigate    | Siempre `encodeURIComponent`; el texto ya viene validado server-side (plan 01) y solo se usa como cuerpo del mensaje, nunca como URL   |
