**Data fetching:**

- Import `api` from `src/boot/axios` and `useUserStore` from `stores/useUserStore`
- On mount: `api.get('/members/subscription/plans')` to load plans
- Split into `gymPlans` (isPersonalizada=false) and `personalizadaPlans` (isPersonalizada=true) via computed

**Current plan matching:**

- Use `userStore.subscription?.planName` to match against `plan.name` to identify current plan
- Computed: `const hasSubscription = computed(() => !!userStore.subscription)`

**CTA logic:**

- If plan is current plan: show `q-badge` with label "Tu plan actual" (color: primary) and status line "Activo — vence [endDate formatted]" instead of CTA button
- If member has a subscription: CTA text = "Contacta para cambiar de plan"
- If member has NO subscription: CTA text = "Contacta para elegir tu plan"
- CTA button opens: `https://wa.me/5492235820521?text=Hola, me interesa el plan ${encodeURIComponent(plan.name)}`

**Template structure:**

```
q-page (padding)
  div.text-h5.text-weight-bold "Planes"

  <!-- Loading state -->
  q-inner-loading :showing="loading"

  <!-- Empty state -->
  div v-if="!loading && plans.length === 0"
    "No hay planes disponibles"

  <!-- Gym Plans Section -->
  div v-if="gymPlans.length > 0"
    div.text-h6.q-mb-md "Planes de Gimnasio"
    div.row.q-col-gutter-md
      div.col-12.col-sm-6 v-for="plan in gymPlans"
        q-card.full-height
          q-card-section
            div.row.items-center.justify-between.q-mb-sm
              div.text-subtitle1.text-weight-bold {{ plan.name }}
              q-badge(:color="tierColor(plan.planTier)" :label="tierLabel(plan.planTier)")
            <!-- "Tu plan actual" badge if current plan -->
            q-badge(v-if="isCurrentPlan(plan)" color="primary" label="Tu plan actual" class="q-mb-sm")
            div.text-body2.text-grey-7(v-if="plan.description") {{ plan.description }}
          q-separator
          q-card-actions
            <!-- Current plan: show status -->
            div(v-if="isCurrentPlan(plan)" class="text-positive text-caption q-pa-sm")
              q-icon(name="check_circle" size="16px" class="q-mr-xs")
              | Activo — vence {{ formatEndDate() }}
            <!-- Other plans: WhatsApp CTA -->
            q-btn(v-else flat no-caps color="positive" icon="sym_o_chat" :label="ctaText" @click="openWhatsApp(plan)")

  <!-- Personalizada Plans Section -->
  div.q-mt-lg(v-if="personalizadaPlans.length > 0")
    div.text-h6.q-mb-md "Clases Personalizadas"
    div.row.q-col-gutter-md

            <!-- NO tier badge for personalizada cards -->

            div.text-body2.text-grey-7(v-if="plan.description") {{ plan.description }}
            <!-- Zone info -->
            div.q-mt-sm(v-if="plan.personalizadaZones?.length")
              div.text-caption.text-grey-6 Zonas

                q-badge(v-for="zone in plan.personalizadaZones" :key="zone" outline color="primary" :label="zone")
          q-separator
          q-card-actions
            div(v-if="isCurrentPlan(plan)" class="text-positive text-caption q-pa-sm")
              q-icon(name="check_circle" size="16px" class="q-mr-xs")

            q-btn(v-else flat no-caps color="positive" icon="sym_o_chat" :label="ctaText" @click="openWhatsApp(plan)")
```

**Helper functions:**

- `isCurrentPlan(plan: MemberPlan): boolean` — `userStore.subscription?.planName === plan.name`
- `formatEndDate(): string` — format `userStore.subscription?.endDate` as DD/MM/YYYY using Intl.DateTimeFormat('es-AR')
- `tierLabel(tier: string): string` — lookup from PLAN_TIER_LABELS, fallback to tier
- `tierColor(tier: string): string` — lookup from TIER_COLORS, fallback to 'grey'
- `openWhatsApp(plan: MemberPlan): void` — `window.open(url, '_blank')`
- `ctaText: computed` — returns "Contacta para cambiar de plan" if hasSubscription, else "Contacta para elegir tu plan"

**Style:** Use brand fonts (Montserrat for headings, Geologica for body) via existing Quasar variable classes. Cards use standard q-card elevation. Keep styling minimal and consistent with existing app pages.

Use `createLogger('PlanesPage')` from `src/utils/logger.ts` for any error logging. No console.log.
