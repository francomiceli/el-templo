<task type="auto">
  <name>Task 1: Self-host fonts and install Nuxt modules</name>
  <files>
    el-templo-web/package.json

    el-templo-web/assets/fonts/ (woff2 files)

  <action>
    **1. Install modules:**
    ```bash
    cd el-templo-web && pnpm add nuxt-schema-org @nuxt/image @nuxtjs/sitemap
    ```

    **2. Download and self-host fonts (woff2 only):**
    Create `el-templo-web/assets/fonts/` directory. Download woff2 files for:
    - Montserrat: weights 300, 600, 700, 800 (regular only, no italic needed)
    - Cormorant Garamond: weights 400, 500, 600 (regular) + weight 400 (italic)
    - Geologica: weights 400, 500, 600 (regular only)

    Use google-webfonts-helper or fontsource to get woff2 files. Place them in `el-templo-web/assets/fonts/` with naming convention: `{family}-{weight}{-italic}.woff2` (e.g., `montserrat-300.woff2`, `cormorant-garamond-400-italic.woff2`).

    If downloading is not straightforward via CLI, use `curl` to fetch woff2 files from Google Fonts CSS API (with User-Agent trick to get woff2 format URLs). Alternatively, use the `@fontsource` npm packages:
    ```bash
    pnpm add @fontsource/montserrat @fontsource/cormorant-garamond @fontsource/geologica
    ```
    Then copy the woff2 files from node_modules to assets/fonts/ and reference them directly. The @fontsource packages are preferred as they're well-maintained and provide clean woff2 files.

    **3. Create `el-templo-web/assets/css/fonts.css`:**
    Write @font-face declarations for each family+weight+style combo. Use `font-display: swap` for all. Reference files with `url('~/assets/fonts/{filename}.woff2') format('woff2')`.

    Example structure:
    ```css
    @font-face {
      font-family: 'Montserrat';
      font-style: normal;
      font-weight: 300;
      font-display: swap;
      src: url('~/assets/fonts/montserrat-300.woff2') format('woff2');
    }
    /* ... repeat for all weight/style combos */
    ```

    **4. Update `el-templo-web/nuxt.config.ts`:**
    - Add `fonts.css` to the `css` array (BEFORE tokens.css so font-face loads first)
    - Add modules: `'nuxt-schema-org'`, `'@nuxt/image'`, `'@nuxtjs/sitemap'`
    - REMOVE the Google Fonts `<link>` tags from `app.head.link` (the 3 links: preconnect to fonts.googleapis.com, preconnect to fonts.gstatic.com, and the stylesheet link)
    - Add `runtimeConfig.public` entries:
      - `ga4Id: ''` (env: NUXT_PUBLIC_GA4_ID)
      - `metaPixelId: ''` (env: NUXT_PUBLIC_META_PIXEL_ID)
    - Add `site` config for nuxt-schema-org: `site: { url: 'https://eltemplo.org', name: 'El Templo' }`
    - Add `schemaOrg` config: `schemaOrg: { identity: 'Organization' }`

    **Important:** Keep existing modules (`@nuxt/content`, `@nuxt/eslint`). Keep existing runtimeConfig entries (apiUrl, sentryDsn, appEnvironment). Append new entries, don't replace.

  </action>

    - runtimeConfig.public has ga4Id and metaPixelId with empty string defaults
