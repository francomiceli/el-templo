Implement the first 4 pipeline stages that resolve data from SPOM tables:

**stage-1-rotator.ts:**
- `resolveRotator(ctx: BlockContext, spomService: SpomService)`: Promise
- Calls spomService.getWeeklyRotator(week, day, levelGroup)
- Maps BlockRole to correct route column:
  - INITIUM: fixed "MOV" route (mobility warmup)
  - NUCLEUS: nucleusRouteId
  - DEUTEROS_1: deuteros1RouteId
  - DEUTEROS_2: deuteros2RouteId (may be null - skip block if null)
  - ATHLOS_EPIKOS: athlosRouteId
- Need secondary lookup to convert routeId to route code
- Returns ctx with route added, emits ROUTE_RESOLVED trace

**stage-2-spom.ts:**
- `resolveSpom(ctx: BlockContextWithRoute, spomService: SpomService)`: Promise
- Calls spomService.getSpomRule({ week, route })
- Returns ctx with intensity, pattern, category added
- Emits SPOM_RESOLVED trace with rule details

**stage-3-budget.ts:**
- `deriveBudget(ctx: BlockContextWithSpom, spomService: SpomService)`: Promise
- Calls spomService.getIntensityRule(intensity)
- Returns ctx with repsBudget, exerciseCountMin, exerciseCountMax, difficultyBucket
- Emits BUDGET_DERIVED trace

**stage-4-contraction.ts:**
- `deriveContraction(ctx: BlockContextWithBudget, spomService: SpomService)`: Promise
- Picks exerciseCount from min-max range (use min for determinism)
- Calls spomService.getContractionRule(intensity, exerciseCount)
- Returns ctx with contractionMix: { CON: n, EXC: n, ISO: n }
- Emits CONTRACTION_DERIVED trace

Each stage must:
1. Accept immutable context, return NEW context with spread operator
2. Append trace events to ctx.trace array (immutably)
3. Handle null/missing data by throwing with descriptive error
4. Sort any arrays deterministically by id before processing
  </action>

Implement stages 5-7 that select format, exercises, and generate prescriptions:

**stage-5-format.ts:**
- `selectFormat(ctx: BlockContextWithContraction, db: MySql2Database)`: Promise
- Query format_compatibility where block matches role, level matches member level (map levelGroup to individual level for query), intensity matches
- Filter to compatibility > 0
- Apply tie-breakers for determinism: sort by compatibility DESC, then formatId ASC
- Select first candidate
- Returns ctx with format: { formatId, name }
- Emits FORMAT_SELECTED trace with candidates count and winner

**stage-6-exercises.ts:**
- `selectExercises(ctx: BlockContextWithFormat, spomService: SpomService)`: Promise
- For each contraction type (CON, EXC, ISO) in contractionMix:
  - Query exercises where route matches, effort matches contraction type, difficulty <= difficultyBucket
  - Apply level filtering: alfa_delta sees alfa+delta, sigma sees alfa+delta+sigma, omega sees all
  - Sort deterministically: by id ASC
  - Pick first N exercises where N = contractionMix[type]
- Combine all selected exercises into array
- Returns ctx with exercises array
- Emits EXERCISES_SELECTED trace per contraction type

**stage-7-prescription.ts:**
- `generatePrescriptions(ctx: BlockContextWithExercises)`: Promise
- Distribute repsBudget across exercises evenly (integer division, remainder to first exercises)
- For each exercise, create ExercisePrescription:
  - reps = allocated budget portion (for strength exercises)
  - seconds = 0 (unless format dictates time-based)
  - rest = 60 (default, adjust by intensity: lower intensity = shorter rest)
  - notes = null
- Returns ctx with prescriptions array
- Emits PRESCRIPTIONS_GENERATED trace with budget allocation details

Each stage follows immutable context pattern. Sort all arrays by stable keys for determinism.
