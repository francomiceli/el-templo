## STRIDE Threat Register

| Threat ID | Category               | Component                              | Disposition | Mitigation Plan                                                                                                                               |
| --------- | ---------------------- | -------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| T-150-04  | Tampering              | updateBankAccount/closeBankAccount(id) | mitigate    | Guard `NotFoundError` al leer la caja + verificar `type='banco'` antes de mutar; no se permite mutar cajas efectivo por este camino           |

| T-150-06  | Repudiation            | close/reactivate (cambio de is_active) | mitigate    | Operaciones vía service loggeadas con `this.log` (Pino); baja lógica conserva el registro (no DELETE) para trazabilidad                       |
