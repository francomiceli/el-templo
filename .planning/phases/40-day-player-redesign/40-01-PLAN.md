**useStoryNavigation.ts:**
Create `el-templo-app/src/modules/training/composables/useStoryNavigation.ts` — a composable that manages Instagram Stories-style navigation for exercises within a block.

Interface:

```typescript
export function useStoryNavigation(totalSlides: Ref<number>) {
  // State
  currentIndex: Ref<number>       // 0-based index of current story slide

  // Methods
  next(): void                    // Go to next slide (clamp at max)
  prev(): void                    // Go to previous slide (clamp at 0)
  goTo(index: number): void       // Jump to specific slide
  reset(): void                   // Reset to index 0

  // Computed
  isFirst: ComputedRef<boolean>   // Whether on first slide
  isLast: ComputedRef<boolean>    // Whether on last slide

  // Cleanup
  cleanup(): void
}
```

The composable must:

- Accept a reactive `totalSlides` ref (exercises + mobility if present = total slide count)
- Clamp navigation at boundaries (no wrap-around)
- Expose `cleanup()` per project conventions (no `onUnmounted` inside composable)
- Watch `totalSlides` and clamp `currentIndex` if it exceeds the new count
- Use `createLogger('StoryNavigation')` for logging

Visual design (per CONTEXT.md):

- Horizontal row of thin bars (3px height, 2px gap between), one per exercise
- **Completed segments**: filled with Aged Gold (#b89b5e) — solid
- **Active segment**: filled with Aged Gold (#b89b5e) with a subtle glow/pulse animation (CSS `box-shadow` pulse using `@keyframes`)
- **Empty segments**: `rgba(255, 255, 255, 0.3)` (semi-transparent white, since this sits on dark overlay)
- Container has `padding: 8px 12px` and sits at the absolute top of the story area
- Segments use `border-radius: 2px` for subtle rounding
- Use `flex: 1` for each segment so they auto-size equally
