**Completely rewrite** BlockProgressionView.vue to use the new Stories-style interface.

**New Props (replacing current):**

```typescript
interface Props {
  dayName: string;
  currentBlock: Block | null;
  completedBlocks: BlockRole[];
  elapsedSeconds: number;
  currentBlockCompletedExercises: number[];
  isSessionComplete: boolean;
}
interface Emits {
  (e: "back"): void;
  (e: "restart"): void;
  (e: "complete-block"): void;
  (e: "toggle-exercise-complete", payload: { prescriptionId: number }): void;
}
```

Note: `selectedExerciseIndex` and `select-exercise` emit are REMOVED from props/emits — story navigation is now managed internally via `useStoryNavigation`.

**Layout structure (top to bottom):**

1. **Story area container** (relative positioned, 60vh height):
   - **SegmentedProgressBar** — positioned absolute at top (z-index 10), overlaying the video/name hero
   - **Header overlay** — positioned absolute at top (below progress bar), z-index 10:
     - Semi-transparent gradient overlay: `linear-gradient(to bottom, rgba(0,0,0,0.6) 0%, transparent 100%)`, height ~80px
     - Back arrow button (white `q-btn` flat round), block name (white, Montserrat 16px bold), timer (white, Roboto Mono 16px)
     - Three-dot menu (white) with Reiniciar option (keep current pattern)
   - **StoryExerciseCard** — fills the story area container

2. **Content area** (below story area, cream background, scrollable):
   - **CompactExerciseList** — always visible, shows all exercises + mobility

3. **Action area** (fixed bottom, same pattern as current):
   - "Completar {BlockName}" button (same logic as current `handleCompleteBlock`, including incomplete exercise dialog)

**Story navigation wiring:**

- Initialize `useStoryNavigation` with `totalSlides` = block exercises count + (1 if mobility exists)
- Last slide index = mobility slide (if block has mobility)
- On `tap-next` from StoryExerciseCard → call `storyNav.next()`
- On `tap-prev` from StoryExerciseCard → call `storyNav.prev()`
- On CompactExerciseList `navigate` → call `storyNav.goTo(index)`
- On `complete` from StoryExerciseCard → emit `toggle-exercise-complete` with the exercise's `exerciseId` (prescriptionId)
- Watch `currentBlock.blockId` — on change, call `storyNav.reset()` to go back to first slide

**Computed data bridging:**

- `currentSlideExercise`: Prescription or null (null when on mobility slide)
- `currentSlideMobility`: Block['mobilityExercise'] (when on mobility slide)
- `isMobilitySlide`: boolean (current index === exercises.length, i.e. last slide for non-INITIUM)
- `segmentCompletedIndices`: Set<number> — map exercise index to completed state
- `compactListData`: transform exercises + mobility into the CompactExerciseList format

**Cleanup:** Call `storyNav.cleanup()` in the component's `onUnmounted`.

**Remove old imports:** Remove ProgressBar, VideoPlaceholder, BlockHeader, ExerciseList, ExerciseCard. Import new components: SegmentedProgressBar, StoryExerciseCard, CompactExerciseList, useStoryNavigation.

**Keep existing logic:** `handleCompleteBlock` with incomplete exercise dialog, `formattedTime`, block name computation, route name display.
