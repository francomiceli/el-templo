Create `StoryExerciseCard.vue` — the main exercise display component in the redesigned Stories-style player.

**Props:**

```typescript
interface Props {
  /** Current exercise prescription (null for mobility slide) */
  exercise: Prescription | null;
  /** Mobility exercise data (used when exercise is null and this is the mobility slide) */
  mobilityExercise: Block["mobilityExercise"];
  /** Whether this is the mobility slide */
  isMobilitySlide: boolean;
  /** Block role for accent colors */
  blockRole: BlockRole;
  /** Whether this exercise is marked complete */
  isCompleted: boolean;
}
```

**Emits:**

```typescript
interface Emits {
  (e: "tap-next"): void;
  (e: "tap-prev"): void;
  (e: "complete"): void;
}
```

**Layout — split card:**

- **Top ~70% — Story area** (full width, dark background):
  - If exercise/mobility has `videoUrl`: render `<VideoPlaceholder :video-url="url" />` restyled to fill the story area (height: 60vh instead of 40vh)
  - If NO video: **Name Hero** — large exercise name centered on `linear-gradient(135deg, #1e1b18 0%, #2e2a26 50%, #3d3732 100%)` background, with contraction badge (q-badge) below the name. Name in Montserrat, 28px, white, semi-bold. Contraction badge uses `getBlockAccentColor` color.
  - **Tap zones** — Two invisible divs overlaid on the story area:
    - Left 30% of width: `@click="emit('tap-prev')"` with `cursor: pointer`
    - Right 70% of width: `@click="emit('tap-next')"` with `cursor: pointer`
    - Both have `position: absolute` within the story area container
    - **CRITICAL per CONTEXT.md:** Tapping does NOT mark exercises complete, only navigates

- **Bottom ~30% — Exercise detail panel** (cream background):
  - Exercise name (text-h6, weight-bold)
  - **Cantidad** (renamed from "Dosis"): format reps, seconds, death-by sequence (reuse formatting logic from existing ExerciseCard.vue)
  - Contraction type: full name (Concentrica/Excentrica/Isometrica)
  - Notes (if present, italic, smaller)
  - Position: "X de Y" within block
  - **"Completar" button**: full-width `q-btn` at the bottom of the detail panel
    - If NOT completed: `color="primary"` (Terracotta), label "Completar"
    - If completed: `color="positive"`, label "Completado", icon `check_circle`
    - `@click="emit('complete')"` — this is the ONLY way to mark complete per CONTEXT.md

For the **mobility slide** (isMobilitySlide=true, mobilityExercise provided):

- Same layout but uses mobilityExercise data instead of exercise
- Detail panel shows: mobility exercise name, Cantidad (reps or seconds), contraction
- "Completar" button NOT shown for mobility (mobility completion is optional per Phase 17 decision)
- Instead show "Descanso Activo" label in subtitle position

**Styling:**

- BEM: `.story-card`, `.story-card__video-area`, `.story-card__name-hero`, `.story-card__tap-left`, `.story-card__tap-right`, `.story-card__detail`, `.story-card__complete-btn`

- Detail panel: cream background, `padding: 16px`, subtle top border
- Import `quasar.variables.scss` for `$cream`, `$primary`
