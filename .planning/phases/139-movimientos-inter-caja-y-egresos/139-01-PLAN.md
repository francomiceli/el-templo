<objective>
Lay the ledger foundation for inter-caja movements and expenses: extend the
`kind` enum with `cash_transfer` + `expense`, make `member_id` nullable, widen
the dependent TypeScript types, and close the two RESEARCH "must-fix" leaks that
the new kinds introduce into existing read paths. Also add a public `voidPair`
primitive on `TransactionService` so phase-139's `MovementService` (Plan 03) can
void a 2-row movement atomically without exposing the private `_void`.

Purpose: Every downstream task (MovementService, getBalance outflow, void-the-pair)
depends on these schema + type changes existing first. The two must-fixes are
NOT optional polish — without them a movement silently corrupts `monthlyRevenue`
(MUST-FIX A) and `tsc --noEmit` fails (MUST-FIX B).

Output: Migration 0155, widened schema/types, hardened create()/getSummary/applyDelta,
a public voidPair helper, and a regression test proving a movement does not move revenue.
</objective>
