<threat_model>

## Trust Boundaries

| Boundary                                | Description                                                               |
| --------------------------------------- | ------------------------------------------------------------------------- |
| deep link / token → app router          | Token arrives via an untrusted email link; must not grant the reservation |
| app → reserve-trial / eligibility       | Authenticated member; server is the authorization source of truth         |
| OS App Links verification → .well-known | assetlinks/AASA files served from eltemplo.org establish app↔domain trust |

## STRIDE Threat Register

| Threat ID   | Category               | Component              | Disposition | Mitigation Plan                                                                                                  |
| ----------- | ---------------------- | ---------------------- | ----------- | ---------------------------------------------------------------------------------------------------------------- |
| T-119-05-01 | Elevation of Privilege | deep link token        | mitigate    | Token ignored for auth (D-21); eligibility fetched server-side; backend reserveTrial revalidates state (Plan 03) |
| T-119-05-02 | Spoofing               | App Links domain assoc | mitigate    | autoVerify + .well-known assetlinks/AASA bind the app to eltemplo.org; distinct SHA-256 per prod/staging app ID  |
| T-119-05-03 | Tampering              | trial cancel from app  | mitigate    | No cancel affordance rendered for trials (D-03); backend rejects trial cancel (Plan 03)                          |
| T-119-05-04 | Information Disclosure | eligibility surface    | accept      | Endpoint returns only the requesting user's own status/booking (enforced in Plan 03)                             |
| T-119-05-SC | Tampering              | npm installs           | accept      | No package installs (@capacitor/app already in deps).                                                            |

</threat_model>
