<objective>
Build the reusable campaign module (D-12): an HMAC tracking token (D-04/D-21), tracking endpoints (open pixel + click redirect + unsubscribe — public, no auth, D-18/D-15), the `CampaignService` facade (create-draft D-12, audience query D-08/09/10, batch send D-11/D-12, per-campaign funnel D-18/D-19), Fastify schemas, and route registration. ## Trust Boundaries

| Boundary                                    | Description                                                                       |
| ------------------------------------------- | --------------------------------------------------------------------------------- |
| email recipient → public tracking endpoints | Unauthenticated callers (email clients / browsers) hit pixel/click/unsubscribe    |
| admin client → campaign create/send/funnel  | Owner/admin JWT + country scope; create writes a draft, mass send is irreversible |
| campaign module → Resend                    | Email transport via shared EmailService                                           |

| ----------- | ---------------------- | -------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
