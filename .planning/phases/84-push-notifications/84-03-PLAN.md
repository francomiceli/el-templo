import { FastifyPluginAsync } from "fastify";

**Member endpoints (authenticated):**

1. **POST /token** — Register FCM token (per D-26)
   - onRequest: [fastify.authenticate]
   - Body schema: { token: string (minLength 10, maxLength 500), platform: enum ['android', 'ios'] }
   - Handler: call service.registerToken(request.user.userId, body.token, body.platform)
   - Return 200 { success: true }

2. **GET /preferences** — Get member notification preferences (per D-18)
   - onRequest: [fastify.authenticate]
   - Handler: call service.getUserPreferences(request.user.userId)
   - Return 200 { preferences: { entrenamiento: true, programas: true, motivacion: true, anuncios: true } }

3. **PUT /preferences** — Update a single category preference (per D-20)
   - onRequest: [fastify.authenticate]
   - Body schema: { category: enum ['entrenamiento', 'programas', 'motivacion', 'anuncios'], enabled: boolean }
   - Validate category is in NOTIFICATION_CATEGORIES
   - Handler: call service.updatePreference(request.user.userId, body.category, body.enabled)
   - Return 200 { success: true }

4. **POST /:id/opened** — Report notification opened (per D-32)
   - onRequest: [fastify.authenticate]
   - Params schema: { id: integer }
   - Handler: call service.recordOpened(params.id)
   - Return 200 { success: true }
   - Graceful: if notification ID not found, still return 200 (don't fail the client)

**Admin endpoints (ADMIN_ROLES):**

5. **GET /admin/templates** — List all notification templates (per D-14)
   - onRequest: [fastify.authenticate], preHandler checks role in ADMIN_ROLES (per D-15)
   - Per-route auth pattern (same as programs/routes.ts)
   - Handler: query all notification_templates, return array of { id, templateKey, category, title, body, route, isEnabled, sentCount, openedCount, openRate (computed: openedCount/sentCount\*100 or 0) }
   - Return 200 { templates: [...] }

6. **PUT /admin/templates/:id** — Update template (per D-13)
   - onRequest: [fastify.authenticate], preHandler ADMIN_ROLES check
   - Params: { id: integer }
   - Body: { title?: string, body?: string, route?: string, isEnabled?: boolean }
   - Handler: update notification_templates where id=params.id with provided fields
   - Return 200 with updated template

7. **POST /admin/send-segment** — Send notification to segment(s) (per D-14)
   - onRequest: [fastify.authenticate], preHandler ADMIN_ROLES check
   - Body: { title: string, body: string, segmentIds: string[] (array of segment names from memberSegmentEnum), route?: string }
   - Handler: query member_profiles where segment IN segmentIds, for each member queue an ad-hoc notification (category 'anuncios') via service.queueAdHocNotification
   - Return 200 { queued: number } (count of notifications queued)

8. **POST /admin/seed-templates** — Seed initial templates (one-time setup)
   - onRequest: [fastify.authenticate], preHandler ADMIN_ROLES check (using OWNER_ROLES for safety — only owner can seed)
   - Import OWNER_ROLES from permissions
   - Handler: call service.seedTemplates()
   - Return 200 { success: true }
