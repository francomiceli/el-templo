<task type="auto">
  <name>Task 2: Register all editing routes in admin routes module</name>
  <files>
    el-templo-api/src/modules/admin/routes.ts
    el-templo-api/src/modules/admin/index.ts
  </files>
  <action>
    Add to `el-templo-api/src/modules/admin/routes.ts`:

    1. Import AdminEditService and instantiate alongside existing AdminSessionService:
       `const editService = new AdminEditService(fastify.db);`

    2. Add these routes (all under existing /admin prefix with role check hook):

    **Exercise Pool:**
    ```
    GET /exercises/pool
    - Query: route, contraction?, blockId, pattern?
    - Handler: editService.getExercisePool(query)
    - Schema: getExercisePoolSchema
    ```

    **Exercise Swap:**
    ```
    POST /sessions/:sessionId/blocks/:blockId/exercises/:prescriptionId/swap
    - Body: { newExerciseId }
    - Handler: editService.swapExercise({ sessionId, blockId, oldPrescriptionId: prescriptionId, newExerciseId, userId: request.user.userId })
    - Schema: swapExerciseSchema
    ```

    **Prescription Update:**
    ```
    PATCH /sessions/:sessionId/blocks/:blockId/exercises/:prescriptionId
    - Body: { reps?, seconds?, rest?, notes? }
    - Handler: editService.updatePrescription({ sessionId, blockId, prescriptionId, fields: body, userId: request.user.userId })
    - Schema: updatePrescriptionSchema
    ```

    **Format Change:**
    ```
    PATCH /sessions/:sessionId/blocks/:blockId/format
    - Body: { formatId, formatName }
    - Handler: editService.changeBlockFormat({ sessionId, blockId, ...body, userId: request.user.userId })
    - Schema: changeFormatSchema
    ```

    **Add Exercise:**
    ```
    POST /sessions/:sessionId/blocks/:blockId/exercises
    - Body: { exerciseId }
    - Handler: editService.addExercise({ sessionId, blockId, exerciseId, userId: request.user.userId })
    - Schema: addExerciseSchema
    ```

    **Remove Exercise:**
    ```
    DELETE /sessions/:sessionId/blocks/:blockId/exercises/:prescriptionId
    - Handler: editService.removeExercise({ sessionId, blockId, prescriptionId, userId: request.user.userId })
    - Schema: removeExerciseSchema
    ```

    **Reset to Algorithm:**
    ```
    POST /sessions/:id/reset
    - Handler: editService.resetToAlgorithm({ sessionId: id, userId: request.user.userId })
    - Schema: resetSessionSchema
    - Return 400 if no snapshot available
    ```

    **Compatible Formats:**
    ```
    GET /formats/compatible
    - Query: blockRole, level, intensity
    - Handler: editService.getCompatibleFormats(query)
    - Schema: getCompatibleFormatsSchema
    ```

    **Member Preview:**
    ```
    GET /sessions/:id/preview
    - Query: memberLevel?
    - Handler: Use existing adminService.getSessionWithDetails(id) and transform to preview format
    - The preview is the same session data in a simplified read-only shape
    - Per user decision: level-specific preview via dropdown switches between sessions for different levels
    - If memberLevel provided, find the corresponding session for that level (same week/day, different memberLevel)
    - Schema: getPreviewSchema
    ```

    3. Update `index.ts` to export AdminEditService if needed.

    Error handling pattern (consistent with existing routes):
    - 404 for session/block/exercise not found: `{ error: 'Recurso no encontrado' }`
    - 400 for invalid operation (e.g., reset without snapshot): `{ error: 'No hay snapshot disponible para esta sesion' }`
  </action>
