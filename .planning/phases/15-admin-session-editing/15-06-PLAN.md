    Per user decision: centered dialog/modal, one exercise swap at a time.

    **Props:**
    - modelValue: boolean (v-model for dialog open state)
    - sessionId: number
    - blockId: number
    - currentExercise: SessionExercise (the exercise being replaced)
    - blockRoute: string (route of the block)
    - blockPattern: string (pattern of the block, for cross-route filtering)

    **Emits:**
    - 'update:modelValue': boolean
    - 'swapped': void (notify parent to reload)

    **Template structure:**
    QDialog (v-model bound, persistent while loading):
      QCard (min-width: 600px, max-width: 800px):
        - Header: "Reemplazar Ejercicio" title + close button
        - Current exercise info: name, contraction badge, difficulty
        - Filter bar:
          - QSelect for contraction type filter: All / CON / EXC / ISO
          - QInput for search (filter by exercise name, debounced 300ms)
        - Loading state: QSpinnerDots while fetching pool
        - Empty state: "No hay ejercicios disponibles" when pool empty
        - Exercise list: QList with separator, bordered
          Each exercise item (QItem, clickable):
          - Exercise name (text-weight-medium)
          - Row of badges:
            - Contraction badge (CON/EXC/ISO with color: blue-grey/teal/orange)
            - Linear difficulty number badge (small, outlined)
            - Pattern badge showing which pattern the exercise comes from (e.g., "pattern_1", "pattern_2") - per user decision
          - Swap button on right side (swap_horiz icon)
          - Per user decision: sort by closest linear difficulty to current exercise

    **Script logic:**
    - Watch modelValue: when dialog opens, call fetchExercisePool with block's route and pattern
    - Contraction filter: when changed, re-fetch pool with contraction param
    - Search filter: client-side filter on fetched results (filter by exercise name contains search text)
    - Sort: computed that sorts exercises by |exercise.dificultadLineal - currentExercise.dificultadLineal| ascending
    - On exercise click: call swapExercise(sessionId, blockId, currentExercise.id, selectedExercise.id)
      - Show QSpinner on the clicked item during API call
      - On success: $q.notify positive "Ejercicio reemplazado", emit 'swapped', close dialog
      - On error: $q.notify negative "Error reemplazando ejercicio"
    - Per user decision: one swap at a time - dialog closes after successful swap

    **Pattern badge logic:**
    - Compare exercise.pattern against the block's pattern
    - If exercise comes from a different pattern (cross-route), show "pattern_2" badge in a distinctive color (e.g., deep-orange)
    - If exercise matches block's pattern, show "pattern_1" badge or no badge at all
    - This helps coaches understand why an exercise appears in the pool (per user decision)

    **Styling:**
    - Use Claude's discretion for exact modal sizing (600-800px width)
    - Contraction filter: small QSelect above the list
    - Search: QInput with search icon, outline style
    - Scrollable list area with max-height (e.g., 400px) for long exercise pools
